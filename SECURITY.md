# Security Policy

## Catalog scope

This repository contains catalog metadata, documentation and generic contribution configuration.
A listing is not a security certification, and this project does not endorse or guarantee any
plugin. Check the original repository, pinned source commit, license and installation behavior
before installing an entry.

## Reporting a plugin vulnerability

Report vulnerabilities in a listed plugin privately to that plugin's original maintainer. Do not
publish exploit details in this catalog's issues. After coordinating with the maintainer, request
a catalog correction or quarantine state without including sensitive reproduction material.

## Reporting a catalog vulnerability

When the public repository is available, use its private GitHub Security Advisory channel for
vulnerabilities in catalog validation or contribution handling. Do not use a public issue for an
unpatched vulnerability.

## Secrets and personal data

Never submit access tokens, API keys, cookies, private email addresses, credentials or private
repository contents in entries, pull requests or issue forms. Public evidence must come from the
original public source repository and its pinned commit.

## Unofficial status

This is an unofficial community project. It is not affiliated with, endorsed by, or sponsored by
DeepSeek. DeepSeek names and marks belong to their respective owner.
