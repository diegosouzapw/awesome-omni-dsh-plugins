## Scopul catalogului

Acest repository conține metadate de catalog, documentație și configurație generică de contribuție.
O listare nu este o certificare de securitate, iar acest proiect nu susține și nu garantează niciun
plugin. Verifică repository-ul original, commit-ul sursă fixat, licența și comportamentul de
instalare înainte de a instala o intrare.

## Raportarea unei vulnerabilități de plugin

Raportează vulnerabilitățile unui plugin listat în mod privat, întreținătorului original al acelui
plugin. Nu publica detalii de exploit în issue-urile acestui catalog. După coordonarea cu
întreținătorul, solicită o corectare a catalogului sau o stare de carantină, fără a include
material sensibil de reproducere.

## Raportarea unei vulnerabilități de catalog

Când repository-ul public este disponibil, folosește canalul lui privat GitHub Security Advisory
pentru vulnerabilități în validarea catalogului sau în procesarea contribuțiilor. Nu folosi un
issue public pentru o vulnerabilitate neremediată.

## Secrete și date personale

Nu trimite niciodată tokenuri de acces, chei API, cookie-uri, adrese de e-mail private, credențiale
sau conținut privat de repository în intrări, pull request-uri sau formulare de issue. Dovezile
publice trebuie să provină din repository-ul sursă public original și din commit-ul lui fixat.

Acesta este un proiect comunitar neoficial. Nu este afiliat, susținut sau sponsorizat de DeepSeek.
Numele și mărcile DeepSeek aparțin proprietarului lor de drept.
