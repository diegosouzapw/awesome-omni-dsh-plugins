# Bezpečnostná politika

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **Slovenčina**

## Rozsah katalógu

Tento repozitár obsahuje metadáta katalógu, dokumentáciu a všeobecnú konfiguráciu prispievania.
Zaradenie do zoznamu nie je bezpečnostnou certifikáciou a tento projekt žiadny plugin neodporúča
ani nezaručuje. Pred inštaláciou záznamu skontrolujte pôvodný repozitár, pripnutý zdrojový commit,
licenciu a správanie pri inštalácii.

## Nahlásenie zraniteľnosti pluginu

Zraniteľnosti zaradeného pluginu nahláste súkromne pôvodnému správcovi daného pluginu.
Nezverejňujte podrobnosti o zneužití v issues tohto katalógu. Po koordinácii so správcom požiadajte
o opravu katalógu alebo karanténny stav bez zahrnutia citlivých materiálov na reprodukciu.

## Nahlásenie zraniteľnosti katalógu

Ak je dostupný verejný repozitár, použite pre zraniteľnosti vo validácii katalógu alebo v spracovaní
príspevkov jeho súkromný kanál GitHub Security Advisory. Pre neopravenú zraniteľnosť nepoužívajte
verejný issue.

## Tajomstvá a osobné údaje

V záznamoch, pull requestoch ani formulároch issues nikdy nepredkladajte prístupové tokeny, API
kľúče, cookies, súkromné e-mailové adresy, prihlasovacie údaje ani obsah súkromných repozitárov.
Verejné dôkazy musia pochádzať z pôvodného verejného zdrojového repozitára a jeho pripnutého
commitu.

## Neoficiálny status

Toto je neoficiálny komunitný projekt. Nie je prepojený s DeepSeek, nie je ním podporovaný ani
sponzorovaný. Názvy a značky DeepSeek patria ich príslušnému vlastníkovi.
