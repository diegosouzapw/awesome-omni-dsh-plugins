## Stručný prehľad

| Časť     | Čo to je                                                       | Kde                                                                    |
| ----------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Web** | Vykreslený prehliadač katalógu s vyhľadávaním a rebríčkom                 | [dsh-plugins.omniroute.online](https://dsh-plugins.omniroute.online)     |
| **Katalóg** | Jeden YAML súbor na plugin, jediný zdroj pravdy             | [`catalog/plugins/`](../../catalog/plugins)                                    |
| **Schéma**  | Verejná JSON schéma (draft 2020-12), voči ktorej sa validuje každý záznam | [`schemas/plugin.schema.yaml`](../../schemas/plugin.schema.yaml)               |
| **CLI**     | Vyhľadávanie, kontrola, validácia a inštalácia z katalógu           | [`omni-dsh-plugins`](https://www.npmjs.com/package/omni-dsh-plugins) |
| **Strojové zdroje** | `catalog.json` + `catalog.snapshot.json` pre nástroje           | [catalog.json](https://dsh-plugins.omniroute.online/catalog.json) · [catalog.snapshot.json](https://dsh-plugins.omniroute.online/catalog.snapshot.json) |

Tento repozitár je verejným zdrojom pravdy pre katalóg. Každý záznam je jeden YAML súbor v priečinku
`catalog/plugins/`, validovaný voči zverejnenej JSON schéme, pridaný prostredníctvom jedného
individuálne posúdeného pull requestu a vždy pripísaný pôvodnému tvorcovi pluginu.
Nič v katalógu nie je generované z iného katalógu alebo zoznamu: každý záznam je zrekonštruovaný
z repozitára pôvodného tvorcu na pripnutom commite.

Web je udržiavaný zo súkromného zdrojového kódu. CLI sa nachádza tu, v tomto repozitári, v priečinku
[`cli/`](../../cli) a tento repozitár obsahuje verejné dáta katalógu, schému a politiky, ktoré obe
využívajú.

## Stav katalógu

**483 zlúčených pluginov.** Každý plugin vstupuje prostredníctvom individuálne posúdeného pull
requestu, jeden po druhom, z repozitára pôvodného tvorcu, s pripnutým zdrojovým commitom a
explicitným pripísaním autorstva.

## 🚀 Inštalácia CLI

```bash
npx omni-dsh-plugins --help
```

Balík je publikovaný ako `omni-dsh-plugins@1.0.1` a príkaz vyššie je dnes kanonickým
spôsobom spustenia; žiadny inštalačný skript tu nie je hosťovaný.

### Používanie CLI už dnes

Verzia 1.0.1 obsahuje príkazy len na čítanie pre objavovanie a validáciu, ako aj inštalačné
príkazy podmienené súhlasom. Úplný referenčný prehľad príkazov vrátane príznakov, návratových
kódov a brány súhlasu na spustenie kódu nájdete v [docs/CLI.md](../../docs/CLI.md).

| Príkaz                        | Čo robí                                                        | Zasahuje do vášho systému?                    |
| ------------------------------ | --------------------------------------------------------------------- | --------------------------------------- |
| `catalog validate --catalog .` | Validuje YAML katalógu, schému a lokálnu sémantiku                   | Nie — len na čítanie                          |
| `search <query...>`            | Lokálne vyhľadáva vo verejných poliach katalógu                                | Nie — len na čítanie                          |
| `info <id>`                    | Zobrazí jeden verejný záznam katalógu                                       | Nie — len na čítanie                          |
| `list`                         | Vypíše inštalácie spravované katalógom bez úpravy profilov            | Nie — len na čítanie                          |
| `doctor`                       | Diagnostika len na čítanie pre Node, DSH, natívnu politiku Windows a katalóg  | Nie — len na čítanie                          |
| `add <id> --profile <name> --dry-run` | Zobrazí overený inštalačný plán bez súborov alebo podprocesov | Nie — skúšobný beh (dry-run)                            |
| `add <id> --profile <name> --allow-code-execution` | Inštaluje prostredníctvom oficiálnej delegácie DSH        | Áno — iba s explicitným príznakom súhlasu   |

```bash
# Validate the catalog in this repository (what CI runs):
npx omni-dsh-plugins catalog validate --catalog .

# Search and inspect locally, without installing anything:
npx omni-dsh-plugins search memory --catalog .
npx omni-dsh-plugins info <plugin-id> --catalog .

# Preview an install plan; nothing is written and no subprocess runs:
npx omni-dsh-plugins add <plugin-id> --profile default --dry-run
```

Meniace príkazy (`add`, `update`, `remove`) nikdy nespúšťajú kód životného cyklu pluginu, pokiaľ
nezadáte `--allow-code-execution`. Na natívnom Windows sú tieto zmeny vo verzii v1.0.1 zakázané;
použite WSL. Príkazy len na čítanie a skúšobný beh fungujú všade.

## 🔍 Ako sa plugin dostane do katalógu

![Ako sa plugin dostane do katalógu](../../docs/diagrams/catalog-flow-dark.svg#gh-dark-mode-only)
![Ako sa plugin dostane do katalógu](../../docs/diagrams/catalog-flow-light.svg#gh-light-mode-only)

1. **Jeden plugin, jedna vetva, jeden pull request.** Pull request pridáva alebo mení presne
   jeden YAML súbor v priečinku `catalog/plugins/`.
2. **Prednosť tvorcu.** Pull request otvorený tvorcom pluginu alebo vlastniacou organizáciou má
   vždy prednosť pred kurátorstvom komunity alebo automatizáciou pre ten istý plugin — pozri
   [docs/CREDIT.md](../../docs/CREDIT.md).
3. **Dôkazy z pôvodného zdroja.** Každé pole je zrekonštruované z repozitára tvorcu na pripnutom
   40-znakovom commite: popis, licencia, DSH integrácia, inštalačný deskriptor, hviezdičky.
4. **Lokálna validácia.** `catalog validate` kontroluje štruktúru a lokálnu sémantiku; ide o
   rovnakú kontrolu, akú na pull requeste spúšťa CI úloha `catalog-validation`.
5. **Brány správcov.** Pred zlúčením správcovia samostatne overujú identitu repozitára, väzbu na
   tvorcu a pripnuté dôkazy. Zelená lokálna validácia je nevyhnutná, nikdy však postačujúca.

Úplná zmluva — požadované dôkazy, pravidlá YAML, politika hviezdičiek, riešenie kolízií a brány
posúdenia — sa nachádza v [CONTRIBUTING.md](../../CONTRIBUTING.md). Ako a kým sa prijímajú
rozhodnutia, nájdete v [docs/GOVERNANCE.md](../../docs/GOVERNANCE.md).

## 📄 Anatómia záznamu

Každý záznam je jeden YAML súbor pomenovaný podľa svojho ID. Nasledujúci príklad je validný voči
aktuálnej schéme (referencia pole po poli je v [docs/SCHEMA.md](../../docs/SCHEMA.md)):

```yaml
schemaVersion: 1
id: example-notes-search
name: Example Notes Search
description:
  en: >-
    Searches a local Markdown notes folder from DSH sessions and returns
    matching snippets with file paths.
  evidencePath: README.md
unofficial: true
kind: plugin
primaryCategory: search-research
tags:
  - search
  - notes
  - cli
source:
  repository: https://github.com/example-creator/example-notes-search
  repositoryNodeId: R_kgDOExample01
  subpath: null
  commit: 0123456789abcdef0123456789abcdef01234567
creator:
  github: example-creator
package:
  ecosystem: npm
  name: example-notes-search
  version: 1.4.2
dsh:
  profiles:
    - default
  evidencePath: dsh-plugin.json
repositoryScope: dedicated
popularity:
  starsPolicy: exact-repository
  stars: 128
license:
  spdx: MIT
verification:
  status: eligible
  checkedAt: "2026-08-18T12:00:00Z"
  repositoryIdentity: resolved
  smokeTest: null
provenance:
  discussion: null
  comment: null
```

Kľúčové invarianty vynucované schémou:

- `unofficial: true` a `schemaVersion: 1` sú konštanty.
- Plugin v monorepe musí používať `stars: null` — hviezdičky nadradeného projektu sa nikdy
  nededia.
- Inštalačný deskriptor je buď npm balík s presnou verziou, alebo priamo pripnutý zdroj; ide o
  dáta, nikdy nie o shellový príkaz.
- Stav `verified` vyžaduje preskúmateľné dôkazy zo smoke testu; inak je záznam `eligible` s
  `smokeTest: null`.

## 🗂 Čo sem patrí

Tento repozitár katalogizuje nezávisle publikované integrácie pre DeepSeek Harness (DSH), vrátane
natívnych pluginov, rodín pluginov, tém, zručností, klientov a mostíkov (bridges). Druhy
artefaktov, kategórie schopností a značky rozhrania sú definované v
[docs/CATEGORIES.md](../../docs/CATEGORIES.md).

Každý verejný záznam je jeden YAML súbor v priečinku `catalog/plugins/` a musí byť validný voči
`schemas/plugin.schema.yaml`. Zaradenie do zoznamu znamená, že boli dokončené zdokumentované
kontroly oprávnenosti alebo overenia; nejde o bezpečnostnú certifikáciu ani o potvrdenie zo
strany DeepSeek.

## 🏅 Rebríček a overenie

Do rebríčka podľa hviezdičiek sa môžu zaradiť iba vyhradené, natívne, oprávnené alebo overené
repozitáre pluginov, ktorých hviezdičky patria presne danému repozitáru. Integrácie uložené vo
väčších monorepách zostávajú objaviteľné, ale používajú `stars: null` a nikdy nededia hviezdičky
nadradeného projektu. Úplný predikát nájdete v [docs/RANKING.md](../../docs/RANKING.md).

Verejné stavy overenia odlišujú štrukturálnu oprávnenosť od smoke testu inštalácie. Žiadny stav
nepredstavuje absolútnu bezpečnosť. Pred použitím pluginu si preverte jeho repozitár, pripnutý
commit, licenciu a správanie pri inštalácii.

## 🤝 Prispejte alebo si nárokujte záznam

Pred otvorením pull requestu si prečítajte [CONTRIBUTING.md](../../CONTRIBUTING.md). Pull
request musí pridať alebo zmeniť presne jeden záznam o plugine a musí odkazovať na repozitár
pôvodného tvorcu, nie na iný katalóg. Pull requesty od samotného tvorcu majú prednosť pred
automatizovanými pull requestmi katalógu.

Pre nároky tvorcov, opravy a odstránenia sú k dispozícii štruktúrované formuláre issue. Nikdy
nezadávajte prihlasovacie údaje, súkromné kontaktné informácie ani iné tajomstvá.

## 👩‍🎨 Tvorcovia pluginov
