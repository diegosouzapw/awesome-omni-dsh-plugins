# ランキングの方法論

> 🌐 [English](../../RANKING.md) · [Português (Brasil)](../pt-BR/RANKING.md) · [中文（简体）](../zh-CN/RANKING.md) · **日本語**

ランキングは、マージ済みの公開カタログエントリに対する透明なビューです。隠された合成スコアを使用すること
は決してなく、より広い親プロジェクトのスターをプラグインの人気度として扱うことも決してありません。

## トッププラグイン(スター数順)の述語

エントリは、以下のすべての条件が真である場合にのみ適格になります:

```text
kind == plugin (正規のネイティブDSHバンドル判別子)
repositoryScope == dedicated
verification.status in [eligible, verified]
repository is active and not archived
stars belong to the exact plugin repository
entry is merged into the public catalog
```

適格なエントリは、`popularity.starsPolicy: exact-repository` と、`popularity.stars` における非負の整数
を使用します。同点の場合は、大文字小文字を区別しないプラグインIDを決定論的な表示順として使用します。この
タイブレークは、品質の差を意味するものではありません。

`kind` は唯一のアーティファクトタイプ判別子です。スキーマは意図的に、それと矛盾しうる第2のDSH統合種別を
保存しません。

## 明示的な除外事項

より広いモノレポ内にあるプラグインは、引き続きカタログへの掲載資格がありますが、その親のスターはプラグイ
ンランキングにおいて未定義です。それは `repositoryScope: monorepo`、
`popularity.starsPolicy: undefined-parent-repository`、`popularity.stars: null` を使用しなければなりま
せん。それは機能的なセクションには表示されますが、あらゆるスターベースのランキングからは除外されます。

プラグインファミリー、テーマ、スキン、skill、プリセット、クライアント、インターフェース、ブリッジ、そし
てより広いエコシステムプロジェクトは、トッププラグイン(スター数順)には表示されません。それらは、比較可
能なデータが存在する場合、別セクションを受け取ります。アグリゲーター、マーケットプレイス、インストーラー
カタログ、リストはカタログエントリではなく、カタログセクションを受け取りません。

## ランキングビュー

このプロジェクトは、スター数、24時間の伸び、7日間の伸び、最近の更新、検証済みインストール、プラグインファ
ミリー、テーマとスキン、クライアントとインターフェース、そしてエコシステム統合について、それぞれ異なるビ
ューを公開する場合があります。各ビューは、独自の掲載ルールとスナップショット時刻を開示しなければなりませ
ん。

適格なエントリが0件の場合、トッププラグインは表示されません。最初の適格なマージによってトッププラグイン
のビューが作成されます。ラベルが「トップ10」に変わるのは、10件の適格なエントリが存在するようになった後だ
けです。プレースホルダーや捏造されたランキングは一切許可されません。

## 検証は推奨を意味しない

`eligible` は、公開された構造とDSH統合が検証されたことを意味します。`verified` はそれに加えて、固定され
たソースまたはパッケージについてインストールのスモークテストが合格したことを意味します。どちらのステータ
スも、推奨、保証、または絶対的なセキュリティ認証ではありません。
