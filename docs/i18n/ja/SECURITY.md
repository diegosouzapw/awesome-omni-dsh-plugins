# セキュリティポリシー

## カタログの対象範囲

このリポジトリには、カタログのメタデータ、ドキュメント、および汎用的な貢献設定が含まれています。掲載され
ていることはセキュリティ認証を意味するものではなく、このプロジェクトはいかなるプラグインについても推奨や
保証を行いません。エントリをインストールする前に、元のリポジトリ、固定されたソースコミット、ライセンス、
インストール時の挙動を確認してください。

## プラグインの脆弱性を報告する

掲載されているプラグインの脆弱性は、そのプラグインの元のメンテナーに非公開で報告してください。このカタロ
グのissueにエクスプロイトの詳細を公開しないでください。メンテナーと調整を行った後、機密性の高い再現手順を
含めずに、カタログの修正または隔離状態への変更をリクエストしてください。

## カタログの脆弱性を報告する

公開リポジトリが利用可能な場合は、カタログの検証または貢献の取り扱いに関する脆弱性について、その非公開の
GitHub Security Advisoryチャンネルを使用してください。未修正の脆弱性について、公開issueを使用しないでくだ
さい。

## 秘密情報と個人データ

エントリ、プルリクエスト、またはissueフォームに、アクセストークン、APIキー、cookie、個人のメールアドレ
ス、認証情報、または非公開リポジトリの内容を決して提出しないでください。公開される証拠は、元の公開ソース
リポジトリと、その固定されたコミットから得られたものでなければなりません。

## 非公式ステータス

これは非公式のコミュニティプロジェクトです。DeepSeek とは提携・承認・スポンサー関係はありません。DeepSeek
の名称および商標は、それぞれの権利者に帰属します。
