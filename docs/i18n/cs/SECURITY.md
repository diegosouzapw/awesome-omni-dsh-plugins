# Bezpečnostní zásady

## Rozsah katalogu

Tento repozitář obsahuje katalogová metadata, dokumentaci a obecnou konfiguraci pro přispívání.
Zařazení do seznamu není bezpečnostní certifikací a tento projekt žádný plugin neschvaluje ani
nezaručuje. Před instalací záznamu zkontrolujte původní repozitář, fixovaný zdrojový commit,
licenci a chování při instalaci.

## Nahlášení zranitelnosti pluginu

Zranitelnosti v pluginu zařazeném do seznamu nahlaste soukromě původnímu správci daného pluginu.
Nepublikujte podrobnosti o zneužití (exploity) v issues tohoto katalogu. Po koordinaci se
správcem požádejte o opravu katalogu nebo stav karantény, aniž byste zahrnuli citlivý materiál
pro reprodukci.

## Nahlášení zranitelnosti katalogu

Pokud je veřejný repozitář dostupný, použijte pro zranitelnosti ve validaci katalogu nebo ve
zpracování příspěvků jeho soukromý kanál GitHub Security Advisory. Pro neopravenou zranitelnost
nepoužívejte veřejné issue.

## Tajemství a osobní údaje

Nikdy neodesílejte přístupové tokeny, API klíče, cookies, soukromé e-mailové adresy,
přihlašovací údaje ani obsah soukromých repozitářů v záznamech, pull requestech nebo formulářích
issues. Veřejné důkazy musí pocházet z původního veřejného zdrojového repozitáře a jeho
fixovaného commitu.

## Neoficiální status

Toto je neoficiální komunitní projekt. Není přidružen k DeepSeek, DeepSeek jej neschvaluje ani
nesponzoruje. Názvy a značky DeepSeek náleží jejich příslušným vlastníkům.
