# Політика безпеки

> 🌐 [English](../../SECURITY.md) · **Українська**

> **Неофіційний проєкт спільноти. Не пов'язаний із DeepSeek, не схвалений і не спонсорований компанією DeepSeek.**
> Назви та товарні знаки DeepSeek належать їхньому власнику.

## Область каталогу

Цей репозиторій містить метадані каталогу, документацію та загальну конфігурацію для внесків.
Наявність запису не є сертифікацією безпеки, і цей проєкт не схвалює та не гарантує жодного
плагіна. Перед встановленням запису перевірте оригінальний репозиторій, закріплений коміт
джерела, ліцензію та поведінку під час встановлення.

## Повідомлення про вразливість плагіна

Повідомляйте про вразливості плагіна, внесеного до каталогу, приватно оригінальному супровіднику
цього плагіна. Не публікуйте деталі експлойтів в issue цього каталогу. Після узгодження із
супровідником попросіть виправлення запису в каталозі або статус карантину, не включаючи чутливих
матеріалів відтворення.

## Повідомлення про вразливість каталогу

Коли публічний репозиторій доступний, використовуйте його приватний канал GitHub Security
Advisory для вразливостей у валідації каталогу чи обробці внесків. Не використовуйте публічне
issue для невиправленої вразливості.

## Секрети та особисті дані

Ніколи не надсилайте токени доступу, ключі API, куки, приватні адреси електронної пошти, облікові
дані чи приватний вміст репозиторіїв у записах, pull request або формах issue. Публічні докази
мають походити з оригінального публічного репозиторію джерела та його закріпленого коміта.

## Неофіційний статус

Це неофіційний проєкт спільноти. Він не пов'язаний із DeepSeek, не схвалений і не спонсорований
компанією DeepSeek. Назви та товарні знаки DeepSeek належать їхньому власнику.
