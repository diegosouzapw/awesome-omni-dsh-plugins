# 安全政策

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **中文（繁體）**

## 目錄的範圍

本儲存庫僅包含目錄中繼資料、文件與通用的貢獻設定。條目被收錄不代表通過安全認證,本專案也不
為任何外掛背書或提供保證。安裝任何條目之前,請自行檢查原始儲存庫、固定的來源提交(commit)、
授權條款與安裝行為。

## 回報外掛本身的漏洞

若在已收錄的外掛中發現漏洞,請私下回報給該外掛的原始維護者,不要在本目錄的 Issue 中公開漏
洞利用細節。與維護者協調完成後,再對本目錄提出更正或隔離(quarantine)狀態的請求,且不要附
上敏感的重現資料。

## 回報目錄本身的漏洞

若公開儲存庫可用,請透過其私人的 GitHub Security Advisory 管道回報目錄驗證或貢獻處理流程中
的漏洞。未修補的漏洞請勿使用公開 Issue 回報。

## 機密資訊與個人資料

請勿在條目、提取請求(PR)或 Issue 表單中提交存取權杖(access token)、API 金鑰、Cookie、
私人電子郵件地址、憑證或私有儲存庫內容。公開證據必須來自原始的公開來源儲存庫及其固定提交。

## 非官方聲明

本專案為非官方社群專案,與 DeepSeek 無關聯、未經其認可,也未獲其贊助。DeepSeek 的名稱與標
識歸其各自所有者所有。
