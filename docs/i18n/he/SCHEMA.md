# הפניית סכימת רשומת הקטלוג

> 🌐 [English](../../docs/SCHEMA.md) · [Português (Brasil)](../pt-BR/SCHEMA.md) · [中文（简体）](../zh-CN/SCHEMA.md) · **עברית**

> **פרויקט קהילתי בלתי רשמי. אינו קשור, מאושר או ממומן על ידי DeepSeek.**
> השמות והסימנים של DeepSeek שייכים לבעליהם המתאימים.

זוהי הפניה שדה-אחר-שדה עבור [`schemas/plugin.schema.yaml`](../../schemas/plugin.schema.yaml),
סכימת ה-JSON הציבורית (טיוטה 2020-12) שכל קובץ תחת `catalog/plugins/` חייב לספק. קובץ הסכימה
עצמו הוא מקור האמת; כאשר עמוד זה והסכימה חלוקים, הסכימה מנצחת.

חלות שתי שכבות אימות. הסכימה הציבורית אוכפת *צורות בטוחות* מוגבלות (תבניות ואורכים הדוחים
ערכים דמויי-אפשרות או בלתי-מוגבלים). מעל לכך, `catalog validate` מיישמת מפרשים סמנטיים חובה:
SemVer מדויק עבור גרסאות, SHA-512 SRI עבור ערכי שלמות (integrity), פירוש ביטויי SPDX עבור
רישיונות, ודחיית מפתחות כפולים. ערך יכול להתאים לתבנית הסכימה ובכל זאת להידחות סמנטית.

כללי רמה עליונה: הרשומה היא אובייקט YAML יחיד, `additionalProperties: false` (שדות לא ידועים
נדחים), וכל השדות הבאים נדרשים.

## שדות ברמה העליונה

| שדה                | סוג     | נדרש  | תקציר                                                       |
| ----------------- | ------- | :------: | ------------------------------------------------------------- |
| `schemaVersion`   | קבוע    |   כן    | חייב להיות בדיוק `1`                                          |
| `id`              | מחרוזת  |   כן    | מזהה רשומה ב-kebab-case באותיות קטנות; חייב להתאים לשם הקובץ  |
| `name`            | מחרוזת  |   כן    | שם תצוגה, 1–120 תווים                                         |
| `description`     | אובייקט |   כן    | תקציר אנגלי ערוך יחד עם מסלול הראיה שלו                       |
| `unofficial`      | קבוע    |   כן    | חייב להיות בדיוק `true`                                       |
| `kind`            | תעתיק (enum) |   כן    | מבחין החפץ הקנוני                                        |
| `primaryCategory` | תעתיק (enum) |   כן    | קטגוריית יכולת ראשית יחידה                               |
| `tags`            | מערך    |   כן    | תגים ייחודיים ב-kebab-case באותיות קטנות (יכול להיות ריק)      |
| `source`          | אובייקט |   כן    | מאגר מקורי, מזהה Node, תת-נתיב וקומיט מוצמד                   |
| `creator`         | אובייקט |   כן    | שם המשתמש הציבורי של היוצר ב-GitHub                            |
| `package`         | אובייקט |   כן    | מתאר התקנה קנוני (npm **או** מקור)                             |
| `dsh`             | אובייקט |   כן    | פרופילי DSH ומסלול ראיית אינטגרציה מקורית                     |
| `repositoryScope` | תעתיק (enum) |   כן    | `dedicated` או `monorepo`                                |
| `popularity`      | אובייקט |   כן    | מדיניות כוכבים וספירת כוכבים (מותנה בהיקף)                    |
| `license`         | אובייקט |   כן    | ביטוי רישיון SPDX של המקור                                     |
| `verification`    | אובייקט |   כן    | מצב אימות, זמן בדיקה, זהות ו-smoke test                        |
| `provenance`      | אובייקט |   כן    | כתובות URL ציבוריות של Discussion/תגובה, או `null`             |

### `schemaVersion`

קבוע `1`. מזהה גרסת סכימה ציבורית 1; כל ערך אחר אינו תקף.

### `id`

מחרוזת התואמת ל-`^[a-z0-9]+(?:-[a-z0-9]+)*$` — kebab-case באותיות קטנות, ללא מקפים מובילים,
נגררים או כפולים. לפי [CONTRIBUTING.md](../../CONTRIBUTING.md), קובץ הרשומה חייב להיקרא
`catalog/plugins/<id>.yaml` עם אותו ערך זהה; המאמת דוחה אי-התאמה (`id-filename-mismatch`).
ה-ID חייב גם להתחיל במרחב השם של היוצר: שם המשתמש `creator.github` באותיות קטנות, כאשר כל
רצף תווים מחוץ ל-`[a-z0-9]` מתקפל למקף בודד `-`, ואחריו `-` (`id-creator-prefix`).

### `name`

שם תצוגה חופשי, `minLength: 1`, `maxLength: 120`.

### `description`

אובייקט עם בדיוק שתי מאפיינים נדרשים (אין אחרים מותרים):

| מאפיין        | סוג     | כללים                                                                 |
| -------------- | ------ | ----------------------------------------------------------------------- |
| `en`           | מחרוזת | תקציר באנגלית, 20–320 תווים                                            |
| `evidencePath` | מחרוזת | תבנית נתיב מאגר יחסי; ללא `/` מוביל, ללא backslash, ללא מקטעי `.`/`..` |

התקציר באנגלית חייב להיות ערוך מהקובץ ב-`evidencePath` כפי שהוא קיים ב-`source.commit` — לא
מועתק מקטלוג אחר.

### `unofficial`

קבוע `true`. סימון הניתן לקריאת מכונה שהרשומה בלתי רשמית.

### `kind`

מבחין סוג החפץ ה**יחיד** (אין שדה סוג אינטגרציה שני). אחד מ:

`plugin` · `plugin-family` · `skin-theme` · `skill` · `preset-profile` · `client-interface` ·
`bridge-adapter` · `ecosystem-project`

המשמעויות וההשלכות על הדירוג מוגדרות ב-[docs/CATEGORIES.md](../../docs/CATEGORIES.md).

### `primaryCategory`

אחת משלוש-עשרה קטגוריות היכולת:

`user-interface-dashboards` · `memory-rag` · `search-research` · `coding-developer-tools` ·
`browser-automation` · `vision-audio-multimodal` · `sessions-productivity` ·
`security-permissions-approvals` · `diagnostics-observability` · `models-providers-routing` ·
`messaging-notifications` · `data-external-services` · `entertainment-customization`

תוויות תצוגה והנחיות בחירה נמצאות ב-[docs/CATEGORIES.md](../../docs/CATEGORIES.md).

### `tags`

מערך של מחרוזות ייחודיות, כל אחת תואמת ל-`^[a-z0-9]+(?:-[a-z0-9]+)*$` (kebab-case באותיות
קטנות). הסכימה אינה כופה מספר מינימלי.

### `source`

אובייקט עם בדיוק ארבעה מאפיינים נדרשים:

| מאפיין           | סוג            | כללים                                                                  |
| ------------------ | -------------- | ---------------------------------------------------------------------- |
| `repository`       | מחרוזת         | כתובת `https://github.com/<owner>/<repo>`; הבעלים עוקב אחר כללי שם משתמש GitHub, שם המאגר 1–100 תווים, לא יכול להיות `.`/`..` או להסתיים ב-`.git` |
| `repositoryNodeId` | מחרוזת         | מזהה Node בלתי-משתנה של מאגר GitHub, לא ריק                            |
| `subpath`          | מחרוזת או null | תת-נתיב התוסף בתוך המאגר (אותה תבנית נתיב יחסי בטוח כמו `evidencePath`), או `null` עבור תוסף בשורש המאגר |
| `commit`           | מחרוזת         | מזהה קומיט הקסדצימלי מלא בן 40 תווים                                   |

אימות הקטלוג חייב לפתור את `repositoryNodeId` ולדחות אי-התאמת כתובת מאגר — פתרון זה הוא שער
בצד המתחזק, לא חלק מהבדיקה המבנית המקומית.

### `creator`

אובייקט עם מאפיין נדרש יחיד:

| מאפיין | סוג     | כללים                                              |
| -------- | ------ | ---------------------------------------------------- |
| `github` | מחרוזת | שם משתמש GitHub (1–39 תווים, כללי handle של GitHub) |

כתובת הפרופיל הציבורי תמיד נגזרת כ-`https://github.com/<handle>`; אין שדה פרופיל שני
מאוחסן, כך ששני הערכים לעולם לא יכולים לסטות זה מזה.

### `package`

מתאר ההתקנה הקנוני. זהו נתון, לעולם לא פקודת מעטפת (shell), ולוקח בדיוק אחת משתי צורות
(`oneOf`):

**חבילת npm** — נדרשים `ecosystem`, `name`, `version`; אופציונלי `integrity`:

| מאפיין      | סוג    | כללים                                                                      |
| ----------- | ----- | ---------------------------------------------------------------------------- |
| `ecosystem` | קבוע  | `npm`                                                                        |
| `name`      | מחרוזת | תבנית שם חבילת npm (אופציונלית עם scope), עד 214 תווים                     |
| `version`   | מחרוזת | תבנית גרסה מדויקת `x.y.z` (עם prerelease/build אופציונלי); טווחים נדחים. השכבה הסמנטית דורשת גם SemVer מדויק וניתן לפירוש |
| `integrity` | מחרוזת | תבנית `sha512-…` SRI אופציונלית, 8–256 תווים. השכבה הסמנטית חייבת לפרש אותה כ-SHA-512 SRI תקין |

**התקנת מקור** — נדרש רק `ecosystem`:

| מאפיין      | סוג    | כללים    |
| ----------- | ----- | -------- |
| `ecosystem` | קבוע  | `source` |

מתאר מקור במכוון אינו מאחסן דבר נוסף: המאגר, הקומיט ותת-הנתיב נגזרים מ-`source`, כך שערכים
בני-שינוי לעולם אינם משוכפלים.

### `dsh`

ראיית אינטגרציית DSH מקורית:

| מאפיין       | סוג   | כללים                                                          |
| -------------- | ------ | ---------------------------------------------------------------- |
| `profiles`     | מערך  | לפחות שם פרופיל ייחודי אחד התואם ל-`^[A-Za-z0-9][A-Za-z0-9._-]*$` |
| `evidencePath` | מחרוזת | נתיב יחסי בטוח לראיית אינטגרציית DSH ב-`source.commit`           |

### `repositoryScope`

או `dedicated` (כוכבי המאגר שייכים לתוסף המדויק הזה) או `monorepo` (התוסף הוא תת-נתיב או חבילה
בתוך פרויקט רחב יותר). ערך זה מניע את כללי הפופולריות המותנים שלהלן.

### `popularity`

| מאפיין      | סוג             | כללים                                                |
| ------------ | --------------- | ------------------------------------------------------ |
| `starsPolicy`| תעתיק (enum)     | `exact-repository` או `undefined-parent-repository`   |
| `stars`      | מספר שלם או null | מספר שלם לא-שלילי, או `null`                          |

כללים מותנים (נאכפים על ידי בלוקי `allOf` של הסכימה):

- `repositoryScope: monorepo` **מכריח** `starsPolicy: undefined-parent-repository` ו-
  `stars: null`. כוכבים של פרויקט אב לעולם אינם מיוחסים לתוסף מונו-ריפו.
- `repositoryScope: dedicated` **מכריח** `starsPolicy: exact-repository` ומספר שלם
  `stars >= 0`.

ראו [docs/RANKING.md](../../docs/RANKING.md) כיצד הערכים האלה מזינים את כלל הדירוג.

### `license`

| מאפיין | סוג     | כללים                                                          |
| -------- | ------ | ---------------------------------------------------------------- |
| `spdx`   | מחרוזת | תבנית ביטוי SPDX, 2–256 תווים, ללא מקף מוביל                    |

הסכימה אוכפת רק תבנית תווים בטוחה; אימות הקטלוג חייב לפרש ולנרמל את הערך עם מפרש ביטויי SPDX
אמיתי. תעדו את הביטוי המלא במעלה הזרם (upstream) כפי שמעוגן בקומיט המוצמד (לדוגמה `Apache-2.0`
או `MIT OR GPL-3.0-only`).

### `verification`

האימות חל על `source.commit`. אובייקט עם ארבעה מאפיינים נדרשים:

| מאפיין             | סוג            | כללים                                                  |
| -------------------- | -------------- | --------------------------------------------------------- |
| `status`             | תעתיק (enum)    | `eligible` · `verified` · `stale` · `unavailable` · `archived` · `quarantined` |
| `checkedAt`          | מחרוזת         | חותמת זמן בפורמט `date-time` של הבדיקה                    |
| `repositoryIdentity` | קבוע           | חייב להיות `resolved`                                     |
| `smokeTest`          | אובייקט או null | רשומת smoke test, או `null` כאשר אין בדיקה מתאימה קיימת   |

כאשר קיים, `smokeTest` דורש:

| מאפיין        | סוג   | כללים                                                             |
| --------------- | ------ | -------------------------------------------------------------------- |
| `installTarget` | קבוע  | `canonical-install-descriptor` — מפנה ל-`package` או למקור המוצמד בלי לשכפל ערכים בני-שינוי |
| `check`         | אובייקט | נדרשים `name` (תבנית שם חבילה) ו-`version` (תבנית גרסה מדויקת)      |
| `result`        | קבוע  | `passed` — smoke test שנכשל אינו נרשם כ-smoke test                   |

כלל מותנה: `status: verified` **דורש** אובייקט `smokeTest` שאינו null. רשומות ללא ראיית
smoke test הניתנת לבדיקה משתמשות ב-`status: eligible` וב-`smokeTest: null`. אף מצב אינו
הצהרת תמיכה או תעודת אבטחה — ראו [docs/RANKING.md](../../docs/RANKING.md).

### `provenance`

קישורי ראיה ציבוריים, כל אחד URI או `null`:

| מאפיין     | סוג          | כללים                                            |
| ------------ | ------------- | --------------------------------------------------- |
| `discussion` | מחרוזת או null | כתובת Discussion ציבורית כאשר קיימת                 |
| `comment`    | מחרוזת או null | כתובת תגובה ציבורית כאשר קיימת                       |

## מה הסכימה אינה בודקת

הסכימה מכוונת להיות מקומית ומבנית. היא **אינה** מוודאת שהמאגר קיים, שמזהה ה-Node תואם
לכתובת, שמסלולי הראיה קיימים בקומיט המוצמד, שספירת הכוכבים מדויקת, או שהיוצר בבעלות המקור.
בדיקות אלו שייכות לשערי הבדיקה של המתחזקים המתוארים ב-[CONTRIBUTING.md](../../CONTRIBUTING.md)
וב-[docs/GOVERNANCE.md](../../docs/GOVERNANCE.md).
