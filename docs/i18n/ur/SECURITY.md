# سیکیورٹی پالیسی

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **اردو**

## کیٹلاگ کا دائرہ کار

اس ریپوزٹری میں کیٹلاگ میٹا ڈیٹا، دستاویزات اور عمومی شراکت کنفیگریشن شامل ہے۔ کسی چیز کی فہرست میں شمولیت کوئی سیکیورٹی سرٹیفیکیشن نہیں ہے، اور یہ پروجیکٹ کسی بھی پلگ ان کی توثیق یا ضمانت نہیں دیتا۔ کسی اندراج کو انسٹال کرنے سے پہلے اصل ریپوزٹری، پن شدہ سورس کمٹ، لائسنس اور انسٹالیشن کے رویے کو چیک کریں۔

## پلگ ان کی خامی کی رپورٹ کرنا

فہرست شدہ پلگ ان میں خامیوں کی رپورٹ نجی طور پر اس پلگ ان کے اصل مینٹینر کو کریں۔ اس کیٹلاگ کے issues میں exploit کی تفصیلات شائع نہ کریں۔ مینٹینر کے ساتھ ہم آہنگی کے بعد، حساس reproduction مواد شامل کیے بغیر کیٹلاگ کی اصلاح یا قرنطینہ حالت کی درخواست کریں۔

## کیٹلاگ کی خامی کی رپورٹ کرنا

جب عوامی ریپوزٹری دستیاب ہو، تو کیٹلاگ توثیق یا شراکت کی ہینڈلنگ میں خامیوں کے لیے اس کا نجی GitHub Security Advisory چینل استعمال کریں۔ کسی غیر پیچ شدہ خامی کے لیے عوامی issue استعمال نہ کریں۔

## خفیہ معلومات اور ذاتی ڈیٹا

اندراجات، pull requests یا issue فارمز میں کبھی بھی access tokens، API keys، کوکیز، نجی ای میل پتے، اسناد یا نجی ریپوزٹری کا مواد جمع نہ کروائیں۔ عوامی ثبوت لازمی طور پر اصل عوامی سورس ریپوزٹری اور اس کے پن شدہ کمٹ سے آنا چاہیے۔

## غیر سرکاری حیثیت

یہ ایک غیر سرکاری کمیونٹی پروجیکٹ ہے۔ یہ DeepSeek سے وابستہ، اس کی توثیق یافتہ یا اس کے زیرِ سرپرستی نہیں ہے۔ DeepSeek کے نام اور نشانات ان کے متعلقہ مالک کی ملکیت ہیں۔
