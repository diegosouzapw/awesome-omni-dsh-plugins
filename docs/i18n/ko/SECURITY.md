# 보안 정책

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **한국어**

## 카탈로그 범위

이 저장소는 카탈로그 메타데이터, 문서, 일반적인 기여 설정을 포함합니다. 등록되어 있다는 것은
보안 인증이 아니며, 이 프로젝트는 어떤 플러그인도 보증하거나 보장하지 않습니다. 항목을 설치하기
전에 원본 저장소, 고정된 소스 커밋, 라이선스, 설치 동작을 확인하세요.

## 플러그인 취약점 신고하기

등록된 플러그인의 취약점은 그 플러그인의 원 메인테이너에게 비공개로 신고하세요. 이 카탈로그의
이슈에 취약점 악용 세부 정보를 게시하지 마세요. 메인테이너와 조율한 후, 민감한 재현 자료를
포함하지 않은 채로 카탈로그 정정이나 격리 상태를 요청하세요.

## 카탈로그 취약점 신고하기

공개 저장소를 이용할 수 있는 경우, 카탈로그 검증이나 기여 처리 과정의 취약점에 대해서는 해당
저장소의 비공개 GitHub 보안 권고(Security Advisory) 채널을 사용하세요. 패치되지 않은 취약점에
대해 공개 이슈를 사용하지 마세요.

## 비밀 정보와 개인 정보

항목, 풀 리퀘스트, 이슈 양식에 액세스 토큰, API 키, 쿠키, 개인 이메일 주소, 자격 증명 또는
비공개 저장소 콘텐츠를 절대 제출하지 마세요. 공개된 증거는 반드시 원본 공개 소스 저장소와 그
고정된 커밋으로부터 나와야 합니다.

## 비공식 상태

이는 비공식 커뮤니티 프로젝트입니다. DeepSeek와 제휴, 승인, 후원 관계가 없습니다. DeepSeek의
이름과 상표는 각 소유자에게 귀속됩니다.
