# બિનસત્તાવાર પ્રોજેક્ટ નોટિસ

> **બિનસત્તાવાર સામુદાયિક પ્રોજેક્ટ. DeepSeek સાથે સંલગ્ન નથી, તેના દ્વારા સમર્થિત નથી કે પ્રાયોજિત નથી.**
> DeepSeek નામો અને ચિહ્નો તેમના સંબંધિત માલિકના છે.

Awesome Omni DSH Plugins એક સ્વતંત્ર સામુદાયિક કેટલોગ અને ઇન્સ્ટોલર પ્રોજેક્ટ છે. કેટલોગમાં
પ્લગિનનું અસ્તિત્વ DeepSeek અથવા આ પ્રોજેક્ટના મેન્ટેનર્સ દ્વારા રિવ્યૂ, સર્ટિફિકેશન,
સ્પોન્સરશિપ કે મંજૂરી સૂચવતું નથી.

પ્રોજેક્ટ ઓફિશિયલ DeepSeek લોગો વાપરતો નથી, DeepSeek ની ઓફિશિયલ વિઝ્યુઅલ ઓળખની
નકલ કરતો નથી કે કેટલોગ સ્ટેટ્સને ઓફિશિયલ સર્ટિફિકેશન તરીકે વર્ણવતો નથી. DeepSeek Harness અને DSH ના સંદર્ભો
ફક્ત કમ્પેટિબિલિટી ટાર્ગેટ્સ ઓળખાવે છે.

પ્લગિન નામો, પ્રોજેક્ટ નામો, લોગો, સ્ક્રીનશોટ્સ, કોડ અને દસ્તાવેજીકરણ તેમના સંબંધિત
માલિકોના છે અને તેમના મૂળ લાઇસન્સ તથા ટ્રેડમાર્ક પોલિસીઓને આધીન રહે છે.
