# સુરક્ષા પોલિસી

## કેટલોગ સ્કોપ

આ રિપોઝિટરી કેટલોગ મેટાડેટા, દસ્તાવેજીકરણ અને સામાન્ય યોગદાન કન્ફિગરેશન ધરાવે છે.
લિસ્ટિંગ સુરક્ષા પ્રમાણપત્ર નથી, અને આ પ્રોજેક્ટ કોઈપણ પ્લગિનને સમર્થન કે ગેરંટી આપતું નથી.
એન્ટ્રી ઇન્સ્ટોલ કરતા પહેલા મૂળ રિપોઝિટરી, પિન કરેલ સોર્સ કમિટ, લાઇસન્સ અને ઇન્સ્ટોલેશન વર્તન ચકાસો.

## પ્લગિનની નબળાઈની જાણ કરવી

લિસ્ટ થયેલ પ્લગિનમાં રહેલી નબળાઈઓની જાણ ખાનગી રીતે તે પ્લગિનના મૂળ મેન્ટેનરને કરો.
આ કેટલોગના ઇશ્યુમાં એક્સપ્લોઇટની વિગતો પ્રકાશિત ન કરો. મેન્ટેનર સાથે સંકલન કર્યા પછી,
સંવેદનશીલ રિપ્રોડક્શન સામગ્રી સામેલ કર્યા વિના કેટલોગ સુધારા અથવા ક્વોરન્ટાઇન સ્ટેટનો અનુરોધ કરો.

## કેટલોગની નબળાઈની જાણ કરવી

જ્યારે પબ્લિક રિપોઝિટરી ઉપલબ્ધ હોય, ત્યારે કેટલોગ વેલિડેશન કે યોગદાન હેન્ડલિંગમાં રહેલી
નબળાઈઓ માટે તેની ખાનગી GitHub Security Advisory ચેનલનો ઉપયોગ કરો. પેચ ન થયેલી
નબળાઈ માટે પબ્લિક ઇશ્યુનો ઉપયોગ ન કરો.

## ગુપ્ત માહિતી અને અંગત ડેટા

એન્ટ્રીઝ, પુલ રિક્વેસ્ટ્સ કે ઇશ્યુ ફોર્મમાં ક્યારેય એક્સેસ ટોકન્સ, API કીઝ, કૂકીઝ, ખાનગી ઇમેઇલ
સરનામાં, ક્રેડેન્શિયલ્સ કે ખાનગી રિપોઝિટરી સામગ્રી સબમિટ ન કરો. પબ્લિક પુરાવો મૂળ
પબ્લિક સોર્સ રિપોઝિટરી અને તેના પિન કરેલા કમિટમાંથી જ આવવો જોઈએ.

## બિનસત્તાવાર સ્ટેટસ

આ એક બિનસત્તાવાર સામુદાયિક પ્રોજેક્ટ છે. તે DeepSeek સાથે સંલગ્ન નથી, તેના દ્વારા સમર્થિત
નથી કે પ્રાયોજિત નથી. DeepSeek નામો અને ચિહ્નો તેમના સંબંધિત માલિકના છે.
