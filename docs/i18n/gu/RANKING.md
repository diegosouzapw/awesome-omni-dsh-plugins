# રેન્કિંગ મેથડોલોજી

રેન્કિંગ્સ મર્જ થયેલી પબ્લિક કેટલોગ એન્ટ્રીઝ પર પારદર્શક વ્યૂઝ છે. તેઓ ક્યારેય છુપાયેલો
સંયુક્ત સ્કોર વાપરતા નથી અને વ્યાપક પેરેન્ટ પ્રોજેક્ટના સ્ટાર્સને ક્યારેય પ્લગિનની લોકપ્રિયતા ગણતા નથી.

## સ્ટાર્સ પ્રમાણે ટોચના પ્લગિન્સ પ્રિડિકેટ

એન્ટ્રી ફક્ત ત્યારે જ લાયક બને છે જ્યારે નીચેની દરેક શરત સાચી હોય:

```text
kind == plugin (the canonical native DSH bundle discriminator)
repositoryScope == dedicated
verification.status in [eligible, verified]
repository is active and not archived
stars belong to the exact plugin repository
entry is merged into the public catalog
```

લાયક એન્ટ્રીઓ `popularity.starsPolicy: exact-repository` અને
`popularity.stars` માં બિન-નકારાત્મક પૂર્ણાંક વાપરે છે. ટાઈ કેસ-ઇન્સેન્સિટિવ પ્લગિન ID ને
નિશ્ચિત ડિસ્પ્લે ક્રમ તરીકે વાપરે છે; ટાઈ-બ્રેક ગુણવત્તાનો તફાવત સૂચવતો નથી.

`kind` એકમાત્ર આર્ટિફેક્ટ-પ્રકાર ડિસ્ક્રિમિનેટર છે. સ્કીમા જાણીજોઈને બીજું
એવું DSH ઇન્ટિગ્રેશન કાઇન્ડ સંગ્રહતું નથી જે તેની સાથે વિરોધાભાસ કરી શકે.

## સ્પષ્ટ બાકાતો

વ્યાપક મોનોરેપોની અંદરનું પ્લગિન કેટલોગ માટે લાયક રહે છે, પરંતુ પ્લગિન રેન્કિંગ માટે તેના
પેરેન્ટ સ્ટાર્સ અવ્યાખ્યાયિત છે. તેણે `repositoryScope: monorepo`,
`popularity.starsPolicy: undefined-parent-repository` અને `popularity.stars: null` વાપરવું જ પડે.
તે ફંક્શનલ વિભાગોમાં દેખાય છે અને દરેક સ્ટાર-આધારિત રેન્કિંગમાંથી બાકાત રહે છે.

પ્લગિન ફેમિલીઝ, થીમ્સ, સ્કિન્સ, સ્કિલ્સ, પ્રીસેટ્સ, ક્લાયન્ટ્સ, ઇન્ટરફેસ, બ્રિજ અને વ્યાપક
ઇકોસિસ્ટમ પ્રોજેક્ટ્સ સ્ટાર્સ પ્રમાણે ટોચના પ્લગિન્સમાં દેખાતા નથી. સરખાવી શકાય તેવો ડેટા અસ્તિત્વમાં
હોય ત્યારે તેમને અલગ વિભાગો મળે છે. એગ્રિગેટર્સ, માર્કેટપ્લેસ, ઇન્સ્ટોલર કેટલોગ અને યાદીઓ કેટલોગ
એન્ટ્રી નથી અને તેમને કોઈ કેટલોગ વિભાગ મળતો નથી.

## રેન્કિંગ વ્યૂઝ

પ્રોજેક્ટ સ્ટાર્સ, 24-કલાક વૃદ્ધિ, 7-દિવસ વૃદ્ધિ, તાજેતરના અપડેટ્સ,
વેરિફાઇડ ઇન્સ્ટોલ્સ, પ્લગિન ફેમિલીઝ, થીમ્સ અને સ્કિન્સ, ક્લાયન્ટ્સ અને ઇન્ટરફેસ, તથા ઇકોસિસ્ટમ
ઇન્ટિગ્રેશન્સ માટે અલગ વ્યૂઝ પ્રકાશિત કરી શકે છે. દરેક વ્યૂએ પોતાનો સમાવેશ નિયમ અને સ્નેપશોટ સમય
જાહેર કરવો જ પડે.

શૂન્ય લાયક એન્ટ્રીઓ પર, ટોચના પ્લગિન્સ રેન્ડર થતા નથી. પહેલી લાયક મર્જ ટોચના
પ્લગિન્સ વ્યૂ બનાવે છે; લેબલ ફક્ત દસ લાયક એન્ટ્રીઓ અસ્તિત્વમાં આવે પછી જ ટોચના 10માં બદલાય છે. કોઈ પ્લેસહોલ્ડર
કે બનાવટી રેન્કિંગની મંજૂરી નથી.

## વેરિફિકેશન એટલે સમર્થન નહીં

`eligible` એટલે પબ્લિક સ્ટ્રક્ચર અને DSH ઇન્ટિગ્રેશન વેલિડેટ થયા. `verified` વધારામાં
એટલે કે પિન કરેલા સોર્સ કે પેકેજ માટે ઇન્સ્ટોલેશન સ્મોક ટેસ્ટ પાસ થયો. કોઈ પણ સ્ટેટસ
સમર્થન, ગેરંટી કે સંપૂર્ણ સુરક્ષા પ્રમાણપત્ર નથી.
