## Alcance del catálogo

Este repositorio contiene metadatos del catálogo, documentación y configuración genérica de
contribución. Un listado no es una certificación de seguridad, y este proyecto no respalda ni
garantiza ningún plugin. Revise el repositorio original, el commit de origen fijado, la licencia
y el comportamiento de instalación antes de instalar una entrada.

## Reportar una vulnerabilidad de un plugin

Reporte las vulnerabilidades de un plugin listado de forma privada al mantenedor original de ese
plugin. No publique detalles de exploits en los issues de este catálogo. Después de coordinar con
el mantenedor, solicite una corrección del catálogo o un estado de cuarentena sin incluir material
sensible de reproducción.

## Reportar una vulnerabilidad del catálogo

Cuando el repositorio público esté disponible, use su canal privado de GitHub Security Advisory
para vulnerabilidades en la validación del catálogo o en el manejo de contribuciones. No use un
issue público para una vulnerabilidad sin parchear.

## Secretos y datos personales

Nunca envíe tokens de acceso, claves de API, cookies, direcciones de correo privadas,
credenciales ni contenido de repositorios privados en entradas, pull requests o formularios de
issue. La evidencia pública debe provenir del repositorio de origen público original y de su
commit fijado.

## Estado no oficial

Este es un proyecto comunitario no oficial. No está afiliado, respaldado ni patrocinado por
DeepSeek. Los nombres y marcas de DeepSeek pertenecen a sus respectivos propietarios.
