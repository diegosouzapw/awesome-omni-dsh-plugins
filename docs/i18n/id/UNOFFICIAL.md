# Pemberitahuan Proyek Tidak Resmi

> 🌐 [English](../../docs/UNOFFICIAL.md) · **Bahasa Indonesia (id)**

> **Proyek komunitas tidak resmi. Tidak berafiliasi dengan, tidak didukung oleh, dan tidak disponsori oleh DeepSeek.**
> Nama dan merek DeepSeek adalah milik pemiliknya masing-masing.

Awesome Omni DSH Plugins adalah proyek katalog dan installer komunitas yang independen.
Kehadiran sebuah plugin di katalog tidak menyiratkan tinjauan, sertifikasi, sponsorship, atau
persetujuan dari DeepSeek atau dari maintainer proyek ini.

Proyek ini tidak menggunakan logo resmi DeepSeek, tidak meniru identitas visual resmi DeepSeek,
dan tidak mendeskripsikan status katalog sebagai sertifikasi resmi. Referensi ke DeepSeek
Harness dan DSH hanya mengidentifikasi target kompatibilitas.

Nama plugin, nama proyek, logo, tangkapan layar, kode, dan dokumentasi adalah milik pemiliknya
masing-masing dan tetap tunduk pada lisensi asli dan kebijakan merek dagangnya.
