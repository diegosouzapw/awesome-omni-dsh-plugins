# Sifa za Muumba na Kipaumbele cha Pull Request

> 🌐 [English](../../CREDIT.md) · [Português (Brasil)](../pt-BR/CREDIT.md) · [中文（简体）](../zh-CN/CREDIT.md) · **Kiswahili**

Katalogi ipo ili kuifanya kazi huru ya DSH igundulike bila kuchukua umiliki kutoka kwa waumbaji wake.
Viingilio vya umma vinataja hazina asili na commit ya chanzo isiyobadilika.

## Kipaumbele kwa programu-jalizi moja

<!-- creator-first:direct-pr-supersedes-curation-and-automation -->

1. Pull request iliyofunguliwa na muumba wa programu-jalizi au shirika linalomiliki.
2. Pull request ya jamii iliyoidhinishwa au kuandikwa pamoja wazi na muumba.
3. Pull request halali ya jamii iliyopo.
4. Pull request ya otomatiki ya katalogi.
5. Mgombea binafsi asiye na pull request ya umma.

Pull request ya moja kwa moja ya muumba daima inapendelewa na inachukua nafasi ya pull request yoyote
wazi ya ukusanyaji wa jamii au otomatiki kwa programu-jalizi moja rasmi hiyo hiyo, bila kujali ipi
iliyofunguliwa kwanza au ipi iliyo mbali zaidi. Pull request ya muumba inakuwa chombo cha ukaguzi;
tawi lao kamwe halifutwi, halifanyiwi force-push wala kuhamishiwa kwenye pull request ya ukusanyaji.
Ikiwa kiingilio cha ukusanyaji tayari kimeunganishwa, historia inabaki kamili na muumba anaweza
kukidai au kukirekebisha katika mchango mpya.

## Utambuzi wa umma

Kila kiingilio cha katalogi hubeba handle ya umma ya GitHub ya muumba, hazina asili, ID ya node ya
hazina, subpath ya programu-jalizi na commit kamili iliyobandikwa. Wasifu ya umma ya muumba hutokana
na handle moja badala ya kuhifadhiwa kama utambulisho wa pili. Lango tofauti la asili la wasimamizi
hutatua ID ya node na kukataa kutolingana kwa URL ya hazina. Maelezo ya pull request yanapaswa kusema
`Created by @handle` na kujumuisha metadata ya hazina ya chanzo na commit ya chanzo.

Mtu anayechapisha au kuandika maoni kwenye Discussion hachukuliwi kiotomatiki kuwa muumba. Umiliki
lazima uungwe mkono na mmiliki wa hazina au shirika, uandishi wa kifurushi, metadata ya manifest au
historia halisi ya chanzo kilichobandikwa.

## Utambulisho wa Git

<!-- creator-first:source-bound-git-identity -->

Uandishi wa commit na uandishi wa pull request ni tofauti. Pull request inayotoka kwa muumba humweka
muumba kama mwandishi wa pull request, na commits zao huhifadhi uandishi kwa asili. Akaunti ya
msimamizi au otomatiki inaweza kuonekana kama committer au kama co-author iliyothibitishwa, lakini
lazima isichukue nafasi ya uandishi wa muumba.

Kwa commit ya ukusanyaji, tumia muumba kama mwandishi wa Git au ongeza trailer ya `Co-authored-by`
tu wakati utambulisho halisi umefungwa kwa chanzo na unaweza kuthibitishwa hadharani, kama vile
utambulisho ambao tayari umeunganishwa kwenye commit ya muumba katika hazina asili. Kamwe usikisie
barua pepe, usitengeneze anwani ya noreply au kutumia anwani ya faragha iliyopatikana nje ya chanzo
cha umma kilichoidhinishwa.

Wakati utambulisho wa Git uliothibitishwa haupatikani, mkusanya au akaunti ya otomatiki ndiyo
huandika commit na badala yake kutoa sifa za wazi zinazoonekana: `Created by @handle`, wasifu ya umma
inayolingana na kiungo cha hazina asili katika kiingilio na pull request. Utambuzi wa YAML unaonekana
daima unahitajika bila kujali ramani ya utambulisho wa Git. Pull request ya moja kwa moja ya muumba
inayokuja baadaye inachukua nafasi ya pull request wazi ya ukusanyaji badala ya kurithi historia yake
bandia.

## Mtajo wa heshima wa muumba

Pull request ya ukusanyaji hutumia mtajo mmoja wa heshima wa umma wa `@creator` katika maelezo yake
kando ya kiungo cha hazina asili. Inaweza kualika ukaguzi au pull request mbadala ya moja kwa moja.
Usirudie mtajo, usifungue masuala ya matangazo, usichapishe mtandaoni kwa sehemu nyingine
au kutuma ujumbe wa moja kwa moja usioombwa.

## Leseni ya katalogi dhidi ya leseni ya upstream

Ukweli wa katalogi na metadata ya uhariri ya YAML zimewekwa wakfu chini ya CC0-1.0. Uwekaji huo wakfu
haubadilishi leseni ya programu-jalizi ya upstream. Msimbo wa upstream, nyaraka, picha za skrini,
nembo na nyenzo nyingine za ubunifu zinabaki chini ya leseni na wamiliki wao wa asili.
