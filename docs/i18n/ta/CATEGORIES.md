# பட்டியல் வகைகள்

ஒவ்வொரு பட்டியல் பதிவும் ஒரு கலைப்படைப்பு வகை, ஒரு முதன்மை திறன் வகை மற்றும் பூச்சியம் அல்லது
அதற்கு மேற்பட்ட குறிச்சொற்களைக் கொண்டுள்ளது. முதன்மை வகை பதிவு எங்கு தோன்றும் என்பதை
தீர்மானிக்கிறது; குறிச்சொற்கள் பதிவை நகலெடுக்காமல் வகைகளுக்குக் குறுக்கே தேடலை வழங்குகின்றன.

## கலைப்படைப்பு வகைகள்

<!-- catalog-policy:aggregators-never-entries -->

| மதிப்பு | பொருள் | செருகுநிரலாக நட்சத்திர தரவரிசையில் |
|---|---|---:|
| `plugin` | நிறுவக்கூடிய சொந்த DSH தொகுப்பு | ஒவ்வொரு தரவரிசை நிபந்தனையும் பூர்த்தி செய்யப்படும்போது மட்டுமே |
| `plugin-family` | பல DSH செருகுநிரல்களைக் கொண்ட களஞ்சியம் | இல்லை; தனிப் பிரிவு |
| `skin-theme` | DSH UI ஸ்கின் அல்லது காட்சி தீம் | இல்லை; தனிப் பிரிவு |
| `skill` | DSH ஆதரவு கொண்ட முகவர் திறன் | இல்லை |
| `preset-profile` | DSH சுயவிவரம் அல்லது முன்னமைவு | இல்லை |
| `client-interface` | டெஸ்க்டாப், TUI, திருத்தி அல்லது தொலை கிளையன்ட் | இல்லை |
| `bridge-adapter` | வேறொரு தயாரிப்பிலிருந்து DSH-க்கான ஒருங்கிணைப்பு | இல்லை |
| `ecosystem-project` | DSH ஒருங்கிணைப்பைக் கொண்ட பரந்த திட்டம் | இல்லை |

ஒரு குடைக் களஞ்சியம், திரட்டி, சந்தை, நிறுவி பட்டியல் அல்லது பட்டியல் ஒருபோதும் பட்டியல்
பதிவாகாது, அந்தத் திரட்டியே நிறுவக்கூடியதாக இருந்தாலும் சரி. அதைத் தடயமாக மட்டுமே
பயன்படுத்த முடியும். ஒவ்வொரு தடயத்தையும் சுயாதீனமாக நிறுவக்கூடிய சேய் கலைப்படைப்பு வரை
பின்தொடர்ந்து, அதைச் சமர்ப்பிக்கும் முன் அந்தக் கலைப்படைப்பின் உண்மையான படைப்பாளர், அசல்
களஞ்சியம், தொகுப்பு மற்றும் மூலத் துணைப்பாதையைத் தீர்க்கவும். படைப்பாளரின் உண்மையான
மோனோரெப்போ ஒரு சேய் செருகுநிரலின் அசல் களஞ்சியமாக இருக்கலாம், ஆனால் சேய் அந்தச் சரியான
துணைப்பாதையையும் மோனோரெப்போ நட்சத்திரக் கொள்கையையும் பயன்படுத்த வேண்டும்.

`kind` புலமே அதிகாரப்பூர்வ DSH கலைப்படைப்பு பாகுபடுத்தி. தனி ஒருங்கிணைப்பு வகை எதுவும்
இல்லை: `plugin` ஏற்கனவே சொந்த DSH தொகுப்பு என்று பொருள்படுகிறது, அதேபோல்
`ecosystem-project` ஏற்கனவே DSH ஒருங்கிணைப்பு கொண்ட பரந்த திட்டம் என்று பொருள்படுகிறது.
இது முரண்பாடான வகைப்படுத்தல் ஜோடிகளைத் தடுக்கிறது.

தென்படும் தன்மையை அதிகரிக்கக்கூடிய வகையை அல்ல.

## இடைமுகக் குறிச்சொற்கள்

நிலையான இடைமுகக் குறிச்சொற்களில் `web-ui`, `sidebar`, `settings`, `tui`, `cli`, `desktop`,
`mobile`, `remote`, `editor`, `headless` மற்றும் `theme` ஆகியவை அடங்கும். பின்னிணைக்கப்பட்ட
அசல் மூலத்தில் காணக்கூடிய ஆதாரத்தை விவரிக்கும்போது கூடுதல் சிறியெழுத்து kebab-case திறன்
குறிச்சொற்கள் அனுமதிக்கப்படுகின்றன.

## களஞ்சிய நோக்கு

களஞ்சிய நட்சத்திரங்கள் பட்டியலிடப்பட்ட சரியான செருகுநிரலுக்குச் சொந்தமானவையாக
இருக்கும்போது மட்டுமே `dedicated` பயன்படுத்தவும். செருகுநிரல் ஒரு பரந்த திட்டத்திற்குள்
துணைப்பாதை அல்லது தொகுப்பாக இருக்கும்போது `monorepo` பயன்படுத்தவும். ஒரு மோனோரெப்போ பதிவு
`popularity.starsPolicy: undefined-parent-repository` மற்றும் `popularity.stars: null`
பயன்படுத்த வேண்டும்.
