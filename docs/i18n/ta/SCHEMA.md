# பட்டியல் பதிவு திட்டவரைவு குறிப்பு

> 🌐 [English](../../SCHEMA.md) · [Português (Brasil)](../pt-BR/SCHEMA.md) · [中文（简体）](../zh-CN/SCHEMA.md) · **தமிழ்**

> **அதிகாரப்பூர்வமற்ற சமூகத் திட்டம். DeepSeek உடன் இணைப்போ, ஏற்புடையதோ, ஆதரவு பெற்றதோ அல்ல.**
> DeepSeek பெயர்களும் குறியீடுகளும் அவற்றின் உரிமையாளருக்கே சொந்தமானவை.

இது [`schemas/plugin.schema.yaml`](../../schemas/plugin.schema.yaml)-இன் புலம்-வாரி குறிப்பு,
`catalog/plugins/` கீழ் உள்ள ஒவ்வொரு கோப்பும் பூர்த்தி செய்ய வேண்டிய பொது JSON Schema
(draft 2020-12). திட்டவரைவுக் கோப்பே உண்மையின் மூலம்; இந்தப் பக்கமும் திட்டவரைவும்
முரண்படும்போது, திட்டவரைவே வெல்கிறது.

இரண்டு அடுக்கு சரிபார்ப்பு பொருந்தும். பொது திட்டவரைவு வரம்புடைய *பாதுகாப்பான வடிவங்களை*
அமல்படுத்துகிறது (விருப்பம்-போன்ற அல்லது வரம்பற்ற மதிப்புகளை நிராகரிக்கும் முறைகள் மற்றும்
நீளங்கள்). அதன் மீது, `catalog validate` கட்டாய சொற்பொருள் பாகுபடுத்திகளைப்
பயன்படுத்துகிறது: பதிப்புகளுக்குச் சரியான SemVer, ஒருமைப்பாட்டு மதிப்புகளுக்கு SHA-512 SRI,
உரிமங்களுக்கு SPDX கோவை பாகுபடுத்தல், மற்றும் நகல்-விசை நிராகரிப்பு. ஒரு மதிப்பு திட்டவரைவு
முறையுடன் பொருந்தியும் சொற்பொருள் ரீதியாக நிராகரிக்கப்படலாம்.

மேல்நிலை விதிகள்: பதிவு ஒரே ஒரு YAML பொருள், `additionalProperties: false`
(தெரியாத புலங்கள் நிராகரிக்கப்படும்), மேலும் கீழே உள்ள அனைத்து புலங்களும் கட்டாயம் — ஒரே
விருப்பப் புலமான `media` தவிர.

## உயர்மட்டப் புலங்கள்

| புலம்             | வகை    | தேவை | சுருக்கம்                                                       |
| ----------------- | ------- | :------: | ------------------------------------------------------------- |
| `schemaVersion`   | const   |   ஆம்    | சரியாக `1` ஆக இருக்க வேண்டும்                                           |
| `id`              | string  |   ஆம்    | சிறியெழுத்து kebab-case பதிவு ID; கோப்புப் பெயருடன் பொருந்த வேண்டும்        |
| `name`            | string  |   ஆம்    | காட்சிப் பெயர், 1–120 எழுத்துகள்                                |
| `description`     | object  |   ஆம்    | க்யூரேட் செய்யப்பட்ட ஆங்கில சுருக்கம் மற்றும் அதன் ஆதாரப் பாதை                |
| `unofficial`      | const   |   ஆம்    | சரியாக `true` ஆக இருக்க வேண்டும்                                        |
| `kind`            | enum    |   ஆம்    | அதிகாரப்பூர்வ கலைப்படைப்பு பாகுபடுத்தி                              |
| `primaryCategory` | enum    |   ஆம்    | ஒற்றை முதன்மை திறன் வகை                            |
| `tags`            | array   |   ஆம்    | தனித்துவமான சிறியெழுத்து kebab-case குறிச்சொற்கள் (காலியாக இருக்கலாம்)               |
| `source`          | object  |   ஆம்    | அசல் களஞ்சியம், நோட் ID, துணைப்பாதை மற்றும் பின்னிணைக்கப்பட்ட commit       |
| `creator`         | object  |   ஆம்    | படைப்பாளரின் பொது GitHub ஹேண்டில்                                |
| `package`         | object  |   ஆம்    | அதிகாரப்பூர்வ நிறுவல் விவரிப்பான் (npm **அல்லது** மூலம்)              |
| `dsh`             | object  |   ஆம்    | DSH சுயவிவரங்கள் மற்றும் சொந்த-ஒருங்கிணைப்பு ஆதாரப் பாதை             |
| `repositoryScope` | enum    |   ஆம்    | `dedicated` அல்லது `monorepo`                                     |
| `popularity`      | object  |   ஆம்    | நட்சத்திரக் கொள்கை மற்றும் நட்சத்திர எண்ணிக்கை (நோக்கத்தைப் பொறுத்து)            |
| `license`         | object  |   ஆம்    | மேல்நீரோட்ட SPDX உரிமக் கோவை                              |
| `verification`    | object  |   ஆம்    | சரிபார்ப்பு நிலை, சோதனை நேரம், அடையாளம் மற்றும் புகை சோதனை      |
| `provenance`      | object  |   ஆம்    | பொது Discussion/கருத்து URL-கள் அல்லது `null`                      |
| `media`           | array   |    இல்லை    | அதிகபட்சம் 6 திரைப்பிடிப்பு/வீடியோ, ஒவ்வொரு URL-உம் `source.commit`-இல் நிலைநிறுத்தப்படும் |

### `schemaVersion`

மாறிலி `1`. பொது திட்டவரைவு பதிப்பு 1-ஐ அடையாளம் காட்டுகிறது; வேறு எந்த மதிப்பும்
செல்லுபடியாகாது.

### `id`

`^[a-z0-9]+(?:-[a-z0-9]+)*$`-உடன் பொருந்தும் சரம் — சிறியெழுத்து kebab-case, முன்னிலை/பின்னிலை
அல்லது இரட்டை ஹைஃபன்கள் இல்லை. [CONTRIBUTING.md](../../CONTRIBUTING.md)-இன்படி, பதிவுக்
கோப்பு `catalog/plugins/<id>.yaml` என ஒரே மதிப்புடன் பெயரிடப்பட வேண்டும்; சரிபார்ப்பான்
பொருத்தமின்மையை நிராகரிக்கிறது (`id-filename-mismatch`). ID படைப்பாளரின் பெயர்வெளியுடனும்
தொடங்க வேண்டும்: `creator.github` ஹேண்டில் சிறியெழுத்தில், `[a-z0-9]` வெளியே உள்ள ஒவ்வொரு
எழுத்துத் தொடரும் ஒற்றை `-` ஆகச் சுருக்கப்பட்டு, பின்னர் `-` (`id-creator-prefix`).

### `name`

இலவச வடிவக் காட்சிப் பெயர், `minLength: 1`, `maxLength: 120`.

### `description`

சரியாக இரண்டு தேவையான பண்புகளைக் கொண்ட பொருள் (வேறு எதுவும் அனுமதிக்கப்படாது):

| பண்பு       | வகை   | விதிகள்                                                                 |
| -------------- | ------ | --------------------------------------------------------------------- |
| `en`           | string | ஆங்கில சுருக்கம், 20–320 எழுத்துகள்                                    |
| `evidencePath` | string | தொடர்புடைய களஞ்சியப் பாதை முறை; முன்னிலை `/` இல்லை, பின்சாய்வுகள் இல்லை, `.`/`..` பிரிவுகள் இல்லை |

ஆங்கில சுருக்கம் `source.commit`-இல் உள்ளபடி `evidencePath`-இல் உள்ள கோப்பிலிருந்து க்யூரேட்
செய்யப்பட வேண்டும் — வேறொரு பட்டியலிலிருந்து நகலெடுக்கப்படக்கூடாது.

### `unofficial`

மாறிலி `true`. பட்டியல் அதிகாரப்பூர்வமற்றது என்பதற்கான இயந்திர-படிக்கக்கூடிய குறி.

### `kind`

கலைப்படைப்பு வகையின் **ஒரே** பாகுபடுத்தி (இரண்டாவது ஒருங்கிணைப்பு-வகைப் புலம் இல்லை).
இவற்றில் ஒன்று:

`plugin` · `plugin-family` · `skin-theme` · `skill` · `preset-profile` · `client-interface` ·
`bridge-adapter` · `ecosystem-project`

பொருட்கள் மற்றும் தரவரிசை விளைவுகள் [docs/CATEGORIES.md](../../docs/CATEGORIES.md)-இல்
வரையறுக்கப்பட்டுள்ளன.

### `primaryCategory`

பதினான்கு திறன் வகைகளில் ஒன்று:

`user-interface-dashboards` · `memory-rag` · `search-research` · `coding-developer-tools` ·
`browser-automation` · `vision-audio-multimodal` · `sessions-productivity` ·
`security-permissions-approvals` · `diagnostics-observability` · `models-providers-routing` ·
`messaging-notifications` · `data-external-services` · `entertainment-customization` · `finance-trading`

காட்சி பெயரிடல்களும் தேர்வு வழிகாட்டுதலும்
[docs/CATEGORIES.md](../../docs/CATEGORIES.md)-இல் உள்ளன.

### `tags`

தனித்துவமான சரங்களின் வரிசை, ஒவ்வொன்றும் `^[a-z0-9]+(?:-[a-z0-9]+)*$`-உடன் பொருந்தும்
(சிறியெழுத்து kebab-case). திட்டவரைவு குறைந்தபட்ச எண்ணிக்கையை விதிப்பதில்லை.

### `source`

சரியாக நான்கு தேவையான பண்புகளைக் கொண்ட பொருள்:

| பண்பு           | வகை           | விதிகள்                                                                  |
| ------------------ | -------------- | ---------------------------------------------------------------------- |
| `repository`       | string         | `https://github.com/<owner>/<repo>` URL; owner GitHub பயனர்பெயர் விதிகளைப் பின்பற்றுகிறது, களஞ்சியப் பெயர் 1–100 எழுத்துகள், `.`/`..` ஆக இருக்கக்கூடாது அல்லது `.git`-இல் முடியக்கூடாது |
| `repositoryNodeId` | string         | மாறாத GitHub களஞ்சிய நோட் ID, காலியாகாதது                         |
| `subpath`          | string அல்லது null | களஞ்சியத்திற்குள் செருகுநிரல் துணைப்பாதை (`evidencePath` போன்ற அதே பாதுகாப்பான தொடர்புடைய-பாதை முறை), அல்லது களஞ்சிய-மூல செருகுநிரலுக்கு `null` |
| `commit`           | string         | முழு 40-எழுத்து ஹெக்சாடெசிமல் commit OID                               |

பட்டியல் சரிபார்ப்பு `repositoryNodeId`-ஐத் தீர்த்து, களஞ்சிய URL பொருத்தமின்மையை
நிராகரிக்க வேண்டும் — அந்தத் தீர்வு பராமரிப்பாளர்-பக்க நுழைவாயில், உள்ளூர் கட்டமைப்புச்
சோதனையின் பகுதி அல்ல.

### `creator`

ஒற்றை தேவையான பண்பைக் கொண்ட பொருள்:

| பண்பு | வகை   | விதிகள்                                             |
| -------- | ------ | ------------------------------------------------- |
| `github` | string | GitHub பயனர்பெயர் (1–39 எழுத்துகள், GitHub ஹேண்டில் விதிகள்) |

பொது சுயவிவர URL எப்போதும் `https://github.com/<handle>` என வருவிக்கப்படுகிறது; இரண்டாவது
சுயவிவரப் புலம் சேமிக்கப்படாததால், இரண்டும் ஒருபோதும் வேறுபட முடியாது.

### `package`

அதிகாரப்பூர்வ நிறுவல் விவரிப்பான். இது தரவு, ஒருபோதும் ஷெல் கட்டளை அல்ல, மேலும் இரண்டு
வடிவங்களில் சரியாக ஒன்றை எடுக்கிறது (`oneOf`):

**npm தொகுப்பு** — தேவை `ecosystem`, `name`, `version`; விருப்ப `integrity`:

| பண்பு    | வகை  | விதிகள்                                                                      |
| ----------- | ----- | -------------------------------------------------------------------------- |
| `ecosystem` | const | `npm`                                                                      |
| `name`      | string | npm தொகுப்புப் பெயர் வடிவம் (விருப்பமாக scope செய்யப்பட்ட), அதிகபட்சம் 214 எழுத்துகள்                 |
| `version`   | string | சரியான `x.y.z` பதிப்பு வடிவம் (விருப்ப prerelease/build); வரம்புகள் நிராகரிக்கப்படுகின்றன. சொற்பொருள் அடுக்கு கூடுதலாகப் பாகுபடுத்தக்கூடிய, சரியான SemVer-ஐக் கோருகிறது |
| `integrity` | string | விருப்ப `sha512-…` SRI வடிவம், 8–256 எழுத்துகள். சொற்பொருள் அடுக்கு அதைச் செல்லுபடியாகும் SHA-512 SRI ஆகப் பாகுபடுத்த வேண்டும் |

**மூல நிறுவல்** — `ecosystem` மட்டுமே தேவை:

| பண்பு    | வகை  | விதிகள்    |
| ----------- | ----- | -------- |
| `ecosystem` | const | `source` |

ஒரு மூல விவரிப்பான் வேண்டுமென்றே வேறு எதையும் சேமிப்பதில்லை: களஞ்சியம், commit மற்றும்
துணைப்பாதை `source`-இலிருந்து வருவிக்கப்படுவதால், மாறக்கூடிய மதிப்புகள் ஒருபோதும்
நகலெடுக்கப்படாது.

### `dsh`

சொந்த DSH ஒருங்கிணைப்பு ஆதாரம்:

| பண்பு       | வகை   | விதிகள்                                                          |
| -------------- | ------ | -------------------------------------------------------------- |
| `profiles`     | array  | `^[A-Za-z0-9][A-Za-z0-9._-]*$`-உடன் பொருந்தும் குறைந்தது ஒரு தனித்துவமான சுயவிவரப் பெயர் |
| `evidencePath` | string | `source.commit`-இல் DSH ஒருங்கிணைப்பு ஆதாரத்திற்கான பாதுகாப்பான தொடர்புடைய பாதை |

### `repositoryScope`

`dedicated` (களஞ்சிய நட்சத்திரங்கள் இந்தச் சரியான செருகுநிரலுக்குச் சொந்தமானவை) அல்லது
`monorepo` (செருகுநிரல் ஒரு பரந்த திட்டத்திற்குள் துணைப்பாதை அல்லது தொகுப்பு). இந்த மதிப்பு
கீழே உள்ள நிபந்தனை பிரபல விதிகளை இயக்குகிறது.

### `popularity`

| பண்பு     | வகை            | விதிகள்                                                |
| ------------ | --------------- | ---------------------------------------------------- |
| `starsPolicy`| enum            | `exact-repository` அல்லது `undefined-parent-repository`  |
| `stars`      | integer அல்லது null | எதிர்மறையல்லாத முழு எண், அல்லது `null`                      |

நிபந்தனை விதிகள் (திட்டவரைவின் `allOf` தொகுதிகளால் அமல்படுத்தப்படுகின்றன):

- `repositoryScope: monorepo` `starsPolicy: undefined-parent-repository` மற்றும்
  `stars: null`-ஐ **கட்டாயப்படுத்துகிறது**. தாய்த் திட்ட நட்சத்திரங்கள் ஒருபோதும் மோனோரெப்போ
  செருகுநிரலுக்கு வழங்கப்படாது.
- `repositoryScope: dedicated` `starsPolicy: exact-repository` மற்றும் முழு எண்
  `stars >= 0`-ஐ **கட்டாயப்படுத்துகிறது**.

இந்த மதிப்புகள் தரவரிசை நிபந்தனைக்கு எவ்வாறு உள்ளீடாகின்றன என்பதற்கு
[docs/RANKING.md](../../docs/RANKING.md) பார்க்கவும்.

### `license`

| பண்பு | வகை   | விதிகள்                                                          |
| -------- | ------ | -------------------------------------------------------------- |
| `spdx`   | string | SPDX கோவை வடிவம், 2–256 எழுத்துகள், முன்னிலை ஹைஃபன் இல்லை          |

திட்டவரைவு பாதுகாப்பான எழுத்து வடிவத்தை மட்டுமே அமல்படுத்துகிறது; பட்டியல் சரிபார்ப்பு
மதிப்பை உண்மையான SPDX கோவை பாகுபடுத்தியால் பாகுபடுத்தி இயல்பாக்க வேண்டும். பின்னிணைக்கப்பட்ட
commit-இல் ஆதாரப்படுத்தப்பட்ட முழுமையான மேல்நீரோட்டக் கோவையைப் பதிவு செய்யவும்
(எடுத்துக்காட்டாக `Apache-2.0` அல்லது `MIT OR GPL-3.0-only`).

### `verification`

சரிபார்ப்பு `source.commit`-க்குப் பொருந்தும். நான்கு தேவையான பண்புகளைக் கொண்ட பொருள்:

| பண்பு             | வகை           | விதிகள்                                                  |
| -------------------- | -------------- | ------------------------------------------------------ |
| `status`             | enum           | `eligible` · `verified` · `stale` · `unavailable` · `archived` · `quarantined` |
| `checkedAt`          | string         | சோதனையின் `date-time` வடிவ நேரமுத்திரை           |
| `repositoryIdentity` | const          | `resolved` ஆக இருக்க வேண்டும்                                     |
| `smokeTest`          | object அல்லது null | புகை சோதனை பதிவு, அல்லது தகுதியான சோதனை இல்லாதபோது `null` |

இருக்கும்போது, `smokeTest` கோருகிறது:

| பண்பு        | வகை   | விதிகள்                                                             |
| --------------- | ------ | ----------------------------------------------------------------- |
| `installTarget` | const  | `canonical-install-descriptor` — மாறக்கூடிய மதிப்புகளை நகலெடுக்காமல் `package` அல்லது பின்னிணைக்கப்பட்ட மூலத்தைக் குறிக்கிறது |
| `check`         | object | தேவையான `name` (தொகுப்பு-பெயர் வடிவம்) மற்றும் `version` (சரியான பதிப்பு வடிவம்) |
| `result`        | const  | `passed` — தோல்வியுற்ற புகை சோதனை புகை சோதனையாகப் பதிவு செய்யப்படாது    |

நிபந்தனை விதி: `status: verified` காலியல்லாத `smokeTest` பொருளை **கோருகிறது**. மதிப்பாய்வு
செய்யக்கூடிய புகை ஆதாரம் இல்லாத பதிவுகள் `status: eligible` மற்றும் `smokeTest: null`
பயன்படுத்துகின்றன. எந்த நிலையும் ஏற்பு அல்லது பாதுகாப்புச் சான்றிதழ் அல்ல —
[docs/RANKING.md](../../docs/RANKING.md) பார்க்கவும்.

### `provenance`

பொது மரபுரிமை இணைப்புகள், ஒவ்வொன்றும் URI அல்லது `null`:

| பண்பு     | வகை          | விதிகள்                                            |
| ------------ | ------------- | ------------------------------------------------ |
| `discussion` | string அல்லது null | இருக்கும்போது பொது Discussion URL            |
| `comment`    | string அல்லது null | இருக்கும்போது பொது கருத்து URL               |

### `media`

ஒரே விருப்பப் புலம். அதிகபட்சம் **6** உருப்படிகள் கொண்ட வரிசை; ஒவ்வொன்றும் செருகுநிரலின் ஒரு திரைப்பிடிப்பையோ ஒரு குறும் வீடியோவையோ விவரிக்கிறது:

| பண்பு | வகை | விதிகள் |
| -------- | ------ | ----- |
| `kind`   | enum   | `screenshot` அல்லது `video` |
| `url`    | string | மாறாத GitHub URL, அதிகபட்சம் 2048 எழுத்துகள் (கீழே காண்க) |
| `alt`    | string | மாற்று உரை, 1–120 எழுத்துகள் |

இங்குள்ள URL `source.commit` அளவுக்கே மாறாததாக இருக்க வேண்டும். கிளையின் பெயரைக் கொண்ட
`raw.githubusercontent.com` பாதை (`.../main/docs/shot.png`) அந்தக் கிளை இன்று வைத்திருப்பதைக்
காட்டும்; எனவே கிளை நகரும் நாளில் பதிவு பரிசீலிக்கப்படாத படத்தை வெளியிட்டுவிடும். இரண்டு வடிவங்களே
ஏற்கப்படுகின்றன:

- `https://raw.githubusercontent.com/<owner>/<repo>/<commit>/<path>` — கமிட்டில் நிலைநிறுத்தப்பட்ட raw பாதை;
- `https://github.com/<owner>/<repo>/assets/…` — GitHub-இன் உள்ளடக்க முகவரியிடப்பட்ட பதிவேற்ற URL, `video` உருப்படிகளுக்கு.

ஸ்கீமா பாதுகாப்பான வடிவத்தை மட்டுமே கட்டாயப்படுத்துகிறது (ஹோஸ்ட், 40 எழுத்து ஹெக்ஸாடெசிமல்
குறிப்பு, வரம்பிட்ட நீளம்). மீதியை `catalog validate` பொருள் அளவில் கட்டாயப்படுத்துகிறது: URL
**பதிவின் சொந்த** களஞ்சியத்தில் **பதிவின் சொந்த** `source.commit`-ஐ நிலைநிறுத்த வேண்டும், கிளை URL
`media[n].url must pin the entry commit, not a branch` என நிராகரிக்கப்படும்.

காட்ட ஒன்றும் இல்லாதபோது புலத்தை முழுவதுமாக விட்டுவிடுங்கள் — `media: []` என்பது "திரைப்பிடிப்புகள்
இல்லை" எனச் சொல்லும் செல்லுபடியான வழி அல்ல. இப்புலம் கூட்டல் தன்மையுடையது: இது இருப்பதற்கு முன்பு
வெளியிடப்பட்ட பதிவுகள் செல்லுபடியாகவே இருக்கும், இதைப் புறக்கணிக்கும் நுகர்வோர் ஒவ்வொரு பதிவையும்
முன்பு போலவே படிப்பார்.

## `kind: skill` பதிவுகள்

திட்டவரைவு பதிப்பு 1, `kind: skill`-க்கான இரண்டாவது, தன்னிறைவான பதிவு ஒப்பந்தத்தையும்
வரையறுக்கிறது; அது [`schemas/skill.schema.yaml`](../../schemas/skill.schema.yaml) ஆக
வெளியிடப்பட்டுள்ளது (SKL-01 கட்டம் 0). இது மேலே உள்ள செருகுநிரல் திட்டவரைவை ஒருபோதும்
தொடுவதில்லை: `kind: plugin` கொண்ட பதிவுகள் முன்பு போலவே சரிபார்க்கப்படுகின்றன, மேலும்
செருகுநிரல் திட்டவரைவு செருகுநிரல் பதிவுகளுக்கு எப்படியோ அப்படியே skill திட்டவரைவுக்
கோப்பு skill பதிவுகளுக்கு உண்மையின் மூலம்.

ஒரு skill நிறுவப்படுவதில்லை, அது ஹார்னெஸால் **ஏற்றப்படுகிறது**; எனவே செருகுநிரலுக்கு
மட்டுமே உரிய நிறுவல் விவரிப்பான்கள் (`package`, `dsh`) skill பதிவில் இல்லை, அவற்றுக்குப்
பதிலாக `usage` + `compat` உள்ளன. ஒரு skill பல skill-களை வைத்திருக்கும் களஞ்சியத்தின் துணை
அடைவில் அடிக்கடி வாழ்கிறது; எனவே அடையாளமும் நகல்நீக்கமும் களஞ்சியம் மட்டுமன்றி
`source.repository` + `source.subpath` ஆகும். skill பதிவு `media` காட்சியகத்தை
அனுமதிப்பதில்லை: skill என்பது ஹார்னெஸ் ஏற்றும் உரை; எனவே திரைப்பிடிக்க எதுவும் இல்லை
(`additionalProperties: false` தான் இதை அமல்படுத்துகிறது).

இந்தப் புலங்கள் மேலே செருகுநிரல் பதிவுகளுக்கு ஆவணப்படுத்தப்பட்ட வடிவத்தையும் விதிகளையும்
அப்படியே வைத்திருக்கின்றன: `schemaVersion`, `id`, `name`, `description`, `unofficial`,
`primaryCategory`, `tags`, `source`, `creator`, `repositoryScope`, `license`, `provenance`.
ஒரே விருப்ப skill புலமான `triggers` தவிர ஒவ்வொரு புலமும் கட்டாயம்.

### skill-க்குரிய புலங்கள்

| புலம்             | வகை    | தேவை | விதிகள்                                                       |
| -------------------- | ------ | :------: | ----------------------------------------------------------- |
| `kind`               | const  |   ஆம்    | சரியாக `skill` ஆக இருக்க வேண்டும்                                     |
| `skillScope`         | enum   |   ஆம்    | `repository` (முழு களஞ்சியமும் skill **ஆகும்**) அல்லது `subdirectory` (skill `source.subpath`-இல் வாழ்கிறது) |
| `triggers`           | array  |    இல்லை    | skill எப்போது தூண்டப்படுகிறது — ஏற்றுவதற்கு முன் பயனர் மதிப்பிடும் உரை. குறைந்தது 1 தனித்துவமான சரம், ஒவ்வொன்றும் 3–200 எழுத்துகள்; எதுவும் இல்லாதபோது புலத்தை முழுவதுமாக விட்டுவிடுங்கள் (`triggers: []` செல்லாது) |
| `usage.load`         | string |   ஆம்    | ஹார்னெஸ் skill-ஐ எப்படி ஏற்றுகிறது, 1–200 எழுத்துகள்; skill ஏற்றப்படுகிறது, ஒருபோதும் நிறுவப்படுவதில்லை |
| `usage.evidencePath` | string |   ஆம்    | `source.commit`-இல் ஏற்றல் ஆதாரத்திற்கான பாதுகாப்பான தொடர்புடைய பாதை (`description.evidencePath` போன்ற அதே முறை) |
| `compat.harnessMin`  | string |   ஆம்    | skill சரிபார்க்கப்பட்ட குறைந்தபட்ச ஹார்னெஸ் பதிப்பு; சரியான `x.y.z` வடிவம் (விருப்ப prerelease/build), அதிகபட்சம் 64 எழுத்துகள். சொற்பொருள் அடுக்கு கூடுதலாகப் பாகுபடுத்தக்கூடிய, சரியான SemVer-ஐக் கோருகிறது |

நிபந்தனை விதிகள் (skill திட்டவரைவின் `allOf` தொகுதிகளால் அமல்படுத்தப்படுகின்றன):

- `skillScope: subdirectory` `source.subpath` ஒரு பாதுகாப்பான தொடர்புடைய-பாதை சரமாக இருக்க
  வேண்டும் என **கட்டாயப்படுத்துகிறது** — துணை அடைவில் வாழும் skill அந்தத் துணை அடைவைப்
  பின்னிணைக்க வேண்டும்.
- `skillScope: repository` `source.subpath: null`-ஐ **கட்டாயப்படுத்துகிறது** — முழு-களஞ்சிய
  skill துணைப்பாதையை அறிவிக்கக்கூடாது.

`verification` செருகுநிரல் வடிவத்தையே (`status`, `checkedAt`, `repositoryIdentity`,
`smokeTest`) வைத்திருக்கிறது, ஆனால் `smokeTest` சரியாக `null` ஆக இருக்க வேண்டும்: skill-க்கு
நிறுவல் புகை சோதனை இல்லை; உள்ளடக்க மதிப்பாய்வே அனுமதி நுழைவாயில். skill திட்டவரைவில்
`status: verified` → `smokeTest` நிபந்தனையும் `repositoryScope` → `popularity`
நிபந்தனைகளும் இல்லை; அந்த இணைப்புகள் செருகுநிரல்-திட்டவரைவு விதிகள் மட்டுமே.

### skill-களுக்கான சொற்பொருள் அடுக்கு

திட்டவரைவின் மீது, புலங்கள் இருக்கும் இடங்களில் பட்டியல் சரிபார்ப்பு செருகுநிரல்களுக்குப்
பயன்படுத்தும் அதே கட்டாய சொற்பொருள் பாகுபடுத்திகளையே பயன்படுத்துகிறது: `license.spdx`
செல்லுபடியாகும் SPDX கோவையாகப் பாகுபடுத்தப்பட வேண்டும் (`invalid-spdx`), மேலும்
`compat.harnessMin` சரியான SemVer ஆக இருக்க வேண்டும் (`invalid-semver`). `invalid-sri`
நிகழ்வு இல்லை — skill-க்கு `package.integrity` இல்லை.

### skill அடையாளமும் நகல்நீக்கமும்

ஒரு skill-இன் அதிகாரப்பூர்வ விசை `skill:<source.repositoryNodeId>:<normalized subpath>`.
துணைப்பாதை அடையாள நோக்கங்களுக்காக மட்டுமே இயல்பாக்கப்படுகிறது: பின்சாய்வுகள் `/`
ஆகின்றன, காலி மற்றும் `.` பிரிவுகள் நீக்கப்படுகின்றன, காலி முடிவு (அல்லது `subpath: null`)
`.` ஆகிறது — முழு களஞ்சியம். NUL பைட்டுகள் அல்லது `..` பிரிவுகளைக் கொண்ட துணைப்பாதை
நிராகரிக்கப்படுகிறது, ஒருபோதும் "சுத்தம்" செய்யப்படாது. ஒரே களஞ்சியத்தின் இரண்டு skill-கள்
இரண்டு பதிவுகள்; ஒரே களஞ்சியம் + துணைப்பாதை இருமுறை என்பது மோதல்.
