# படைப்பாளர் வரவு மற்றும் Pull Request முன்னுரிமை

> 🌐 [English](../../CREDIT.md) · [Português (Brasil)](../pt-BR/CREDIT.md) · [中文（简体）](../zh-CN/CREDIT.md) · **தமிழ்**

பட்டியல், சுயாதீன DSH வேலையை அதன் படைப்பாளர்களிடமிருந்து உரிமையைப் பறிக்காமல்
கண்டறியக்கூடியதாக்குவதற்காக உள்ளது. பொது பதிவுகள் அசல் களஞ்சியம் மற்றும் மாறாத மூல
commit-ஐ மேற்கோள் காட்டுகின்றன.

## அதே செருகுநிரலுக்கான முன்னுரிமை

<!-- creator-first:direct-pr-supersedes-curation-and-automation -->

1. செருகுநிரல் படைப்பாளர் அல்லது உரிமையாளர் அமைப்பினால் திறக்கப்பட்ட ஒரு pull request.
2. படைப்பாளரால் வெளிப்படையாக அங்கீகரிக்கப்பட்ட அல்லது இணை-ஆசிரியத்துடன் கூடிய ஒரு சமூக
   pull request.
3. ஏற்கனவே உள்ள செல்லுபடியாகும் சமூக pull request.
4. ஒரு பட்டியல் தானியங்கிமயமாக்கல் pull request.
5. பொது pull request இல்லாத ஒரு தனிப்பட்ட வேட்பாளர்.

ஒரு நேரடி படைப்பாளர் pull request எப்போதும் விரும்பப்படுகிறது, மேலும் அதே அதிகாரப்பூர்வ
செருகுநிரலுக்கான திறந்த நிலையில் உள்ள எந்தச் சமூக க்யூரேஷன் அல்லது தானியங்கிமயமாக்கல்
pull request-ஐயும் மீறுகிறது, எது முதலில் திறக்கப்பட்டது அல்லது மேலே சென்றது என்பதைப்
பொருட்படுத்தாமல். படைப்பாளரின் pull request மதிப்பாய்வு ஊர்தியாகிறது; அவர்களது கிளை
ஒருபோதும் மீண்டும் எழுதப்படுவதில்லை, வலுக்கட்டாயமாகத் தள்ளப்படுவதில்லை அல்லது க்யூரேட்
செய்யப்பட்ட pull request-க்கு மாற்றப்படுவதில்லை. ஒரு க்யூரேட் செய்யப்பட்ட பதிவு ஏற்கனவே
இணைக்கப்பட்டிருந்தால், வரலாறு மாறாமல் இருக்கும், மேலும் படைப்பாளர் அதை ஒரு புதிய
பங்களிப்பில் உரிமைகோரலாம் அல்லது திருத்தலாம்.

## பொது வரவு

ஒவ்வொரு பட்டியல் பதிவும் படைப்பாளரின் பொது GitHub ஹேண்டில், அசல் களஞ்சியம், களஞ்சிய நோட்
ID, செருகுநிரல் துணைப்பாதை மற்றும் முழு பின்னிணைக்கப்பட்ட commit-ஐ கொண்டிருக்கும். பொது
படைப்பாளர் சுயவிவரம் இரண்டாவது அடையாளமாகச் சேமிக்கப்படாமல், ஒற்றை ஹேண்டிலிலிருந்து
வருவிக்கப்படுகிறது. தனி பராமரிப்பாளர் மரபுரிமை நுழைவாயில் நோட் ID-ஐத் தீர்த்து, களஞ்சிய
URL பொருத்தமின்மையை நிராகரிக்கிறது. pull request விளக்கங்கள் `Created by @handle` எனக்
கூறி, மூல களஞ்சியம் மற்றும் மூல commit மெட்டாடேட்டாவைச் சேர்க்க வேண்டும்.

ஒரு Discussion-இல் இடுகையிடும் அல்லது கருத்துரைக்கும் ஒருவர் தானாகவே படைப்பாளராகக்
கருதப்படமாட்டார். உரிமை களஞ்சிய உரிமையாளர் அல்லது அமைப்பு, தொகுப்பு ஆசிரியம்,
மேனிஃபெஸ்ட் மெட்டாடேட்டா அல்லது சரியான பின்னிணைக்கப்பட்ட மூல வரலாறு ஆகியவற்றால்
ஆதரிக்கப்பட வேண்டும்.

## Git அடையாளம்

<!-- creator-first:source-bound-git-identity -->

commit ஆசிரியமும் pull request ஆசிரியமும் தனித்தனி. படைப்பாளர்-தோற்றுவாய் கொண்ட ஒரு
pull request படைப்பாளரை pull request ஆசிரியராக வைத்திருக்கிறது, மேலும் அவர்களது
commit-கள் ஆசிரியத்தை இயல்பாகப் பாதுகாக்கின்றன. ஒரு பராமரிப்பாளர் அல்லது தானியங்கிமயமாக்கல்
கணக்கு பிணைப்பாளராகவோ சரிபார்க்கப்பட்ட இணை-ஆசிரியராகவோ தோன்றலாம், ஆனால் படைப்பாளரின்
ஆசிரியத்தை மாற்றக்கூடாது.

ஒரு க்யூரேட் செய்யப்பட்ட commit-க்கு, படைப்பாளரை Git ஆசிரியராகப் பயன்படுத்தவும் அல்லது
`Co-authored-by` வாலையைச் சேர்க்கவும் — சரியான அடையாளம் மூலத்துடன் பிணைக்கப்பட்டு
பொதுவில் சரிபார்க்கக்கூடியதாக இருக்கும்போது மட்டுமே, எடுத்துக்காட்டாக அசல் களஞ்சியத்தில்
படைப்பாளரின் commit உடன் ஏற்கனவே இணைக்கப்பட்ட ஒரு அடையாளம். ஒருபோதும் மின்னஞ்சலைக்
கண்டுபிடிக்கவோ, noreply முகவரியை உருவாக்கவோ, அங்கீகரிக்கப்பட்ட பொது மூலத்திற்கு வெளியே
கண்டறியப்பட்ட தனிப்பட்ட முகவரியைப் பயன்படுத்தவோ வேண்டாம்.

சரிபார்க்கப்பட்ட Git அடையாளம் கிடைக்காதபோது, க்யூரேட்டர் அல்லது தானியங்கிமயமாக்கல் கணக்கு
commit-ஐ எழுதி, அதற்குப் பதிலாக வெளிப்படையான காணக்கூடிய வரவை வழங்குகிறது:
`Created by @handle`, பொருந்தும் பொது சுயவிவரம் மற்றும் பதிவு மற்றும் pull request-இல்
அசல் களஞ்சிய இணைப்பு. Git அடையாள வரைபடத்திலிருந்து சுயாதீனமாக காணக்கூடிய YAML வரவு
எப்போதும் தேவை. பிற்காலத்திய நேரடி படைப்பாளர் pull request, திறந்த க்யூரேட் செய்யப்பட்ட
pull request-இன் செயற்கை வரலாற்றைப் பரம்பரையாகப் பெறாமல் அதை மாற்றுகிறது.

## மரியாதையான படைப்பாளர் குறிப்பு

ஒரு க்யூரேட் செய்யப்பட்ட pull request அதன் விளக்கத்தில், அசல் களஞ்சிய இணைப்புக்கு அருகில்,
ஒரு மரியாதையான பொது `@creator` குறிப்பைப் பயன்படுத்துகிறது. அது மதிப்பாய்வு அல்லது மாற்று
நேரடி pull request-ஐ அழைக்கலாம். குறிப்பை மீண்டும் செய்ய வேண்டாம், விளம்பர issue-களைத்
திறக்க வேண்டாம், குறுக்கு-இடுகை செய்ய வேண்டாம் அல்லது கேட்கப்படாத நேரடி செய்திகளை அனுப்ப
வேண்டாம்.

## பட்டியல் உரிமம் எதிர் மேல்நீரோட்ட உரிமம்

பட்டியல் உண்மைகளும் தலையங்க YAML மெட்டாடேட்டாவும் CC0-1.0 கீழ் அர்ப்பணிக்கப்படுகின்றன. அந்த
அர்ப்பணிப்பு மேல்நீரோட்ட செருகுநிரலின் உரிமத்தை மாற்றாது. மேல்நீரோட்ட குறியீடு, ஆவணங்கள்,
திரைக்காட்சிகள், சின்னங்கள் மற்றும் பிற படைப்புப் பொருட்கள் அவற்றின் அசல் உரிமங்கள் மற்றும்
உரிமையாளர்களுக்கே உட்பட்டவையாக இருக்கும்.
