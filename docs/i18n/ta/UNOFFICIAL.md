# அதிகாரப்பூர்வமற்ற திட்ட அறிவிப்பு

> 🌐 [English](../../UNOFFICIAL.md) · [Português (Brasil)](../pt-BR/UNOFFICIAL.md) · [中文（简体）](../zh-CN/UNOFFICIAL.md) · **தமிழ்**

> **அதிகாரப்பூர்வமற்ற சமூகத் திட்டம். DeepSeek உடன் இணைப்போ, ஏற்புடையதோ, ஆதரவு பெற்றதோ அல்ல.**
> DeepSeek பெயர்களும் குறியீடுகளும் அவற்றின் உரிமையாளருக்கே சொந்தமானவை.

Awesome Omni DSH Plugins என்பது ஒரு சுயாதீன சமூகப் பட்டியல் மற்றும் நிறுவித் திட்டம். ஒரு
செருகுநிரல் பட்டியலில் இடம்பெறுவது DeepSeek அல்லது இந்தத் திட்டத்தின் பராமரிப்பாளர்களின்
மதிப்பாய்வு, சான்றிதழ், ஆதரவு அல்லது ஏற்பைக் குறிக்காது.

இந்தத் திட்டம் அதிகாரப்பூர்வ DeepSeek சின்னத்தைப் பயன்படுத்துவதில்லை, DeepSeek-இன்
அதிகாரப்பூர்வ காட்சி அடையாளத்தைப் பின்பற்றுவதில்லை, அல்லது பட்டியல் நிலைகளை அதிகாரப்பூர்வ
சான்றிதழாக விவரிப்பதில்லை. DeepSeek Harness மற்றும் DSH குறிப்புகள் இணக்க இலக்குகளை மட்டுமே
அடையாளம் காட்டுகின்றன.

செருகுநிரல் பெயர்கள், திட்டப் பெயர்கள், சின்னங்கள், திரைக்காட்சிகள், குறியீடு மற்றும்
ஆவணங்கள் அவற்றின் உரிமையாளர்களுக்கே சொந்தமானவை, மேலும் அவை அவற்றின் அசல் உரிமங்கள் மற்றும்
வர்த்தகக் குறி கொள்கைகளுக்கே உட்பட்டவையாக இருக்கும்.
