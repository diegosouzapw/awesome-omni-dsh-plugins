# பாதுகாப்புக் கொள்கை

## பட்டியலின் எல்லை

இந்தக் களஞ்சியம் பட்டியல் மெட்டாடேட்டா, ஆவணங்கள் மற்றும் பொதுவான பங்களிப்புக்
கட்டமைப்பைக் கொண்டுள்ளது. பட்டியலில் இடம்பெறுதல் என்பது பாதுகாப்புச் சான்றிதழ் அல்ல, மேலும்
இந்தத் திட்டம் எந்தச் செருகுநிரலையும் ஆதரிப்பதில்லை அல்லது உத்தரவாதம் அளிப்பதில்லை. ஒரு
பதிவை நிறுவும் முன் அசல் களஞ்சியம், பின்னிணைக்கப்பட்ட மூல commit, உரிமம் மற்றும் நிறுவல்
நடத்தையைச் சரிபார்க்கவும்.

## செருகுநிரல் பாதிப்பைப் புகாரளித்தல்

பட்டியலில் உள்ள செருகுநிரலின் பாதிப்புகளை அந்தச் செருகுநிரலின் அசல் பராமரிப்பாளருக்கு
தனிப்பட்ட முறையில் புகாரளிக்கவும். இந்தப் பட்டியலின் issue-களில் exploit விவரங்களை வெளியிட
வேண்டாம். பராமரிப்பாளருடன் ஒருங்கிணைந்த பிறகு, உணர்திறன் கொண்ட மறுஉருவாக்கப் பொருளைச்
சேர்க்காமல் பட்டியல் திருத்தம் அல்லது தனிமைப்படுத்தல் நிலையைக் கோரவும்.

## பட்டியல் பாதிப்பைப் புகாரளித்தல்

பொது களஞ்சியம் கிடைக்கும்போது, பட்டியல் சரிபார்ப்பு அல்லது பங்களிப்புக் கையாளுதலில் உள்ள
பாதிப்புகளுக்கு அதன் தனிப்பட்ட GitHub Security Advisory சேனலைப் பயன்படுத்தவும். இணைப்பு
செய்யப்படாத பாதிப்புக்குப் பொது issue-ஐப் பயன்படுத்த வேண்டாம்.

## ரகசியங்களும் தனிப்பட்ட தரவும்

பதிவுகள், pull request-கள் அல்லது issue படிவங்களில் அணுகல் டோக்கன்கள், API விசைகள்,
குக்கீகள், தனிப்பட்ட மின்னஞ்சல் முகவரிகள், நம்பிக்கைச் சான்றுகள் அல்லது தனிப்பட்ட களஞ்சிய
உள்ளடக்கங்களை ஒருபோதும் சமர்ப்பிக்க வேண்டாம். பொது ஆதாரம் அசல் பொது மூலக் களஞ்சியம்
மற்றும் அதன் பின்னிணைக்கப்பட்ட commit-இலிருந்தே வர வேண்டும்.

## அதிகாரப்பூர்வமற்ற நிலை

இது ஒரு அதிகாரப்பூர்வமற்ற சமூகத் திட்டம். இது DeepSeek உடன் இணைப்போ, ஏற்புடையதோ, ஆதரவு
பெற்றதோ அல்ல. DeepSeek பெயர்களும் குறியீடுகளும் அவற்றின் உரிமையாளருக்கே சொந்தமானவை.
