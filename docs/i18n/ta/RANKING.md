# தரவரிசை முறையியல்

தரவரிசைகள் இணைக்கப்பட்ட பொது பட்டியல் பதிவுகளின் மீது அமைந்த வெளிப்படையான பார்வைகள். அவை
ஒருபோதும் மறைக்கப்பட்ட ஒருங்கிணைந்த மதிப்பெண்ணைப் பயன்படுத்துவதில்லை, மேலும் ஒரு பரந்த தாய்த்
திட்டத்தின் நட்சத்திரங்களைச் செருகுநிரல் பிரபலமாகக் கருதுவதில்லை.

## Top Plugins by Stars நிபந்தனை

கீழே உள்ள ஒவ்வொரு நிபந்தனையும் உண்மையாக இருக்கும்போது மட்டுமே ஒரு பதிவு தகுதி பெறுகிறது:

```text
kind == plugin (the canonical native DSH bundle discriminator)
repositoryScope == dedicated
verification.status in [eligible, verified]
repository is active and not archived
stars belong to the exact plugin repository
entry is merged into the public catalog
```

தகுதி பெற்ற பதிவுகள் `popularity.starsPolicy: exact-repository` மற்றும் `popularity.stars`-இல்
எதிர்மறையல்லாத முழு எண்ணைப் பயன்படுத்துகின்றன. சமநிலைகள் சிறியெழுத்து-உணர்திறனற்ற
செருகுநிரல் ID-யை தீர்மானிக்கப்பட்ட காட்சி வரிசையாகப் பயன்படுத்துகின்றன; சமநிலை முறிவு தர
வேறுபாட்டைக் குறிக்காது.

`kind` மட்டுமே கலைப்படைப்பு வகை பாகுபடுத்தி. திட்டவரைவு வேண்டுமென்றே அதனுடன் முரண்படக்கூடிய
இரண்டாவது DSH ஒருங்கிணைப்பு வகையைச் சேமிப்பதில்லை.

## வெளிப்படையான விலக்குகள்

பரந்த மோனோரெப்போவிற்குள் உள்ள ஒரு செருகுநிரல் பட்டியல் தகுதியை இழப்பதில்லை, ஆனால் அதன் தாய்
நட்சத்திரங்கள் செருகுநிரல் தரவரிசைக்கு வரையறுக்கப்படவில்லை. அது `repositoryScope: monorepo`,
`popularity.starsPolicy: undefined-parent-repository` மற்றும் `popularity.stars: null`
பயன்படுத்த வேண்டும். அது செயல்பாட்டுப் பிரிவுகளில் தோன்றும், மேலும் ஒவ்வொரு நட்சத்திர
அடிப்படை தரவரிசையிலிருந்தும் விலக்கப்படும்.

செருகுநிரல் குடும்பங்கள், தீம்கள், ஸ்கின்கள், திறன்கள், முன்னமைவுகள், கிளையன்ட்கள்,
இடைமுகங்கள், பாலங்கள் மற்றும் பரந்த சூழல் திட்டங்கள் Top Plugins by Stars-இல் தோன்றாது.
ஒப்பிடக்கூடிய தரவு இருக்கும் இடங்களில் அவை தனிப் பிரிவுகளைப் பெறுகின்றன. திரட்டிகள், சந்தைகள்,
நிறுவி பட்டியல்கள் மற்றும் பட்டியல்கள் பட்டியல் பதிவுகள் அல்ல, அவை எந்தப் பட்டியல் பிரிவையும்
பெறுவதில்லை.

## தரவரிசை பார்வைகள்

இந்தத் திட்டம் நட்சத்திரங்கள், 24-மணிநேர வளர்ச்சி, 7-நாள் வளர்ச்சி, சமீபத்திய புதுப்பிப்புகள்,
சரிபார்க்கப்பட்ட நிறுவல்கள், செருகுநிரல் குடும்பங்கள், தீம்கள் மற்றும் ஸ்கின்கள், கிளையன்ட்கள்
மற்றும் இடைமுகங்கள், மற்றும் சூழல் ஒருங்கிணைப்புகளுக்குத் தனித்தனிப் பார்வைகளை வெளியிடலாம்.
ஒவ்வொரு பார்வையும் அதன் சொந்தச் சேர்க்கை விதியையும் ஸ்நாப்ஷாட் நேரத்தையும் வெளிப்படுத்த
வேண்டும்.

தகுதியான பதிவுகள் பூச்சியமாக இருக்கும்போது, Top Plugins வரையப்படாது. முதல் தகுதியான இணைப்பு
ஒரு Top Plugins பார்வையை உருவாக்குகிறது; பத்து தகுதியான பதிவுகள் இருந்த பிறகு மட்டுமே
பெயரிடல் Top 10 ஆக மாறுகிறது. இடம்பிடிக்கும் அல்லது புனையப்பட்ட தரவரிசைக்கு அனுமதி இல்லை.

## சரிபார்ப்பு ஏற்பு அல்ல

`eligible` என்பது பொது கட்டமைப்பும் DSH ஒருங்கிணைப்பும் சரிபார்க்கப்பட்டது என்பதாகும்.
`verified` கூடுதலாக பின்னிணைக்கப்பட்ட மூலம் அல்லது தொகுப்புக்கு ஒரு நிறுவல் புகை சோதனை
தேர்ச்சி பெற்றது என்பதாகும். இரண்டு நிலைகளும் ஏற்பு, உத்தரவாதம் அல்லது முழுமையான பாதுகாப்புச்
சான்றிதழ் அல்ல.
