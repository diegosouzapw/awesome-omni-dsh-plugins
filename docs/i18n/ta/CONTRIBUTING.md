# பங்களித்தல்

> 🌐 [English](../../CONTRIBUTING.md) · [Português (Brasil)](../pt-BR/CONTRIBUTING.md) · [中文（简体）](../zh-CN/CONTRIBUTING.md) · **தமிழ்**

> **அதிகாரப்பூர்வமற்ற சமூகத் திட்டம். DeepSeek உடன் இணைப்போ, ஏற்புடையதோ, ஆதரவு பெற்றதோ அல்ல.**
> DeepSeek பெயர்களும் குறியீடுகளும் அவற்றின் உரிமையாளருக்கே சொந்தமானவை.

பட்டியலை மேம்படுத்துவதற்கு நன்றி. பங்களிப்புகள் படைப்பாளர்-முன்னுரிமை கொண்டவை: அசல் களஞ்சிய
ஆதாரங்களைப் பயன்படுத்தவும், வரவைப் பேணவும், ஒவ்வொரு செருகுநிரலையும் சுயாதீனமாக மதிப்பாய்வு
செய்யக்கூடியதாக வைக்கவும். பட்டியல் வடிவமைப்பின்படி காலியாகவே தொடங்குகிறது; தனது சொந்த
மதிப்பாய்வு செய்யப்பட்ட pull request இல்லாமல் எந்தப் பதிவும் ஏற்கப்படாது.

## படைப்பாளரிடமிருந்து தொடங்குங்கள்

செருகுநிரலின் படைப்பாளர் அல்லது உரிமையாளர் அமைப்பினால் நேரடியாகத் திறக்கப்பட்ட pull request
எப்போதும் முன்னுரிமை பெறுகிறது. படைப்பாளர் பங்களிக்கத் தயாராக இருந்தால், க்யூரேட்டர் அல்லது
தானியங்கிமயமாக்கல் கிளையில் அவர்களது வேலையை மீண்டும் உருவாக்குவதற்குப் பதிலாக அவர்களது
கிளையையும் pull request-ஐயும் பயன்படுத்தவும்.

இன்னும் pull request திறக்காத படைப்பாளருக்கு உதவும்போது சமூக க்யூரேஷன் வரவேற்கப்படுகிறது.
இது பிற்காலத்திய நேரடி படைப்பாளர் பங்களிப்புக்கு மீதான உரிமையையோ முன்னுரிமையையோ நிலைநாட்டாது.

## ஒரு கிளைக்கு, ஒரு pull request-க்கு ஒரு செருகுநிரல்

ஒரு செருகுநிரலுக்கென ஒரு தனி கிளையை உருவாக்கி, அந்த கிளையிலிருந்து ஒரு pull request-ஐத்
திறக்கவும். அந்த கிளையும் pull request-உம் `catalog/plugins/` கீழ் சரியாக ஒரே ஒரு YAML கோப்பை
உருவாக்க வேண்டும் அல்லது மாற்ற வேண்டும். அந்த கிளையிலோ pull request-இலோ செருகுநிரல்கள்,
ஆவணச் சுத்தம், உருவாக்கப்பட்ட அட்டவணைகள் அல்லது தொடர்பற்ற பராமரிப்பு ஆகியவற்றைக் கலக்க வேண்டாம்.

பதிவின் ID-யும் கோப்புப் பெயரும் ஒரே சிறியெழுத்து kebab-case மதிப்பாக இருக்க வேண்டும்.
பராமரிப்பாளர்கள் ஒவ்வொரு செருகுநிரல் pull request-ஐயும் தனித்தனியாக மதிப்பாய்வு செய்து
இணைக்கின்றனர்; பல செருகுநிரல்களைக் கொண்ட தொகுப்பு பிரிக்கப்படாது அல்லது பகுதியாக இணைக்கப்படாது.

## அசல் மூலத்தைத் தீர்மானிக்கவும்

ஒவ்வொரு பொது புலமும் பின்னிணைக்கப்பட்ட commit-இல் அசல் படைப்பாளர் களஞ்சியம், தொகுப்பு,
மேனிஃபெஸ்ட், README, உரிமம் அல்லது வெளியீட்டிலிருந்து மீண்டும் கட்டமைக்கப்பட வேண்டும். மற்றொரு
பட்டியல் அல்லது திரட்டியின் உரை, வகை ஒதுக்கீடு, திரைக்காட்சிகள், தரவரிசை, பேட்ஜ்கள் அல்லது
உருவாக்கப்பட்ட மேலுலவுத் தரவை நகலெடுக்க வேண்டாம். குடைத் திட்டம், சந்தை, பட்டியல் அல்லது
திரட்டியில் கிடைக்கும் இணைப்பு ஒரு தடயம் மட்டுமே — ஆதாரம் அல்ல, செருகுநிரலின் மூலமும் அல்ல.

குடை, திரட்டி, சந்தை, நிறுவி பட்டியல் அல்லது பட்டியலை ஒருபோதும் பட்டியல் பதிவாக சமர்ப்பிக்க
வேண்டாம், அதுவே சுயாதீனமாக நிறுவக்கூடியதாக இருந்தாலும் சரி. அதைத் தடயமாக மட்டுமே
பயன்படுத்தி, சுயாதீனமாக நிறுவக்கூடிய ஒவ்வொரு சேய் செருகுநிரலையும் அதன் உண்மையான
படைப்பாளர் மற்றும் அசல் களஞ்சியத்திற்குத் தீர்க்கவும். படைப்பாளரின் உண்மையான மோனோரெப்போவில்
உள்ள ஒரு செருகுநிரல் அதன் சரியான துணைப்பாதையிலிருந்து சமர்ப்பிக்கப்படலாம், ஆனால் அது
கீழே உள்ள மோனோரெப்போ நட்சத்திரக் கொள்கையைப் பின்பற்ற வேண்டும்.

## தேவையான ஆதாரம்

pull request-இல் பின்வருவன அனைத்தையும் வழங்கவும்:

- அசல் களஞ்சியத்தின் அதிகாரப்பூர்வ பொது URL மற்றும் அதன் மாறாத களஞ்சிய நோட் ID.
  பராமரிப்பாளர்கள் தனி மரபுரிமை நுழைவாயிலில் நோட் ID-ஐத் தீர்த்து, URL பொருத்தமின்மையை
  நிராகரிக்கின்றனர்.
- படைப்பாளரின் பொது GitHub ஹேண்டில் மற்றும் பொருந்தும் பொது சுயவிவர URL. YAML ஹேண்டிலை
  ஒருமுறை சேமிக்கிறது; சுயவிவர URL `https://github.com/<handle>` என வருவிக்கப்படுகிறது.
- முழு 40-எழுத்து மூல commit OID மற்றும் செருகுநிரலின் சரியான துணைப்பாதை, அல்லது
  களஞ்சிய-மூல செருகுநிரலுக்கு `null`.
- ஒரு வரம்புடைய ஆங்கில விளக்கம் மற்றும் அந்தப் பின்னிணைக்கப்பட்ட commit-இல் அதன் ஆதாரப் பாதை.
- [docs/CATEGORIES.md](../../docs/CATEGORIES.md)-இலிருந்து தேர்ந்தெடுக்கப்பட்ட கலைப்படைப்பு `kind`,
  முதன்மை வகை மற்றும் குறிச்சொற்கள்.
- பின்னிணைக்கப்பட்ட commit-இல் ஆதாரப்படுத்தப்பட்ட முழுமையான மேல்நீரோட்ட SPDX உரிமக் கோவை.
- சரியான ஒரு npm பதிப்புக்குப் பின்னிணைக்கப்பட்ட, அல்லது மூல களஞ்சியம், முழு commit மற்றும்
  துணைப்பாதைக்குப் பின்னிணைக்கப்பட்ட அதிகாரப்பூர்வ நிறுவல் விவரிப்பான். விவரிப்பான் தரவு
  மட்டுமே, ஒருபோதும் ஷெல் கட்டளை அல்ல.
- சொந்த ஒருங்கிணைப்பு ஆதாரம் மற்றும் பின்னிணைக்கப்பட்ட commit-இல் அதன் பாதை.
- அந்தச் சரியான கலைப்படைப்பு பினுக்கு ஏற்கனவே உள்ள, உணர்திறனற்ற புகை ஆதாரம், அல்லது
  வெளிப்படையான மதிப்பு `not run`. பட்டியல் பங்களிப்பைத் தயாரிப்பதற்காக மட்டும்
  செருகுநிரலை நிறுவவோ அல்லது `preinstall`, `install`, `postinstall`, `prepare`
  அல்லது பிற தொகுப்பு/செருகுநிரல் வாழ்க்கைச் சுழற்சிக் குறியீட்டை இயக்கவோ வேண்டாம்.
- தனி களஞ்சியத்திற்கு, அந்தச் சரியான களஞ்சியத்திற்கான சரிபார்க்கக்கூடிய நட்சத்திர எண்ணிக்கை,
  பொது மூலம் மற்றும் சரிபார்ப்பு நேரத்துடன். மோனோரெப்போ செருகுநிரலுக்கு, கீழே உள்ள தேவையான
  ஏதுமில்லை கொள்கையைப் பயன்படுத்தவும்.
- இருக்கும்போது பொது விவாதம் அல்லது கருத்து மரபுரிமை; இல்லையெனில் `null` பயன்படுத்தவும்.
- இயந்திர-படிக்கக்கூடிய `unofficial: true` மதிப்பு.

தகுதியான புகை சோதனை ஏற்கனவே இல்லையெனில், `verification.status: eligible` மற்றும்
`verification.smokeTest: null` பயன்படுத்தவும். சரியான பினுக்கான மதிப்பாய்வு செய்யக்கூடிய
புகை ஆதாரம் இருக்கும்போது மட்டுமே `verified` பயன்படுத்தவும். எந்த நிலையும் ஏற்பு
அல்லது பாதுகாப்பு சான்றிதழ் அல்ல.

கடவுச்சொற்கள், குக்கீகள், தனியார் மின்னஞ்சல் முகவரிகள், வெளியிடப்படாத மூலம் அல்லது பிற
ரகசியங்களை ஒருபோதும் சமர்ப்பிக்க வேண்டாம்.

## YAML மற்றும் திட்டவரைவு விதிகள்

`catalog/plugins/<plugin-id>.yaml` உருவாக்கி, அதை
[`schemas/plugin.schema.yaml`](../../schemas/plugin.schema.yaml)
எதிராகச் சரிபார்க்கவும். `id` கோப்பின் அடிப்படைப் பெயருக்குச் சமமாக இருக்க வேண்டும்,
மேலும் உங்கள் பெயர்வெளியுடன் தொடங்க வேண்டும்: உங்கள் `creator.github` ஹேண்டில்
சிறியெழுத்தில் (`[a-z0-9]` வெளியே உள்ள எந்த எழுத்துத் தொடரும் ஒற்றை `-` ஆகும்),
பின்னர் `-`, எடுத்துக்காட்டாக `some-creator-my-plugin` ஹேண்டிலுக்கு
`Some-Creator`. பட்டியல் சரிபார்ப்பு இரண்டையும் அமல்படுத்துகிறது. புலப்
பெயர்கள் மற்றும் அனுமதிக்கப்பட்ட மதிப்புகளுக்கு திட்டவரைவே உண்மையின் மூலம்;
[docs/CATEGORIES.md](../../docs/CATEGORIES.md) ஒற்றை கலைப்படைப்பு வகை, முதன்மை வகை,
குறிச்சொற்கள் மற்றும் களஞ்சிய நோக்கை எவ்வாறு தேர்ந்தெடுப்பது என்பதை வரையறுக்கிறது.

ஒரு தொகுப்பு விவரிப்பானில் சரியான தொகுப்புப் பெயரும் சரியான பதிப்பும் இருக்க வேண்டும். பொது
திட்டவரைவு விருப்பம்-போன்ற மற்றும் வரம்பற்ற மதிப்புகளை நிராகரிக்கிறது, ஆனால் பதிப்பு
எண்களையோ ஒருமைப்பாட்டையோ மீண்டும் செயல்படுத்துவதில்லை: பட்டியல் சரிபார்ப்பு பதிப்பைப்
பாகுபடுத்தி, சரியான பதிப்பு எண்களைக் கோரி, எந்த ஒருமைப்பாட்டு மதிப்பையும் செல்லுபடியாகும்
பாதுகாப்பு ஆதாரமாகப் பாகுபடுத்த வேண்டும். மூல விவரிப்பான் `source.repository`,
`source.commit` மற்றும் `source.subpath` உடன் பிணைக்கப்பட்டுள்ளது, மாறக்கூடிய மூல
மதிப்புகளை நகலாக்காமல்.

நிறுவிகள் அளவுரு அணிகளைப் பயன்படுத்த வேண்டும், ஷெல் இயக்கத்தை முடக்க வேண்டும், மேலும்
அழைக்கப்படும் கட்டளை ஆதரிக்கும் இடங்களில் பட்டியல்-வழங்கப்பட்ட நிலை மதிப்புகளுக்கு முன் ஒரு
விருப்ப முடிவியை வைக்க வேண்டும். சமர்ப்பு சரிபார்ப்பு நிறுவியையோ செருகுநிரல் வாழ்க்கைச்
சுழற்சியையோ அழைக்கக்கூடாது.

<!-- catalog-validation:local-structure-and-semantics-only -->

`catalog validate` என்பது உள்ளூர், படிக்க-மட்டும் கட்டமைப்பு மற்றும் சொற்பொருள் சோதனை.
இது பாதுகாப்பான YAML-ஐ பாகுபடுத்தி, பொது திட்டவரைவைச் சரிபார்த்து, உரிமக் கோவைகளைப்
பாகுபடுத்தி, சரியான பதிப்பு எண்களையும் செல்லுபடியாகும் பாதுகாப்பு ஆதாரங்களையும் கோரி,
நகல் பெயர்களையும் அதிகாரப்பூர்வ களஞ்சிய-நோட்-கூடுதல்-துணைப்பாதை விசைகளையும் நிராகரிக்கிறது.
இது GitHub உடன் தொடர்பு கொள்வதில்லை, களஞ்சிய அடையாளத்தைத் தீர்ப்பதில்லை, அல்லது
பின்னிணைக்கப்பட்ட பிணைப்பில் ஆதாரப் பாதைகளை ஆய்வு செய்வதில்லை.

<!-- maintainer-gate:repository-origin-and-pinned-evidence -->

ஒரு பதிவு `eligible` நிலையை அடைவதற்கு முன், பராமரிப்பாளர்கள் தனியாக அதிகாரப்பூர்வ
களஞ்சியத்தையும் நோட் ஐடியையும் தீர்த்து, படைப்பாளரை அசல் மூலத்துடன் பிணைத்து,
`source.commit` இல் அறிவிக்கப்பட்ட விளக்கம், உரிமம், ஒருங்கிணைப்பு மற்றும் புகை ஆதாரத்தை
ஆய்வு செய்கின்றனர். பச்சை உள்ளூர் சரிபார்ப்பு முடிவு மரபுரிமை அல்லது தோற்றுவாய் ஆதாரம் அல்ல.

## களஞ்சிய நட்சத்திரங்கள்

சரியான தனி செருகுநிரல் களஞ்சியத்திற்குச் சொந்தமானது எனச் சரிபார்க்கக்கூடிய நட்சத்திரங்கள்
மட்டுமே பதிவு செய்யப்படலாம். ஒரு தாய்த் திட்டத்தின் நட்சத்திரங்கள் பரந்த மோனோரெப்போவிற்குள்
சேமிக்கப்பட்ட செருகுநிரலுக்கு ஒருபோதும் வழங்கப்படக்கூடாது. மோனோரெப்போ பதிவு செயல்பாட்டு
பட்டியல் பிரிவுகளுக்குத் தகுதியுள்ளதாகவே இருக்கும், ஆனால் அது பின்வருவனவற்றை அறிவிக்க
வேண்டும்:

```yaml
repositoryScope: monorepo
popularity:
  starsPolicy: undefined-parent-repository
  stars: null
```

ஒரு தனி பதிவு `repositoryScope: dedicated`, `starsPolicy: exact-repository` மற்றும்
அதே களஞ்சியத்தில் காணப்படும் எதிர்மறையல்லாத நட்சத்திர எண்ணிக்கையைப் பயன்படுத்துகிறது.
பிரபலத் தரவைச் சமர்ப்பிக்கும் முன் [docs/RANKING.md](../../docs/RANKING.md) படிக்கவும்.

## படைப்பாளர் முன்னுரிமை மற்றும் மரியாதையான தொடர்பு

ஒரே அதிகாரப்பூர்வ செருகுநிரலுக்கு, முன்னுரிமை:

1. படைப்பாளர் அல்லது உரிமையாளர் அமைப்பினால் திறக்கப்பட்ட ஒரு pull request.
2. படைப்பாளரால் வெளிப்படையாக அங்கீகரிக்கப்பட்ட ஒரு சமூக pull request.
3. ஏற்கனவே உள்ள செல்லுபடியாகும் சமூக க்யூரேஷன் pull request.
4. ஒரு பட்டியல் தானியங்கிமயமாக்கல் pull request.

ஒரு நேரடி படைப்பாளர் pull request, எது முதலில் திறக்கப்பட்டது அல்லது மேலே சென்றது என்பதைப்
பொருட்படுத்தாமல், திறந்த நிலையில் உள்ள எந்த க்யூரேஷன் அல்லது தானியங்கிமயமாக்கல்
pull request-ஐயும் மீறுகிறது. படைப்பாளரின் விண்ணப்பே மதிப்பாய்வு ஊர்தியாகிறது;
பராமரிப்பாளர்கள் படைப்பாளரின் கிளையை வலுக்கட்டாயமாகத் தள்ளுவதில்லை அல்லது அவர்களது
வேலையை க்யூரேட் செய்யப்பட்ட pull request-க்கு மாற்றுவதில்லை. ஒரு க்யூரேட் செய்யப்பட்ட பதிவு
ஏற்கனவே இணைக்கப்பட்டிருந்தால், பொது வரலாறு மீண்டும் எழுதப்படாது. படைப்பாளர் ஒரு கோரிக்கை
அல்லது திருத்தக் கோரிக்கையைப் பயன்படுத்தி, பின்னர் நேரடியாக ஒரு தொடர் pull request-ஐப்
பங்களிக்கலாம்.

ஒரு க்யூரேட் செய்யப்பட்ட pull request அதன் விளக்கத்தில், அசல் களஞ்சிய இணைப்புக்கு அருகில்,
ஒரு மரியாதையான பொது `@creator` குறிப்பைப் பயன்படுத்த வேண்டும், படைப்பாளரை அதை
மதிப்பாய்வு செய்ய அல்லது நேரடி விண்ணப்பால் மாற்ற அழைக்கும் வகையில். குறிப்பை மீண்டும்
செய்ய வேண்டாம், விளம்பர சிக்கல்களைத் திறக்க வேண்டாம், குறுக்கு-இடுகை செய்ய வேண்டாம்,
கேட்கப்படாத நேரடி செய்திகளை அனுப்ப வேண்டாம், அல்லது வேறு எந்த வகையிலும் படைப்பாளரை
தொந்தரவு செய்ய வேண்டாம்.

<!-- creator-first:source-bound-git-identity -->

படைப்பாளர்-எழுதிய pull request-களும் பிணைப்புகளும் படைப்பாளரின் வரவை இயல்பாகப்
பாதுகாக்கின்றன. க்யூரேட் செய்யப்பட்ட பிணைப்புகள், மூலத்துடன் பிணைக்கப்பட்ட, பொதுவில்
சரிபார்க்கக்கூடிய அடையாளம் இருந்தால் மட்டுமே படைப்பாளரின் பிணைப்பு ஆசிரியத்தையோ
`Co-authored-by` வாலையோ பயன்படுத்தலாம். ஒருபோதும் மின்னஞ்சலைக் கண்டுபிடிக்கவோ
மதிப்பிடவோ வேண்டாம். சரிபார்க்கப்பட்ட அடையாளம் எதுவும் இல்லாதபோது, க்யூரேட்டர்
பிணைப்பை எழுதி, YAML மற்றும் pull request-இல் அசல் களஞ்சிய இணைப்புடன் வெளிப்படையான
"உருவாக்கியவர் @ஹேண்டில்" வரவை வழங்குகிறார். ஒரு பராமரிப்பாளர் அல்லது தானியங்கிமயமாக்கல்
கணக்கு பிணைப்பாளராகவோ சரிபார்க்கப்பட்ட கூட்டு ஆசிரியராகவோ இருக்கலாம், ஆனால்
படைப்பாளரின் ஆசிரியத்தை மாற்றக்கூடாது. முழுமையான கொள்கைக்கு
[docs/CREDIT.md](../../docs/CREDIT.md) பார்க்கவும்.

## சரிபார்ப்பு கட்டளைகளும் கிடைக்கும் தன்மையும்

கிளை `omni-dsh-plugins@1.0.1` ஆக வெளியிடப்பட்டுள்ளதால், கீழே உள்ள கட்டளைகள்
இன்று `npx` வழியாகக் கிடைக்கின்றன. அவற்றை எழுதப்பட்டபடியே பயன்படுத்தவும்;
பங்களிப்பாளர்கள் மாற்றுக் கட்டளைகளை உருவாக்கக்கூடாது.

இந்தக் கட்டளைகளைக் களஞ்சிய மூலத்திலிருந்து இயக்கவும்:

```bash
npx omni-dsh-plugins catalog validate --catalog .
npx omni-dsh-plugins catalog docs-check .
npx omni-dsh-plugins catalog github-forms-check .
```

`catalog validate` மேலே விவரிக்கப்பட்ட உள்ளூர் YAML, திட்டவரைவு, உரிமம், சரியான
பதிப்பு எண்கள், பாதுகாப்பு ஆதாரம் மற்றும் நகல் சோதனைகளை மட்டுமே செய்து, வேண்டுமென்றே
காலியான பட்டியலை ஏற்கிறது. இது தொலை களஞ்சிய அடையாளத்தையோ பின்னிணைக்கப்பட்ட மூல
ஆதாரத்தையோ நிரூபிக்கவில்லை. மற்ற கட்டளைகள் தேவையான பொது ஆவணங்களையும் கட்டமைக்கப்பட்ட
சிக்கல் படிவங்களையும் சரிபார்க்கின்றன. இந்தக் கட்டளைகளை உள்ளூரில் தேர்ச்சி பெறுவது
ஆதாரத் தேவைகளைத் தளர்த்தாது; இணைக்கும் முன் பராமரிப்பாளர்கள் இன்னும் ஒவ்வொரு
தொடர்புடைய வெளியீட்டு நுழைவாயிலையும் பயன்படுத்துகின்றனர்.

## மதிப்பாய்வு நுழைவாயில்கள், மோதல்கள் மற்றும் இணைப்பு

இணைக்கும் முன் பராமரிப்பாளர்கள் தற்போதைய விண்ணப்பப் பிணைப்புக்கு ஒவ்வொரு
நுழைவாயிலையும் பயன்படுத்துகின்றனர்:

1. **நோக்கம்:** ஒரு தனி கிளை, ஒரு செருகுநிரல் YAML கோப்பு, தொடர்பற்ற மாற்றங்கள் இல்லை.
2. **அசல் அடையாளம்:** படைப்பாளர், அதிகாரப்பூர்வ களஞ்சியம், நோட் ஐடி, முழு பிணைப்பு
   மற்றும் துணைப்பாதை ஒத்துள்ளன.
3. **திட்டவரைவு மற்றும் ஆதாரம்:** YAML, வகைகள், உரிமம், நிறுவல் பின், ஒருங்கிணைப்பு
   ஆதாரம் மற்றும் புகை நிலை ஆகியவை செருகுநிரல் வாழ்க்கைச் சுழற்சிக் குறியீட்டை
   இயக்காமல் உள்ரீதியாக நிலைத்திருக்கின்றன.
4. **பிரபலம்:** தனி நட்சத்திரங்கள் சரியான களஞ்சியத்தில் சரிபார்க்கக்கூடியவை, அல்லது
   மோனோரெப்போ நட்சத்திரங்கள் `null` உடன் `undefined-parent-repository`.
5. **ஆவணங்களும் படிவங்களும்:** பொது ஆவணங்கள், Markdown வேலிகள் மற்றும் கட்டமைக்கப்பட்ட
   படிவங்கள் செல்லுபடியாக இருக்கின்றன.
6. **மோதலும் நகல்நீக்கமும்:** இணைக்கப்பட்ட பதியோ திறந்த விண்ணப்போ அதே அதிகாரப்பூர்வ
   செருகுநிரலைப் பிரதிநிதித்துவப்படுத்தவில்லை.

வெவ்வேறு பெயர்களோ பெயர்களோ நகல் செருகுநிரல்களைத் தனித்தனியாக ஆக்காது. ஒரே
களஞ்சிய நோட் ஐடியும் துணைப்பாதையும், ஒரே அதிகாரப்பூர்வ தொகுப்பு, அல்லது மற்றொரு
நிரூபிக்கக்கூடிய ஒத்த நிறுவல் இலக்கு ஆகியவற்றை மோதலாகக் கருதவும். இணைக்கும் முன்
மாற்றுப்பெயர்களையும் போட்டி pull request-களையும் தீர்க்கவும். ஒரு நேரடி படைப்பாளர்
pull request க்யூரேஷன் அல்லது தானியங்கிமயமாக்கலுடனான மோதலில் வெல்கிறது; இல்லையெனில்
பராமரிப்பாளர்கள் ஒரு மதிப்பாய்வு ஊர்தியைத் தேர்ந்தெடுத்து, இரண்டையும் இணைப்பதற்குப்
பதிலாக நகல்களை மூடி அல்லது திருப்பி விடுகின்றனர்.

அனைத்து நுழைவாயில்களும் தேர்ச்சி பெற்ற பிறகு ஒரு பராமரிப்பாளர் மட்டுமே ஒரு
செருகுநிரலை இணைக்கிறார். ஒவ்வொரு ஏற்கப்பட்ட செருகுநிரலும் தனித்தனியாக இணைக்கப்படுகிறது;
சரிபார்ப்பு, க்யூரேஷன் அல்லது தானியங்கிமயமாக்கல் தானியங்கி அல்லது தொகுப்பு இணைப்பைக்
குறிக்காது.

## மொழிக் கொள்கை

வெளியீட்டு ஆவணங்களும் பட்டியல் விளக்கங்களும் ஆங்கிலத்தில் மட்டுமே. 43-மொழி வெளியீடு
செயலி-பிந்தைய இருப்புப் பட்டியல் உருப்படியாகவே உள்ளது; காலியான மொழி ஆவணங்களையோ
தானியங்கி மொத்த மொழிபெயர்ப்புகளையோ சேர்க்க வேண்டாம்.
