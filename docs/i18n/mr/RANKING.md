# क्रमवारी पद्धती

क्रमवारी ह्या विलीन केलेल्या सार्वजनिक कॅटलॉग एंट्रींवर पारदर्शक दृश्ये आहेत. ती कधीही लपविलेला
एकत्रित गुणांक वापरत नाहीत आणि मोठ्या पालक प्रकल्पातील स्टार्सना कधीही प्लगइन लोकप्रियता मानत नाहीत.

## स्टार्सनुसार टॉप प्लगइन निकष

खालील प्रत्येक अट खरी असल्यासच एखादी एंट्री पात्र ठरते:

```text
kind == plugin (the canonical native DSH bundle discriminator)
repositoryScope == dedicated
verification.status in [eligible, verified]
repository is active and not archived
stars belong to the exact plugin repository
entry is merged into the public catalog
```

पात्र एंट्रीज `popularity.starsPolicy: exact-repository` आणि
`popularity.stars` मध्ये अ-नकारात्मक पूर्णांक वापरतात. बरोबरीच्या वेळी केस-इन्सेन्सिटिव्ह प्लगइन आयडी
निश्चित प्रदर्शन क्रम म्हणून वापरला जातो; टाय-ब्रेक गुणवत्तेतील फरक सूचित करत नाही.

`kind` हा एकमेव आर्टिफॅक्ट-प्रकार डिस्क्रिमिनेटर आहे. स्कीमा जाणूनबुजून दुसरा
असा DSH इंटिग्रेशन काइंड साठवत नाही जो त्याशी विरोधाभास करू शकेल.

## स्पष्ट वगळण्या

मोठ्या मोनोरेपोच्या आतील प्लगइन कॅटलॉगसाठी पात्र राहते, पण प्लगइन क्रमवारीसाठी त्याचे
पालक स्टार्स अनिर्धारित आहेत. त्याने `repositoryScope: monorepo`,
`popularity.starsPolicy: undefined-parent-repository` आणि `popularity.stars: null` वापरलेच पाहिजे.
ते कार्यात्मक विभागांमध्ये दिसते आणि प्रत्येक स्टार-आधारित क्रमवारीतून वगळले जाते.

प्लगइन कुटुंबे, थीम्स, स्किन्स, स्किल्स, प्रीसेट्स, क्लायंट्स, इंटरफेसेस, ब्रिजेस आणि मोठे
इकोसिस्टम प्रकल्प स्टार्सनुसार टॉप प्लगइनमध्ये दिसत नाहीत. तुलनात्मक डेटा अस्तित्वात
असल्यास त्यांना वेगळे विभाग मिळतात. अ‍ॅग्रीगेटर्स, मार्केटप्लेसेस, इंस्टॉलर कॅटलॉग आणि याद्या कॅटलॉग
एंट्री नाहीत आणि त्यांना कोणताही कॅटलॉग विभाग मिळत नाही.

## क्रमवारी दृश्ये

प्रकल्प स्टार्स, 24-तास वाढ, 7-दिवस वाढ, अलीकडील अपडेट्स,
पडताळलेले इंस्टॉल्स, प्लगइन कुटुंबे, थीम्स आणि स्किन्स, क्लायंट्स आणि इंटरफेसेस, तसेच इकोसिस्टम
इंटिग्रेशन्ससाठी वेगळी दृश्ये प्रकाशित करू शकतो. प्रत्येक दृश्याने स्वतःचा समावेश नियम आणि स्नॅपशॉट वेळ
उघड केला पाहिजे.

शून्य पात्र एंट्रींवर, टॉप प्लगइन रेंडर केले जात नाही. पहिल्या पात्र विलीनीकरणामुळे टॉप
प्लगइन दृश्य तयार होते; दहा पात्र एंट्री अस्तित्वात आल्यानंतरच लेबल टॉप 10 मध्ये बदलते. कोणतेही प्लेसहोल्डर
किंवा बनावट क्रमवारी मान्य नाही.

## पडताळणी म्हणजे मान्यता नाही

`eligible` म्हणजे सार्वजनिक रचना आणि DSH एकत्रीकरण पडताळले गेले. `verified` याव्यतिरिक्त
म्हणजे निश्चित केलेल्या सोर्स किंवा पॅकेजसाठी इंस्टॉलेशन स्मोक टेस्ट पास झाली. कोणतीही स्थिती
मान्यता, हमी किंवा परिपूर्ण सुरक्षा प्रमाणपत्र नाही.
