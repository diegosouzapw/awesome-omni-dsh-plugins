# सुरक्षा धोरण

## कॅटलॉग व्याप्ती

या रिपॉझिटरीमध्ये कॅटलॉग मेटाडेटा, दस्तऐवजीकरण आणि सामान्य योगदान कॉन्फिगरेशन आहे.
नोंदणी हे सुरक्षा प्रमाणपत्र नाही, आणि हा प्रकल्प कोणत्याही प्लगइनला मान्यता किंवा हमी
देत नाही. एखादी एंट्री इंस्टॉल करण्यापूर्वी मूळ रिपॉझिटरी, निश्चित केलेला सोर्स कमिट,
परवाना आणि इंस्टॉलेशन वर्तन तपासा.

## प्लगइन असुरक्षिततेची तक्रार करणे

नोंदवलेल्या प्लगइनमधील असुरक्षितता त्या प्लगइनच्या मूळ मेंटेनरकडे खाजगीरित्या नोंदवा.
या कॅटलॉगच्या इश्यूजमध्ये एक्सप्लॉइट तपशील प्रकाशित करू नका. मेंटेनरशी समन्वय केल्यानंतर,
संवेदनशील पुनरुत्पादन साहित्य समाविष्ट न करता कॅटलॉग दुरुस्ती किंवा क्वारंटाइन स्थितीची विनंती करा.

## कॅटलॉग असुरक्षिततेची तक्रार करणे

सार्वजनिक रिपॉझिटरी उपलब्ध असल्यास, कॅटलॉग पडताळणी किंवा योगदान हाताळणीतील
असुरक्षिततेसाठी तिचा खाजगी GitHub Security Advisory चॅनेल वापरा. पॅच न केलेल्या
असुरक्षिततेसाठी सार्वजनिक इश्यू वापरू नका.

## गुपिते आणि वैयक्तिक डेटा

एंट्रीज, पुल रिक्वेस्ट्स किंवा इश्यू फॉर्म्समध्ये ॲक्सेस टोकन्स, API कीज, कुकीज, खाजगी ईमेल
पत्ते, क्रेडेन्शियल्स किंवा खाजगी रिपॉझिटरी सामग्री कधीही सबमिट करू नका. सार्वजनिक पुरावा
मूळ सार्वजनिक सोर्स रिपॉझिटरी आणि तिच्या निश्चित केलेल्या कमिटमधूनच आला पाहिजे.

## अनधिकृत स्थिती

हा एक अनधिकृत समुदाय प्रकल्प आहे. तो DeepSeek शी संलग्न नाही, त्यांच्याकडून मान्यताप्राप्त
किंवा प्रायोजित नाही. DeepSeek ची नावे आणि चिन्हे त्यांच्या संबंधित मालकांची आहेत.
