# Politica di sicurezza

> 🌐 [English](../../SECURITY.md) · **Italiano**

## Ambito del catalogo

Questo repository contiene metadati del catalogo, documentazione e configurazione generica di
contribuzione. Un elenco non è una certificazione di sicurezza, e questo progetto non avalla né
garantisce alcun plugin. Verifica il repository originale, il commit sorgente fissato, la
licenza e il comportamento di installazione prima di installare una voce.

## Segnalare una vulnerabilità di un plugin

Segnala le vulnerabilità di un plugin elencato in modo privato al maintainer originale di quel
plugin. Non pubblicare dettagli di exploit negli issue di questo catalogo. Dopo esserti
coordinato con il maintainer, richiedi una correzione del catalogo o uno stato di quarantena
senza includere materiale di riproduzione sensibile.

## Segnalare una vulnerabilità del catalogo

Quando il repository pubblico sarà disponibile, usa il suo canale privato GitHub Security
Advisory per le vulnerabilità nella validazione del catalogo o nella gestione delle
contribuzioni. Non usare un issue pubblico per una vulnerabilità non corretta.

## Segreti e dati personali

Non inviare mai token di accesso, chiavi API, cookie, indirizzi email privati, credenziali o
contenuti di repository privati in voci, pull request o formulari di issue. Le prove pubbliche
devono provenire dal repository sorgente pubblico originale e dal suo commit fissato.

## Stato non ufficiale

Questo è un progetto comunitario non ufficiale. Non è affiliato, approvato o sponsorizzato da
DeepSeek. I nomi e i marchi DeepSeek appartengono al rispettivo proprietario.
