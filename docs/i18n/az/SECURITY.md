# Təhlükəsizlik siyasəti

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **Azərbaycan dili**

## Kataloq əhatəsi

Bu repozitoriya kataloq metaməlumatlarını, sənədləşməni və ümumi töhfə konfiqurasiyasını ehtiva
edir. Siyahıya salınma təhlükəsizlik sertifikatı deyil və bu layihə heç bir əlavəni təsdiqləmir
və ya ona zəmanət vermir. Qeydi quraşdırmazdan əvvəl orijinal repozitoriyanı, sabitlənmiş mənbə
commit-ini, lisenziyanı və quraşdırma davranışını yoxlayın.

## Əlavə zəifliyini bildirmək

Siyahıya salınmış əlavədəki zəiflikləri həmin əlavənin orijinal baxıcısına özəl olaraq bildirin.
Bu kataloqun issue-larında istismar (exploit) təfərrüatlarını dərc etməyin. Baxıcı ilə
koordinasiyadan sonra, həssas reproduksiya materialları daxil etmədən, kataloq düzəlişi və ya
karantin statusu tələb edin.

## Kataloq zəifliyini bildirmək

İctimai repozitoriya əlçatan olduqda, kataloq doğrulaması və töhfə emalındakı zəifliklər üçün onun
özəl GitHub Security Advisory kanalından istifadə edin. Yamaqlanmamış zəiflik üçün ictimai issue
istifadə etməyin.

## Sirlər və şəxsi məlumatlar

Qeydlərdə, pull request-lərdə və ya issue formalarında heç vaxt giriş tokenləri, API açarları,
cookie-lər, şəxsi e-poçt ünvanları, etimadnamələr və ya özəl repozitoriya məzmunu təqdim etməyin.
İctimai sübut orijinal ictimai mənbə repozitoriyasından və onun sabitlənmiş commit-indən
gəlməlidir.

## Qeyri-rəsmi status

Bu, qeyri-rəsmi icma layihəsidir. DeepSeek ilə əlaqəli deyil, DeepSeek tərəfindən dəstəklənmir və
ya maliyyələşdirilmir. DeepSeek adları və nişanları müvafiq sahiblərinə məxsusdur.
