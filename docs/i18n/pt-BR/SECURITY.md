## Escopo do catálogo

Este repositório contém metadados de catálogo, documentação e configuração genérica de
contribuição. Uma listagem não é uma certificação de segurança, e este projeto não endossa nem
garante nenhum plugin. Verifique o repositório original, o commit de origem fixado, a licença e
o comportamento de instalação antes de instalar uma entrada.

## Reportando uma vulnerabilidade de plugin

Reporte vulnerabilidades em um plugin listado de forma privada ao mantenedor original desse
plugin. Não publique detalhes de exploração nas issues deste catálogo. Depois de coordenar com o
mantenedor, solicite uma correção no catálogo ou um estado de quarentena, sem incluir material de
reprodução sensível.

## Reportando uma vulnerabilidade do catálogo

Quando o repositório público estiver disponível, use seu canal privado de GitHub Security
Advisory para vulnerabilidades na validação do catálogo ou no tratamento de contribuições. Não
use uma issue pública para uma vulnerabilidade ainda não corrigida.

## Segredos e dados pessoais

Nunca submeta tokens de acesso, chaves de API, cookies, endereços de e-mail privados,
credenciais ou conteúdo de repositório privado em entradas, pull requests ou formulários de
issue. A evidência pública deve vir do repositório de origem público original e do seu commit
fixado.

## Status de não oficial

Este é um projeto comunitário não oficial. Ele não é afiliado, endossado ou patrocinado pela
DeepSeek. Nomes e marcas da DeepSeek pertencem aos respectivos proprietários.
