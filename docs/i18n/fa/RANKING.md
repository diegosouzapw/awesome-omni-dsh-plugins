# روش‌شناسی رتبه‌بندی

> 🌐 [English](../../RANKING.md) · [Português (Brasil)](../pt-BR/RANKING.md) · [中文（简体）](../zh-CN/RANKING.md) · **فارسی**

رتبه‌بندی‌ها نماهای شفافی روی ورودی‌های عمومیِ ادغام‌شدهٔ کاتالوگ هستند. هرگز از یک امتیاز
ترکیبیِ پنهان استفاده نمی‌کنند و هرگز ستاره‌های یک پروژهٔ والدِ گسترده را محبوبیت افزونه در نظر
نمی‌گیرند.

## قاعدهٔ افزونه‌های برتر بر اساس ستاره

یک ورودی فقط زمانی واجدشرایط می‌شود که هر شرط زیر برقرار باشد:

```text
kind == plugin (the canonical native DSH bundle discriminator)
repositoryScope == dedicated
verification.status in [eligible, verified]
repository is active and not archived
stars belong to the exact plugin repository
entry is merged into the public catalog
```

ورودی‌های واجدشرایط از `popularity.starsPolicy: exact-repository` و یک عدد صحیح غیرمنفی در
`popularity.stars` استفاده می‌کنند. تساوی‌ها از شناسهٔ افزونه به‌صورت غیرحساس به حروف به‌عنوان
ترتیب نمایشِ قطعی استفاده می‌کنند؛ شکستنِ تساوی به معنای تفاوت کیفیت نیست.

`kind` تنها تمایزدهندهٔ نوع مصنوع است. اسکیما عمداً یک نوع دومِ یکپارچگی DSH را که می‌تواند با
آن در تناقض باشد ذخیره نمی‌کند.

## استثناهای صریح

یک افزونه درون یک مونوریپوی گسترده‌تر واجدشرایط کاتالوگ باقی می‌ماند، اما ستاره‌های والدش برای
رتبه‌بندی افزونه نامشخص است. باید از `repositoryScope: monorepo`،
`popularity.starsPolicy: undefined-parent-repository` و `popularity.stars: null` استفاده کند.
در بخش‌های عملکردی ظاهر می‌شود و از هر رتبه‌بندی مبتنی بر ستاره مستثناست.

خانواده‌های افزونه، تم‌ها، پوسته‌ها، مهارت‌ها، پیش‌تنظیم‌ها، کلاینت‌ها، رابط‌ها، پل‌ها و
پروژه‌های اکوسیستمِ گسترده‌تر در افزونه‌های برتر بر اساس ستاره ظاهر نمی‌شوند. آن‌ها بخش‌های
جداگانه‌ای دریافت می‌کنند وقتی داده‌های قابل‌مقایسه وجود دارد. جمع‌کننده‌ها، بازارها، کاتالوگ‌های
نصب‌کننده و فهرست‌ها ورودی کاتالوگ نیستند و هیچ بخش کاتالوگی دریافت نمی‌کنند.

## نماهای رتبه‌بندی

پروژه ممکن است نماهای متمایزی برای ستاره‌ها، رشد ۲۴ ساعته، رشد ۷ روزه، به‌روزرسانی‌های اخیر،
نصب‌های تأییدشده، خانواده‌های افزونه، تم‌ها و پوسته‌ها، کلاینت‌ها و رابط‌ها، و یکپارچگی‌های
اکوسیستم منتشر کند. هر نما باید قاعدهٔ شمولِ خودش و زمان snapshot را افشا کند.

در صفر ورودی واجدشرایط، افزونه‌های برتر رندر نمی‌شود. اولین ادغام واجدشرایط یک نمای افزونه‌های
برتر ایجاد می‌کند؛ برچسب فقط پس از وجود ده ورودی واجدشرایط به ۱۰ افزونهٔ برتر تغییر می‌کند.
هیچ رتبه‌بندیِ جایگزین یا ساختگی مجاز نیست.

## اعتبارسنجی تأیید نیست

`eligible` یعنی ساختار عمومی و یکپارچگی DSH اعتبارسنجی شده‌اند. `verified` به‌علاوه یعنی یک
smoke test نصب برای منبع یا بستهٔ پین‌شده موفق شده است. هیچ‌کدام از این وضعیت‌ها تأیید، تضمین
یا گواهی امنیتی مطلق نیست.
