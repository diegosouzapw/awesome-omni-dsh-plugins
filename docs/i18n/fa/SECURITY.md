# سیاست امنیتی

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **فارسی**

## دامنهٔ کاتالوگ

این ریپازیتوری شامل ابرداده‌های کاتالوگ، مستندات و پیکربندی عمومی مشارکت است. فهرست‌شدن یک گواهی
امنیتی نیست و این پروژه هیچ افزونه‌ای را تأیید یا تضمین نمی‌کند. پیش از نصب یک ورودی، ریپازیتوری
اصلی، کامیت منبع پین‌شده، مجوز و رفتار نصب را بررسی کنید.

## گزارش آسیب‌پذیری یک افزونه

آسیب‌پذیری‌های یک افزونهٔ فهرست‌شده را به‌صورت خصوصی به نگهدارندهٔ اصلی همان افزونه گزارش دهید.
جزئیات بهره‌برداری (exploit) را در issueهای این کاتالوگ منتشر نکنید. پس از هماهنگی با نگهدارنده،
اصلاح کاتالوگ یا وضعیت قرنطینه را بدون گنجاندن مواد بازتولید حساس درخواست کنید.

## گزارش آسیب‌پذیری کاتالوگ

وقتی ریپازیتوری عمومی در دسترس است، برای آسیب‌پذیری‌های اعتبارسنجی کاتالوگ یا پردازش مشارکت‌ها از
کانال خصوصی GitHub Security Advisory آن استفاده کنید. برای یک آسیب‌پذیریِ اصلاح‌نشده از issue
عمومی استفاده نکنید.

## اطلاعات محرمانه و داده‌های شخصی

هرگز توکن‌های دسترسی، کلیدهای API، کوکی‌ها، آدرس‌های ایمیل خصوصی، اعتبارنامه‌ها یا محتوای
ریپازیتوری خصوصی را در ورودی‌ها، pull requestها یا فرم‌های issue ارسال نکنید. شواهد عمومی باید از
ریپازیتوری منبع اصلیِ عمومی و کامیت پین‌شدهٔ آن به‌دست آید.

## وضعیت غیررسمی

این یک پروژهٔ غیررسمی جامعه است. وابسته به، تأییدشده توسط یا اسپانسرشده توسط DeepSeek نیست. نام‌ها
و علائم DeepSeek متعلق به مالک مربوطه‌شان است.
