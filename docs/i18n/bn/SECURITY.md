# নিরাপত্তা নীতি

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **বাংলা**

## ক্যাটালগের পরিসীমা

এই রিপোজিটরিতে ক্যাটালগ মেটাডেটা, ডকুমেন্টেশন এবং সাধারণ অবদান কনফিগারেশন রয়েছে। একটি তালিকাভুক্তি কোনো
নিরাপত্তা সার্টিফিকেশন নয়, এবং এই প্রকল্প কোনো প্লাগইনকে অনুমোদন বা গ্যারান্টি দেয় না। কোনো এন্ট্রি ইনস্টল
করার আগে মূল রিপোজিটরি, পিন করা সোর্স কমিট, লাইসেন্স এবং ইনস্টলেশন আচরণ পরীক্ষা করুন।

## একটি প্লাগইনের দুর্বলতা রিপোর্ট করা

তালিকাভুক্ত একটি প্লাগইনের দুর্বলতাগুলি সেই প্লাগইনের মূল মেইনটেইনারকে ব্যক্তিগতভাবে রিপোর্ট করুন। এই
ক্যাটালগের ইস্যুতে এক্সপ্লয়েট বিবরণ প্রকাশ করবেন না। মেইনটেইনারের সাথে সমন্বয় করার পরে, সংবেদনশীল
পুনরুৎপাদন উপাদান অন্তর্ভুক্ত না করে একটি ক্যাটালগ সংশোধন বা কোয়ারেন্টাইন অবস্থার অনুরোধ করুন।

## একটি ক্যাটালগের দুর্বলতা রিপোর্ট করা

পাবলিক রিপোজিটরি উপলব্ধ থাকলে, ক্যাটালগ বৈধতা যাচাইকরণ বা অবদান পরিচালনায় দুর্বলতার জন্য এর প্রাইভেট GitHub
Security Advisory চ্যানেল ব্যবহার করুন। একটি অপ্যাচড দুর্বলতার জন্য পাবলিক ইস্যু ব্যবহার করবেন না।

## গোপনীয় তথ্য এবং ব্যক্তিগত ডেটা

এন্ট্রি, পুল রিকোয়েস্ট বা ইস্যু ফর্মে কখনও অ্যাক্সেস টোকেন, API কী, কুকি, ব্যক্তিগত ইমেইল ঠিকানা, ক্রেডেনশিয়াল
বা প্রাইভেট রিপোজিটরির বিষয়বস্তু জমা দেবেন না। পাবলিক প্রমাণ অবশ্যই মূল পাবলিক সোর্স রিপোজিটরি এবং এর পিন করা
কমিট থেকে আসতে হবে।

## অনানুষ্ঠানিক অবস্থা

এটি একটি অনানুষ্ঠানিক কমিউনিটি প্রকল্প। এটি DeepSeek-এর সাথে সংযুক্ত নয়, DeepSeek দ্বারা অনুমোদিত বা
পৃষ্ঠপোষকতাপ্রাপ্ত নয়। DeepSeek-এর নাম এবং চিহ্নসমূহ তাদের নিজ নিজ মালিকের সম্পত্তি।
