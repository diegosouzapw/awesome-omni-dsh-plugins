# ক্যাটালগ এন্ট্রি স্কিমা রেফারেন্স

> 🌐 [English](../../docs/SCHEMA.md) · [Português (Brasil)](../pt-BR/SCHEMA.md) · [中文（简体）](../zh-CN/SCHEMA.md) · **বাংলা**

> **অনানুষ্ঠানিক কমিউনিটি প্রকল্প। DeepSeek-এর সাথে সংযুক্ত নয়, অনুমোদিত নয়, বা পৃষ্ঠপোষকতাপ্রাপ্ত নয়।**
> DeepSeek-এর নাম এবং চিহ্নগুলি তাদের নিজ নিজ মালিকের অন্তর্গত।

এটি [`schemas/plugin.schema.yaml`](../../schemas/plugin.schema.yaml)-এর ফিল্ড-বাই-ফিল্ড রেফারেন্স,
পাবলিক JSON Schema (draft 2020-12) যা `catalog/plugins/`-এর অধীনে প্রতিটি ফাইলকে অবশ্যই সন্তুষ্ট করতে
হবে। স্কিমা ফাইলটি নিজেই সত্যের উৎস; যখন এই পৃষ্ঠা এবং স্কিমা ভিন্নমত পোষণ করে, তখন স্কিমা জয়ী হয়।

দুই স্তরের বৈধতা যাচাইকরণ প্রযোজ্য। পাবলিক স্কিমা সীমাবদ্ধ *নিরাপদ আকার* প্রয়োগ করে (প্যাটার্ন এবং দৈর্ঘ্য
যা অপশন-সদৃশ বা অসীম মান প্রত্যাখ্যান করে)। এর উপরে, `catalog validate` বাধ্যতামূলক সিমান্টিক পার্সার
প্রয়োগ করে: সংস্করণের জন্য সঠিক SemVer, ইন্টিগ্রিটি মানের জন্য SHA-512 SRI, লাইসেন্সের জন্য SPDX
এক্সপ্রেশন পার্সিং, এবং ডুপ্লিকেট-কী প্রত্যাখ্যান। একটি মান স্কিমা প্যাটার্নের সাথে মিলতে পারে এবং তবুও
সিমান্টিকভাবে প্রত্যাখ্যাত হতে পারে।

শীর্ষ-স্তরের নিয়ম: এন্ট্রিটি একটি একক YAML অবজেক্ট, `additionalProperties: false` (অজানা ফিল্ড
প্রত্যাখ্যাত হয়), এবং নিম্নলিখিত **সমস্ত** ফিল্ড প্রয়োজনীয়।

## শীর্ষ-স্তরের ফিল্ড

| ফিল্ড             | টাইপ    | প্রয়োজনীয় | সারাংশ                                                       |
| ----------------- | ------- | :------: | ------------------------------------------------------------- |
| `schemaVersion`   | const   |   হ্যাঁ    | অবশ্যই ঠিক `1` হতে হবে                                           |
| `id`              | string  |   হ্যাঁ    | লোয়ারকেস kebab-case এন্ট্রি ID; ফাইলনামের সাথে মিলতে হবে        |
| `name`            | string  |   হ্যাঁ    | প্রদর্শন নাম, ১–১২০ অক্ষর                                |
| `description`     | object  |   হ্যাঁ    | কিউরেট করা ইংরেজি সারাংশ এবং এর প্রমাণের পথ                |
| `unofficial`      | const   |   হ্যাঁ    | অবশ্যই ঠিক `true` হতে হবে                                        |
| `kind`            | enum    |   হ্যাঁ    | প্রামাণ্য আর্টিফ্যাক্ট ডিসক্রিমিনেটর                            |
| `primaryCategory` | enum    |   হ্যাঁ    | একক প্রাথমিক সক্ষমতা ক্যাটাগরি                            |
| `tags`            | array   |   হ্যাঁ    | অনন্য লোয়ারকেস kebab-case ট্যাগ (খালি হতে পারে)               |
| `source`          | object  |   হ্যাঁ    | মূল রিপোজিটরি, নোড ID, সাবপাথ এবং পিন করা কমিট       |
| `creator`         | object  |   হ্যাঁ    | স্রষ্টার পাবলিক GitHub হ্যান্ডেল                                |
| `package`         | object  |   হ্যাঁ    | প্রামাণ্য ইনস্টল ডেস্ক্রিপ্টর (npm **অথবা** source)              |
| `dsh`             | object  |   হ্যাঁ    | DSH প্রোফাইল এবং নেটিভ-ইন্টিগ্রেশন প্রমাণের পথ             |
| `repositoryScope` | enum    |   হ্যাঁ    | `dedicated` অথবা `monorepo`                                     |
| `popularity`      | object  |   হ্যাঁ    | স্টার নীতি এবং স্টার সংখ্যা (স্কোপের উপর শর্তাধীন)            |
| `license`         | object  |   হ্যাঁ    | আপস্ট্রিম SPDX লাইসেন্স এক্সপ্রেশন                            |
| `verification`    | object  |   হ্যাঁ    | যাচাইকরণ স্ট্যাটাস, চেক টাইম, পরিচয় এবং স্মোক টেস্ট      |
| `provenance`      | object  |   হ্যাঁ    | পাবলিক Discussion/মন্তব্য URL অথবা `null`                      |

### `schemaVersion`

ধ্রুবক `1`। পাবলিক স্কিমা সংস্করণ ১ নির্দেশ করে; অন্য কোনো মান অবৈধ।

### `id`

`^[a-z0-9]+(?:-[a-z0-9]+)*$`-এর সাথে মিলে যাওয়া string — লোয়ারকেস kebab-case, কোনো লিডিং/ট্রেইলিং বা
ডাবল হাইফেন নেই। [CONTRIBUTING.md](../../CONTRIBUTING.md) অনুসারে, এন্ট্রি ফাইলটি অবশ্যই একই মান-সহ
`catalog/plugins/<id>.yaml` নামে নামকরণ করা হতে হবে; ভ্যালিডেটর একটি অমিল প্রত্যাখ্যান করে
(`id-filename-mismatch`)। ID-টি অবশ্যই স্রষ্টার নেমস্পেস দিয়ে শুরু হতে হবে: `creator.github`
হ্যান্ডেল লোয়ারকেসে, `[a-z0-9]`-এর বাইরের প্রতিটি ধারাবাহিক অক্ষরকে একটি একক `-`-এ সংকুচিত করে,
তারপর `-` (`id-creator-prefix`)।

### `name`

মুক্ত-ফর্ম প্রদর্শন নাম, `minLength: 1`, `maxLength: 120`।

### `description`

ঠিক দুটি প্রয়োজনীয় প্রপার্টি-সহ অবজেক্ট (অন্য কোনোটির অনুমতি নেই):

| প্রপার্টি      | টাইপ   | নিয়ম                                                                 |
| -------------- | ------ | --------------------------------------------------------------------- |
| `en`           | string | ইংরেজি সারাংশ, ২০–৩২০ অক্ষর                                    |
| `evidencePath` | string | আপেক্ষিক রিপো পাথ প্যাটার্ন; কোনো লিডিং `/` নেই, কোনো ব্যাকস্ল্যাশ নেই, কোনো `.`/`..` সেগমেন্ট নেই |

ইংরেজি সারাংশটি অবশ্যই `evidencePath`-এর ফাইল থেকে কিউরেট করতে হবে যেমনটি এটি `source.commit`-এ
বিদ্যমান — অন্য কোনো ক্যাটালগ থেকে কপি করা নয়।

### `unofficial`

ধ্রুবক `true`। মেশিন-পাঠযোগ্য চিহ্নিতকারী যে তালিকাভুক্তিটি অনানুষ্ঠানিক।

### `kind`

**একমাত্র** আর্টিফ্যাক্ট-টাইপ ডিসক্রিমিনেটর (কোনো দ্বিতীয় ইন্টিগ্রেশন-kind ফিল্ড নেই)। এর মধ্যে একটি:

`plugin` · `plugin-family` · `skin-theme` · `skill` · `preset-profile` · `client-interface` ·
`bridge-adapter` · `ecosystem-project`

অর্থ এবং র‍্যাঙ্কিংয়ের পরিণতি [docs/CATEGORIES.md](../../docs/CATEGORIES.md)-এ সংজ্ঞায়িত।

### `primaryCategory`

তেরোটি সক্ষমতা ক্যাটাগরির মধ্যে একটি:

`user-interface-dashboards` · `memory-rag` · `search-research` · `coding-developer-tools` ·
`browser-automation` · `vision-audio-multimodal` · `sessions-productivity` ·
`security-permissions-approvals` · `diagnostics-observability` · `models-providers-routing` ·
`messaging-notifications` · `data-external-services` · `entertainment-customization`

প্রদর্শন লেবেল এবং নির্বাচন নির্দেশিকা [docs/CATEGORIES.md](../../docs/CATEGORIES.md)-এ রয়েছে।

### `tags`

অনন্য স্ট্রিংয়ের অ্যারে, প্রতিটি `^[a-z0-9]+(?:-[a-z0-9]+)*$` (লোয়ারকেস kebab-case)-এর সাথে মেলে।
স্কিমা দ্বারা কোনো ন্যূনতম সংখ্যা আরোপ করা হয় না।

### `source`

ঠিক চারটি প্রয়োজনীয় প্রপার্টি-সহ অবজেক্ট:

| প্রপার্টি           | টাইপ           | নিয়ম                                                                  |
| ------------------ | -------------- | ---------------------------------------------------------------------- |
| `repository`       | string         | `https://github.com/<owner>/<repo>` URL; owner GitHub ইউজারনেম নিয়ম অনুসরণ করে, repo নাম ১–১০০ অক্ষর, `.`/`..` হতে পারবে না বা `.git`-এ শেষ হতে পারবে না |
| `repositoryNodeId` | string         | অপরিবর্তনীয় GitHub রিপোজিটরি নোড ID, খালি নয়                         |
| `subpath`          | string বা null | রিপোজিটরির ভেতরে প্লাগইনের সাবপাথ (`evidencePath`-এর মতো একই নিরাপদ আপেক্ষিক-পাথ প্যাটার্ন), অথবা একটি রিপোজিটরি-রুট প্লাগইনের জন্য `null` |
| `commit`           | string         | সম্পূর্ণ ৪০-অক্ষরের হেক্সাডেসিমাল কমিট OID                               |

ক্যাটালগ বৈধতা যাচাইকরণকে অবশ্যই `repositoryNodeId` সমাধান করতে হবে এবং একটি রিপোজিটরি URL অমিল
প্রত্যাখ্যান করতে হবে — সেই সমাধান একটি মেইনটেইনার-পার্শ্বের গেট, স্থানীয় স্ট্রাকচারাল চেকের অংশ নয়।

### `creator`

একটি একক প্রয়োজনীয় প্রপার্টি-সহ অবজেক্ট:

| প্রপার্টি | টাইপ   | নিয়ম                                             |
| -------- | ------ | ------------------------------------------------- |
| `github` | string | GitHub ইউজারনেম (১–৩৯ অক্ষর, GitHub হ্যান্ডেল নিয়ম) |

পাবলিক প্রোফাইল URL সর্বদা `https://github.com/<handle>` হিসেবে উদ্ভূত হয়; কোনো দ্বিতীয় প্রোফাইল
ফিল্ড সংরক্ষণ করা হয় না, তাই দুটি কখনও ভিন্ন হতে পারে না।

### `package`

প্রামাণ্য ইনস্টল ডেস্ক্রিপ্টর। এটি ডেটা, কখনও শেল কমান্ড নয়, এবং দুটি আকারের মধ্যে ঠিক একটি নেয় (`oneOf`):

**npm package** — প্রয়োজনীয় `ecosystem`, `name`, `version`; ঐচ্ছিক `integrity`:

| প্রপার্টি    | টাইপ  | নিয়ম                                                                      |
| ----------- | ----- | --------------------------------------------------------------------------- |
| `ecosystem` | const | `npm`                                                                      |
| `name`      | string | npm প্যাকেজ নামের আকার (ঐচ্ছিকভাবে স্কোপড), সর্বোচ্চ ২১৪ অক্ষর                 |
| `version`   | string | সঠিক `x.y.z` সংস্করণ আকার (ঐচ্ছিক prerelease/build); রেঞ্জ প্রত্যাখ্যাত। সিমান্টিক স্তরে অতিরিক্তভাবে পার্সযোগ্য, সঠিক SemVer প্রয়োজন |
| `integrity` | string | ঐচ্ছিক `sha512-…` SRI আকার, ৮–২৫৬ অক্ষর। সিমান্টিক স্তরকে অবশ্যই এটি বৈধ SHA-512 SRI হিসেবে পার্স করতে হবে |

**source install** — শুধুমাত্র প্রয়োজনীয় `ecosystem`:

| প্রপার্টি    | টাইপ  | নিয়ম    |
| ----------- | ----- | -------- |
| `ecosystem` | const | `source` |

একটি সোর্স ডেস্ক্রিপ্টর ইচ্ছাকৃতভাবে আর কিছু সংরক্ষণ করে না: রিপোজিটরি, কমিট এবং সাবপাথ `source` থেকে
উদ্ভূত, তাই মিউটেবল মান কখনও নকল করা হয় না।

### `dsh`

নেটিভ DSH ইন্টিগ্রেশন প্রমাণ:

| প্রপার্টি       | টাইপ   | নিয়ম                                                          |
| -------------- | ------ | ---------------------------------------------------------------- |
| `profiles`     | array  | `^[A-Za-z0-9][A-Za-z0-9._-]*$`-এর সাথে মেলে এমন অন্তত একটি অনন্য প্রোফাইল নাম |
| `evidencePath` | string | `source.commit`-এ DSH ইন্টিগ্রেশন প্রমাণের নিরাপদ আপেক্ষিক পথ |

### `repositoryScope`

হয় `dedicated` (রিপোজিটরি স্টার এই সঠিক প্লাগইনের অন্তর্গত) অথবা `monorepo` (প্লাগইনটি একটি বৃহত্তর
প্রকল্পের ভেতরে একটি সাবপাথ বা প্যাকেজ)। এই মানটি নিচের শর্তসাপেক্ষ জনপ্রিয়তা নিয়ম নির্ধারণ করে।

### `popularity`

| প্রপার্টি     | টাইপ            | নিয়ম                                                |
| ------------ | --------------- | ---------------------------------------------------- |
| `starsPolicy`| enum            | `exact-repository` অথবা `undefined-parent-repository`  |
| `stars`      | integer বা null | অ-নেতিবাচক ইন্টিজার, অথবা `null`                      |

শর্তসাপেক্ষ নিয়ম (স্কিমার `allOf` ব্লক দ্বারা প্রয়োগকৃত):

- `repositoryScope: monorepo` **বাধ্য করে** `starsPolicy: undefined-parent-repository` এবং
  `stars: null`। প্যারেন্ট-প্রকল্পের স্টার কখনও একটি মনোরিপো প্লাগইনকে দায়ী করা হয় না।
- `repositoryScope: dedicated` **বাধ্য করে** `starsPolicy: exact-repository` এবং একটি ইন্টিজার
  `stars >= 0`।

এই মানগুলি কীভাবে র‍্যাঙ্কিং নির্ণায়ককে খাওয়ায় তার জন্য [docs/RANKING.md](../../docs/RANKING.md) দেখুন।

### `license`

| প্রপার্টি | টাইপ   | নিয়ম                                                          |
| -------- | ------ | ---------------------------------------------------------------- |
| `spdx`   | string | SPDX এক্সপ্রেশন আকার, ২–২৫৬ অক্ষর, কোনো লিডিং হাইফেন নেই          |

স্কিমা শুধুমাত্র একটি নিরাপদ অক্ষর আকার প্রয়োগ করে; ক্যাটালগ বৈধতা যাচাইকরণকে অবশ্যই একটি প্রকৃত SPDX
এক্সপ্রেশন পার্সার দিয়ে মানটি পার্স এবং স্বাভাবিক করতে হবে। পিন করা কমিটে প্রমাণিত সম্পূর্ণ আপস্ট্রিম
এক্সপ্রেশন রেকর্ড করুন (উদাহরণস্বরূপ `Apache-2.0` অথবা `MIT OR GPL-3.0-only`)।

### `verification`

যাচাইকরণ `source.commit`-এ প্রযোজ্য। চারটি প্রয়োজনীয় প্রপার্টি-সহ অবজেক্ট:

| প্রপার্টি             | টাইপ           | নিয়ম                                                  |
| -------------------- | -------------- | ------------------------------------------------------ |
| `status`             | enum           | `eligible` · `verified` · `stale` · `unavailable` · `archived` · `quarantined` |
| `checkedAt`          | string         | চেকের `date-time` ফরম্যাটেড টাইমস্ট্যাম্প           |
| `repositoryIdentity` | const          | অবশ্যই `resolved` হতে হবে                                     |
| `smokeTest`          | object বা null | স্মোক-টেস্ট রেকর্ড, অথবা যখন কোনো যোগ্য টেস্ট বিদ্যমান নেই তখন `null` |

উপস্থিত থাকলে, `smokeTest`-এর প্রয়োজন:

| প্রপার্টি        | টাইপ   | নিয়ম                                                             |
| --------------- | ------ | ------------------------------------------------------------------- |
| `installTarget` | const  | `canonical-install-descriptor` — মিউটেবল মান নকল না করে `package` অথবা পিন করা সোর্স উল্লেখ করে |
| `check`         | object | প্রয়োজনীয় `name` (প্যাকেজ-নাম আকার) এবং `version` (সঠিক সংস্করণ আকার) |
| `result`        | const  | `passed` — একটি ব্যর্থ স্মোক টেস্ট স্মোক টেস্ট হিসেবে রেকর্ড করা হয় না    |

শর্তসাপেক্ষ নিয়ম: `status: verified`-এর জন্য একটি নন-নাল `smokeTest` অবজেক্ট **প্রয়োজন**।
পর্যালোচনাযোগ্য স্মোক প্রমাণ ছাড়া এন্ট্রি `status: eligible` এবং `smokeTest: null` ব্যবহার করে। কোনো
স্ট্যাটাসই কোনো অনুমোদন বা নিরাপত্তা সার্টিফিকেশন নয় — দেখুন [docs/RANKING.md](../../docs/RANKING.md)।

### `provenance`

পাবলিক প্রোভেন্যান্স লিঙ্ক, প্রতিটি একটি URI অথবা `null`:

| প্রপার্টি     | টাইপ          | নিয়ম                                            |
| ------------ | ------------- | -------------------------------------------------- |
| `discussion` | string বা null | একটি বিদ্যমান থাকলে পাবলিক Discussion URL            |
| `comment`    | string বা null | একটি বিদ্যমান থাকলে পাবলিক মন্তব্য URL               |

## স্কিমা কী পরীক্ষা করে না

স্কিমাটি ইচ্ছাকৃতভাবে স্থানীয় এবং স্ট্রাকচারাল। এটি রিপোজিটরিটি বিদ্যমান কিনা, নোড ID URL-এর সাথে মেলে
কিনা, প্রমাণের পথ পিন করা কমিটে বিদ্যমান কিনা, স্টার সংখ্যা সঠিক কিনা, বা স্রষ্টা সোর্সের মালিক কিনা তা
যাচাই করে **না**। সেই চেকগুলি [CONTRIBUTING.md](../../CONTRIBUTING.md) এবং
[docs/GOVERNANCE.md](../../docs/GOVERNANCE.md)-এ বর্ণিত মেইনটেইনার পর্যালোচনা গেটের অন্তর্গত।
