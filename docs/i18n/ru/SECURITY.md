# Политика безопасности

## Область каталога

Этот репозиторий содержит метаданные каталога, документацию и общую конфигурацию для вклада.
Наличие записи не является сертификацией безопасности, и этот проект не одобряет и не
гарантирует ни один плагин. Перед установкой записи проверьте оригинальный репозиторий,
закреплённый исходный коммит, лицензию и поведение при установке.

## Сообщение об уязвимости плагина

Сообщайте об уязвимостях в перечисленном плагине приватно оригинальному мейнтейнеру этого
плагина. Не публикуйте детали эксплойта в issue этого каталога. После согласования с
мейнтейнером запросите исправление записи каталога или статус карантина, не включая
чувствительные материалы для воспроизведения.

## Сообщение об уязвимости каталога

Когда публичный репозиторий доступен, используйте его приватный канал GitHub Security
Advisory для уязвимостей в валидации каталога или обработке вкладов. Не используйте публичный
issue для непропатченной уязвимости.

## Секреты и персональные данные

Никогда не отправляйте токены доступа, API-ключи, cookie, приватные адреса электронной почты,
учётные данные или содержимое приватных репозиториев в записях, pull request'ах или формах
issue. Публичные доказательства должны происходить из оригинального публичного исходного
репозитория и его закреплённого коммита.

## Неофициальный статус

Это неофициальный проект сообщества. Он не аффилирован с DeepSeek, не одобрен и не
спонсируется DeepSeek. Названия и товарные знаки DeepSeek принадлежат их правообладателю.
