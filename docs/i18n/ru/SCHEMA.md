# Справочник схемы записи каталога

> 🌐 [English](../../docs/SCHEMA.md) · [Português (Brasil)](../pt-BR/SCHEMA.md) · [中文（简体）](../zh-CN/SCHEMA.md) · **Русский**

> **Неофициальный проект сообщества. Не аффилирован, не одобрен и не спонсируется DeepSeek.**
> Имена и товарные знаки DeepSeek принадлежат их соответствующим владельцам.

Это постатейный справочник для [`schemas/plugin.schema.yaml`](../../schemas/plugin.schema.yaml) —
публичной JSON Schema (draft 2020-12), которой должен соответствовать каждый файл в
`catalog/plugins/`. Сам файл схемы — источник истины; когда эта страница и схема расходятся,
побеждает схема.

Применяются два уровня валидации. Публичная схема применяет ограниченные *безопасные формы*
(паттерны и длины, которые отклоняют значения, похожие на опции, или неограниченные значения).
Поверх этого `catalog validate` применяет обязательные семантические парсеры: точный SemVer для
версий, SHA-512 SRI для значений целостности, парсинг SPDX-выражений для лицензий и отклонение
дублирующихся ключей. Значение может соответствовать паттерну схемы и всё же быть отклонено
семантически.

Правила верхнего уровня: запись — это единый объект YAML, `additionalProperties: false`
(неизвестные поля отклоняются), и **все** следующие поля обязательны.

## Поля верхнего уровня

| Поле               | Тип    | Обязательно | Резюме                                                        |
| ------------------- | ------- | :---------: | ------------------------------------------------------------- |
| `schemaVersion`     | const   |     да      | Должно быть точно `1`                                         |
| `id`                | string  |     да      | ID записи в нижнем регистре kebab-case; должен совпадать с именем файла |
| `name`              | string  |     да      | Отображаемое имя, 1–120 символов                               |
| `description`       | object  |     да      | Курируемое резюме на английском плюс путь к его доказательству |
| `unofficial`        | const   |     да      | Должно быть точно `true`                                       |
| `kind`              | enum    |     да      | Канонический дискриминатор артефакта                           |
| `primaryCategory`   | enum    |     да      | Единственная основная категория возможностей                   |
| `tags`              | array   |     да      | Уникальные теги в нижнем регистре kebab-case (может быть пустым) |
| `source`            | object  |     да      | Оригинальный репозиторий, node ID, подпуть и закреплённый коммит |
| `creator`           | object  |     да      | Публичный GitHub-хендл создателя                                |
| `package`           | object  |     да      | Канонический дескриптор установки (npm **или** source)          |
| `dsh`               | object  |     да      | Профили DSH и путь к доказательству нативной интеграции          |
| `repositoryScope`   | enum    |     да      | `dedicated` или `monorepo`                                      |
| `popularity`        | object  |     да      | Политика звёзд и число звёзд (условно от области)                |
| `license`           | object  |     да      | Upstream-выражение лицензии SPDX                                 |
| `verification`      | object  |     да      | Статус верификации, время проверки, идентичность и smoke-тест    |
| `provenance`        | object  |     да      | Публичные URL Discussion/комментария или `null`                  |

### `schemaVersion`

Константа `1`. Определяет версию 1 публичной схемы; любое другое значение недопустимо.

### `id`

Строка, соответствующая `^[a-z0-9]+(?:-[a-z0-9]+)*$` — нижний регистр kebab-case, без начальных,
конечных или двойных дефисов. Согласно [CONTRIBUTING.md](../../CONTRIBUTING.md), файл записи
должен называться `catalog/plugins/<id>.yaml` с идентичным значением.

### `name`

Свободное отображаемое имя, `minLength: 1`, `maxLength: 120`.

### `description`

Объект ровно с двумя обязательными свойствами (никаких других не допускается):

| Свойство       | Тип    | Правила                                                                 |
| -------------- | ------ | ------------------------------------------------------------------------- |
| `en`           | string | Резюме на английском, 20–320 символов                                     |
| `evidencePath` | string | Паттерн относительного пути репозитория; без начального `/`, без обратных слэшей, без сегментов `.`/`..` |

Резюме на английском должно быть курировано из файла в `evidencePath` таким, каким он существует на
`source.commit` — не скопировано из другого каталога.

### `unofficial`

Константа `true`. Машиночитаемый маркер того, что листинг неофициален.

### `kind`

**Единственный** дискриминатор типа артефакта (второго поля типа интеграции не существует. Один из:

`plugin` · `plugin-family` · `skin-theme` · `skill` · `preset-profile` · `client-interface` ·
`bridge-adapter` · `ecosystem-project`

Значения и последствия для рейтинга определены в [docs/CATEGORIES.md](../../docs/CATEGORIES.md).

### `primaryCategory`

Одна из тринадцати категорий возможностей:

`user-interface-dashboards` · `memory-rag` · `search-research` · `coding-developer-tools` ·
`browser-automation` · `vision-audio-multimodal` · `sessions-productivity` ·
`security-permissions-approvals` · `diagnostics-observability` · `models-providers-routing` ·
`messaging-notifications` · `data-external-services` · `entertainment-customization`

Отображаемые метки и рекомендации по выбору — в [docs/CATEGORIES.md](../../docs/CATEGORIES.md).

### `tags`

Массив уникальных строк, каждая соответствует `^[a-z0-9]+(?:-[a-z0-9]+)*$` (нижний регистр
kebab-case). Схема не устанавливает минимального количества.

### `source`

Объект ровно с четырьмя обязательными свойствами:

| Свойство           | Тип              | Правила                                                                  |
| ------------------- | ---------------- | ---------------------------------------------------------------------------- |
| `repository`        | string           | URL `https://github.com/<owner>/<repo>`; владелец следует правилам имён пользователей GitHub, имя репозитория 1–100 символов, не может быть `.`/`..` или заканчиваться на `.git` |
| `repositoryNodeId`  | string           | Неизменяемый node ID репозитория GitHub, непустой                            |
| `subpath`           | string или null  | Подпуть плагина внутри репозитория (тот же безопасный паттерн относительного пути, что и `evidencePath`), или `null` для плагина в корне репозитория |
| `commit`            | string           | Полный 40-символьный шестнадцатеричный OID коммита                           |

Проверка каталога должна разрешать `repositoryNodeId` и отклонять несовпадение URL репозитория —
это разрешение — барьер со стороны мейнтейнера, а не часть локальной структурной проверки.

### `creator`

Объект с одним обязательным свойством:

| Свойство | Тип    | Правила                                               |
| -------- | ------ | ------------------------------------------------------- |
| `github` | string | Имя пользователя GitHub (1–39 символов, правила хендла GitHub) |

URL публичного профиля всегда выводится как `https://github.com/<handle>`; второе поле профиля не
хранится, поэтому они никогда не могут разойтись.

### `package`

Канонический дескриптор установки. Это данные, а не команда shell, и он принимает ровно одну из
двух форм (`oneOf`):

**пакет npm** — обязательны `ecosystem`, `name`, `version`; опционально `integrity`:

| Свойство    | Тип    | Правила                                                                        |
| ----------- | ------ | ------------------------------------------------------------------------------------ |
| `ecosystem` | const  | `npm`                                                                                 |
| `name`      | string | Форма имени пакета npm (опционально со scope), максимум 214 символов                 |
| `version`   | string | Точная форма версии `x.y.z` (опциональные prerelease/build); диапазоны отклоняются. Семантический уровень дополнительно требует разбираемого точного SemVer |
| `integrity` | string | Опциональная форма SRI `sha512-…`, 8–256 символов. Семантический уровень должен разобрать её как валидный SHA-512 SRI |

**установка из source** — обязателен только `ecosystem`:

| Свойство    | Тип    | Правила  |
| ----------- | ------ | -------- |
| `ecosystem` | const  | `source` |

Дескриптор source намеренно не хранит ничего больше: репозиторий, коммит и подпуть выводятся из
`source`, поэтому изменяемые значения никогда не дублируются.

### `dsh`

Доказательство нативной интеграции с DSH:

| Свойство       | Тип    | Правила                                                                    |
| --------------- | ------ | -------------------------------------------------------------------------------- |
| `profiles`      | array  | Хотя бы одно уникальное имя профиля, соответствующее `^[A-Za-z0-9][A-Za-z0-9._-]*$` |
| `evidencePath`  | string | Безопасный относительный путь к доказательству интеграции с DSH на `source.commit` |

### `repositoryScope`

Либо `dedicated` (звёзды репозитория принадлежат именно этому плагину), либо `monorepo` (плагин —
это подпуть или пакет внутри более широкого проекта). Это значение определяет условные правила
популярности ниже.

### `popularity`

| Свойство      | Тип                | Правила                                                |
| -------------- | ------------------- | -------------------------------------------------------- |
| `starsPolicy`  | enum                | `exact-repository` или `undefined-parent-repository`      |
| `stars`        | integer или null    | Неотрицательное целое число, или `null`                    |

Условные правила (применяются блоками `allOf` схемы):

- `repositoryScope: monorepo` **вынуждает** `starsPolicy: undefined-parent-repository` и
  `stars: null`. Звёзды родительского проекта никогда не приписываются плагину монорепозитория.
- `repositoryScope: dedicated` **вынуждает** `starsPolicy: exact-repository` и целое
  `stars >= 0`.

См. [docs/RANKING.md](../../docs/RANKING.md) о том, как эти значения питают предикат рейтинга.

### `license`

| Свойство | Тип    | Правила                                                            |
| -------- | ------ | -------------------------------------------------------------------- |
| `spdx`   | string | Форма SPDX-выражения, 2–256 символов, без начального дефиса          |

Схема применяет только безопасную форму символов; проверка каталога должна разобрать и
нормализовать значение реальным парсером SPDX-выражений. Записывайте полное upstream-выражение,
доказанное на закреплённом коммите (например `Apache-2.0` или `MIT OR GPL-3.0-only`).

### `verification`

Верификация применяется к `source.commit`. Объект с четырьмя обязательными свойствами:

| Свойство               | Тип              | Правила                                                  |
| ------------------------ | ----------------- | ------------------------------------------------------------ |
| `status`                 | enum              | `eligible` · `verified` · `stale` · `unavailable` · `archived` · `quarantined` |
| `checkedAt`              | string            | Временная метка проверки в формате `date-time`                |
| `repositoryIdentity`     | const             | Должно быть `resolved`                                        |
| `smokeTest`              | object или null   | Запись smoke-теста, или `null`, когда подходящий тест отсутствует |

При наличии `smokeTest` требует:

| Свойство        | Тип    | Правила                                                              |
| ---------------- | ------ | ---------------------------------------------------------------------------- |
| `installTarget`  | const  | `canonical-install-descriptor` — ссылается на `package` или закреплённый source без дублирования изменяемых значений |
| `check`          | object | Обязательны `name` (форма имени пакета) и `version` (форма точной версии) |
| `result`         | const  | `passed` — неудачный smoke-тест не записывается как smoke-тест    |

Условное правило: `status: verified` **требует** ненулевой объект `smokeTest`. Записи без
проверяемого доказательства smoke-теста используют `status: eligible` и `smokeTest: null`. Ни один
статус не является одобрением или сертификацией безопасности — см.
[docs/RANKING.md](../../docs/RANKING.md).

### `provenance`

Публичные ссылки происхождения, каждая — URI или `null`:

| Свойство      | Тип              | Правила                                            |
| -------------- | ----------------- | ------------------------------------------------------ |
| `discussion`   | string или null   | Публичный URL Discussion, если существует               |
| `comment`      | string или null   | Публичный URL комментария, если существует               |

## Что схема не проверяет

Схема намеренно локальна и структурна. Она **не** проверяет, существует ли репозиторий, совпадает
ли node ID с URL, существуют ли пути доказательств на закреплённом коммите, точно ли число звёзд
или владеет ли создатель источником. Эти проверки принадлежат барьерам ревью мейнтейнеров,
описанным в [CONTRIBUTING.md](../../CONTRIBUTING.md) и
[docs/GOVERNANCE.md](../../docs/GOVERNANCE.md).
