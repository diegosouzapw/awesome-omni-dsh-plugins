# 安全策略

## 目录范围

本仓库包含目录元数据、文档和通用的贡献配置。收录并不代表安全认证,本项目也不对任何插件做出背书或
保证。在安装某个条目之前,请自行检查其原始仓库、固定的源代码提交、许可证和安装行为。

## 报告插件漏洞

请将已收录插件中的漏洞私下报告给该插件的原始维护者。不要在本目录的 issue 中公开利用细节。在与维护
者沟通协调后,可以在不包含敏感复现材料的情况下,请求进行目录更正或标记为隔离(quarantine)状态。

## 报告目录漏洞

当公开仓库可用时,针对目录校验或贡献处理流程中的漏洞,请使用其私密的 GitHub Security Advisory 渠
道报告。未修复的漏洞请勿使用公开 issue 报告。

## 敏感信息与个人数据

切勿在条目、拉取请求或 issue 表单中提交访问令牌、API 密钥、Cookie、私人电子邮件地址、凭据或私有仓
库内容。公开证据必须来自原始公开来源仓库及其固定提交。

## 非官方状态

这是一个非官方社区项目,与 DeepSeek 无关联、未经其认可,也未获其赞助。DeepSeek 的名称与标识归其各
自所有者所有。
