# Kredit Pencipta dan Keutamaan Pull Request

> 🌐 [English](../../docs/CREDIT.md) · **Bahasa Melayu (ms)**

> **Projek komuniti tidak rasmi. Tiada gabungan, kelulusan atau tajaan daripada DeepSeek.**
> Nama dan tanda DeepSeek adalah kepunyaan pemilik masing-masing.

Katalog ini wujud untuk menjadikan kerja DSH bebas boleh ditemui tanpa mengambil pemilikan
daripada penciptanya. Entri awam merujuk repositori asal dan komit sumber tak boleh ubah.

## Keutamaan untuk pemalam yang sama

<!-- creator-first:direct-pr-supersedes-curation-and-automation -->

1. Pull request yang dibuka oleh pencipta pemalam atau organisasi pemilik.
2. Pull request komuniti yang diluluskan secara eksplisit atau dikarang bersama oleh
   pencipta.
3. Pull request komuniti sah yang sedia ada.
4. Pull request automasi katalog.
5. Calon persendirian tanpa pull request awam.

Pull request pencipta langsung sentiasa diutamakan dan mengatasi mana-mana pull request
kurasi komuniti atau automasi yang terbuka bagi pemalam kanonik yang sama, tanpa mengira
mana yang dibuka dahulu atau lebih maju. Pull request pencipta menjadi kenderaan semakan;
cabang mereka tidak sesekali ditulis ganti, force-push atau dipindahkan ke dalam pull
request yang dikuratori. Jika entri yang dikuratori sudah digabungkan, sejarah kekal utuh
dan pencipta boleh menuntut atau membetulkannya dalam sumbangan baharu.

## Atribusi awam

Setiap entri katalog membawa pengendali GitHub awam pencipta, repositori asal, ID nod
repositori, subpath pemalam dan komit penuh yang dipasak. Profil pencipta awam diperoleh
daripada pengendali tunggal itu dan bukannya disimpan sebagai identiti kedua. Pintu
gerbang provenans penyelenggara yang berasingan menyelesaikan ID nod dan menolak
percanggahan URL repositori. Penerangan pull request sepatutnya menyatakan
`Created by @handle` dan menyertakan metadata repositori sumber dan komit sumber.

Seseorang yang menyiarkan atau mengulas pada Discussion tidak secara automatik dianggap
sebagai pencipta. Pemilikan mesti disokong oleh pemilik repositori atau organisasi,
pengarangan pakej, metadata manifes atau sejarah sumber yang dipasak tepat.

## Identiti Git

<!-- creator-first:source-bound-git-identity -->

Pengarangan komit dan pengarangan pull request adalah berasingan. Pull request yang
berasal daripada pencipta mengekalkan pencipta sebagai pengarang pull request, dan
komit mereka mengekalkan pengarangan secara semula jadi. Akaun penyelenggara atau
automasi boleh muncul sebagai committer atau sebagai ko-pengarang yang disahkan, tetapi
tidak boleh menggantikan pengarangan pencipta.

Untuk komit yang dikuratori, gunakan pencipta sebagai pengarang Git atau tambah trailer
`Co-authored-by` hanya apabila identiti tepat itu terikat sumber dan boleh disahkan
secara awam, seperti identiti yang sudah dilekatkan pada komit pencipta dalam repositori
asal. Jangan sesekali teka e-mel, cipta alamat noreply atau gunakan alamat persendirian
yang dijumpai di luar sumber awam yang dibenarkan.

Apabila identiti Git yang disahkan tidak tersedia, kurator atau akaun automasi mengarang
komit itu dan memberikan kredit yang kelihatan secara eksplisit: `Created by @handle`,
profil awam yang sepadan dan pautan kepada repositori asal dalam entri dan pull request.
Atribusi YAML yang kelihatan sentiasa diperlukan secara berasingan daripada pemetaan
identiti Git. Pull request pencipta langsung yang datang kemudian menggantikan pull
request yang dikuratori terbuka dan bukannya mewarisi sejarah sintetiknya.

## Sebutan pencipta yang menghormati

Pull request yang dikuratori menggunakan satu sebutan awam `@creator` yang menghormati
dalam penerangannya di sebelah pautan repositori asal. Ia boleh menjemput semakan atau
pull request langsung sebagai gantian. Jangan ulangi sebutan itu, buka isu promosi,
siar silang atau hantar mesej peribadi tanpa diminta.

## Lesen katalog berbanding lesen huluan

Fakta katalog dan metadata editorial YAML didedikasikan di bawah CC0-1.0. Dedikasi itu
tidak mengubah lesen pemalam huluan. Kod huluan, dokumentasi, tangkapan skrin, logo dan
bahan kreatif lain kekal tertakluk kepada lesen dan pemilik asal mereka.
