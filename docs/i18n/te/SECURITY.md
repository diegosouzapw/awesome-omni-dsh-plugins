# సెక్యూరిటీ పాలసీ

## కేటలాగ్ పరిధి

ఈ రిపాజిటరీ కేటలాగ్ మెటాడేటా, డాక్యుమెంటేషన్ మరియు సాధారణ సహకార కాన్ఫిగరేషన్‌ను కలిగి ఉంటుంది.
లిస్టింగ్ అనేది సెక్యూరిటీ సర్టిఫికేషన్ కాదు, మరియు ఈ ప్రాజెక్ట్ ఏ ప్లగిన్‌ను కూడా ఆమోదించదు లేదా హామీ
ఇవ్వదు. ఎంట్రీని ఇన్‌స్టాల్ చేసే ముందు అసలు రిపాజిటరీ, పిన్ చేయబడిన సోర్స్ కమిట్, లైసెన్స్ మరియు ఇన్‌స్టాలేషన్
ప్రవర్తనను తనిఖీ చేయండి.

## ప్లగిన్ దుర్బలత్వాన్ని నివేదించడం

లిస్ట్ చేయబడిన ప్లగిన్‌లోని దుర్బలత్వాలను ఆ ప్లగిన్ యొక్క అసలు మెయింటైనర్‌కు ప్రైవేట్‌గా నివేదించండి. ఈ
కేటలాగ్ యొక్క ఇష్యూలలో ఎక్స్‌ప్లాయిట్ వివరాలను ప్రచురించవద్దు. మెయింటైనర్‌తో సమన్వయం చేసుకున్న తర్వాత,
సున్నితమైన పునరుత్పత్తి మెటీరియల్‌ను చేర్చకుండా కేటలాగ్ సవరణ లేదా క్వారంటైన్ స్థితిని అభ్యర్థించండి.

## కేటలాగ్ దుర్బలత్వాన్ని నివేదించడం

పబ్లిక్ రిపాజిటరీ అందుబాటులో ఉన్నప్పుడు, కేటలాగ్ వాలిడేషన్ లేదా సహకార నిర్వహణలోని దుర్బలత్వాల కోసం దాని
ప్రైవేట్ GitHub Security Advisory ఛానెల్‌ను ఉపయోగించండి. ప్యాచ్ చేయని దుర్బలత్వం కోసం పబ్లిక్ ఇష్యూను
ఉపయోగించవద్దు.

## రహస్యాలు మరియు వ్యక్తిగత డేటా

ఎంట్రీలు, పుల్ రిక్వెస్ట్‌లు లేదా ఇష్యూ ఫారమ్‌లలో యాక్సెస్ టోకెన్‌లు, API కీలు, కుకీలు, ప్రైవేట్ ఇమెయిల్
చిరునామాలు, క్రెడెన్షియల్స్ లేదా ప్రైవేట్ రిపాజిటరీ కంటెంట్‌ను ఎప్పుడూ సమర్పించవద్దు. పబ్లిక్ సాక్ష్యం అసలు
పబ్లిక్ సోర్స్ రిపాజిటరీ మరియు దాని పిన్ చేయబడిన కమిట్ నుండి రావాలి.

## అనధికారిక స్థితి

ఇది ఒక అనధికారిక కమ్యూనిటీ ప్రాజెక్ట్. ఇది DeepSeekతో అనుబంధం కలిగి లేదు, దాని ఆమోదం పొందలేదు లేదా
స్పాన్సర్ చేయబడలేదు. DeepSeek పేర్లు మరియు గుర్తులు వాటి సంబంధిత యజమానికి చెందినవి.
