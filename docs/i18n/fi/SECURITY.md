# Tietoturvakäytäntö

> 🌐 [English](../../SECURITY.md) · **Suomi**

> **Epävirallinen yhteisöprojekti. Ei liity DeepSeekiin eikä DeepSeek ole hyväksynyt tai sponsoroinut sitä.**

## Katalogin laajuus

Tämä repositorio sisältää katalogin metadataa, dokumentaatiota ja yleistä osallistumisasetelmaa.
Listaus ei ole tietoturvasertifikaatti, eikä tämä projekti suosittele tai takaa mitään
liitännäistä. Tarkista alkuperäinen repositorio, kiinnitetty lähdecommit, lisenssi ja
asennuskäyttäytyminen ennen merkinnän asentamista.

## Liitännäisen haavoittuvuudesta ilmoittaminen

Ilmoita listatun liitännäisen haavoittuvuuksista yksityisesti kyseisen liitännäisen alkuperäiselle
ylläpitäjälle. Älä julkaise exploit-yksityiskohtia tämän katalogin issueissa. Kun olet
koordinoanut ylläpitäjän kanssa, pyydä katalogin korjausta tai karanteenitilaa sisällyttämättä
arkaluonteista jäljennysmateriaalia.

## Katalogin haavoittuvuudesta ilmoittaminen

Kun julkinen repositorio on käytettävissä, käytä sen yksityistä GitHub Security Advisory -kanavaa
katalogin validoinnin tai osallistumiskäsittelyn haavoittuvuuksille. Älä käytä julkista issuea
paikkaamattomalle haavoittuvuudelle.

## Salaisuudet ja henkilötiedot

Älä koskaan lähetä access tokeneita, API-avaimia, evästeitä, yksityisiä sähköpostiosoitteita,
tunnuksia tai yksityisen repositorion sisältöä merkinnöissä, pull requesteissa tai
issue-lomakkeissa. Julkisten todisteiden on tultava alkuperäisestä julkisesta lähderepositoriosta
ja sen kiinnitetystä commitista.

## Epävirallinen asema

Tämä on epävirallinen yhteisöprojekti. Se ei liity DeepSeekiin eikä DeepSeek ole hyväksynyt tai
sponsoroinut sitä. DeepSeekin nimet ja tunnukset kuuluvat niiden omistajalle.
