# Polityka bezpieczeństwa

> 🌐 [English](../../SECURITY.md) · **Polski**

## Zakres katalogu

To repozytorium zawiera metadane katalogu, dokumentację i ogólną konfigurację współtworzenia.
Umieszczenie na liście nie jest certyfikacją bezpieczeństwa, a ten projekt nie popiera ani nie
gwarantuje żadnej wtyczki. Przed instalacją danego wpisu sprawdź oryginalne repozytorium,
przypięty commit źródłowy, licencję i zachowanie instalacyjne.

## Zgłaszanie luki w bezpieczeństwie wtyczki

Luki w bezpieczeństwie wtyczki znajdującej się na liście zgłaszaj prywatnie oryginalnemu opiekunowi
tej wtyczki. Nie publikuj szczegółów exploitów w zgłoszeniach (issues) tego katalogu. Po
skoordynowaniu działań z opiekunem poproś o korektę wpisu w katalogu lub stan kwarantanny, bez
dołączania wrażliwego materiału reprodukcyjnego.

## Zgłaszanie luki w bezpieczeństwie katalogu

Gdy publiczne repozytorium jest dostępne, do zgłaszania luk w walidacji katalogu lub obsłudze
współtworzenia użyj jego prywatnego kanału GitHub Security Advisory. Nie używaj publicznego
zgłoszenia (issue) do niezałatanej luki.

## Sekrety i dane osobowe

Nigdy nie przesyłaj tokenów dostępu, kluczy API, ciasteczek, prywatnych adresów e-mail,
poświadczeń ani zawartości prywatnych repozytoriów we wpisach, pull requestach ani formularzach
zgłoszeń. Publiczny dowód musi pochodzić z oryginalnego publicznego repozytorium źródłowego i
jego przypiętego commita.

## Status nieoficjalny

To jest nieoficjalny projekt społecznościowy. Nie jest powiązany z DeepSeek, nieautoryzowany ani
niesponsorowany przez DeepSeek. Nazwy i znaki DeepSeek należą do ich właściwego właściciela.
