# นโยบายความปลอดภัย

> 🌐 [English](../../SECURITY.md) · **ไทย (th)**

> **โปรเจกต์ชุมชนที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง และไม่ได้รับการสนับสนุนจาก DeepSeek**
> ชื่อและเครื่องหมายการค้าของ DeepSeek เป็นของเจ้าของแต่ละราย

## ขอบเขตของแคตตาล็อก

รีโพซิทอรีนี้ประกอบด้วยเมทาดาทาแคตตาล็อก เอกสารประกอบ และการตั้งค่าการมีส่วนร่วมทั่วไป การอยู่ในรายการไม่ใช่
ใบรับรองด้านความปลอดภัย และโปรเจกต์นี้ไม่รับรองหรือรับประกันปลั๊กอินใด ๆ ตรวจสอบรีโพซิทอรีดั้งเดิม คอมมิตต้นทาง
ที่ตรึงไว้ ใบอนุญาต และพฤติกรรมการติดตั้งก่อนติดตั้งรายการใด ๆ เสมอ

## การรายงานช่องโหว่ของปลั๊กอิน

รายงานช่องโหว่ในปลั๊กอินที่อยู่ในรายการอย่างเป็นส่วนตัวไปยังผู้ดูแลดั้งเดิมของปลั๊กอินนั้น อย่าเผยแพร่รายละเอียด
การโจมตี (exploit) ใน issue ของแคตตาล็อกนี้ หลังจากประสานงานกับผู้ดูแลแล้ว ให้ส่งคำขอแก้ไขหรือขอสถานะกักกัน
(quarantine) ของแคตตาล็อกโดยไม่รวมข้อมูลการทำซ้ำที่ละเอียดอ่อน

## การรายงานช่องโหว่ของแคตตาล็อก

เมื่อรีโพซิทอรีสาธารณะพร้อมใช้งาน ให้ใช้ช่องทาง GitHub Security Advisory แบบส่วนตัวของรีโพซิทอรีนั้นสำหรับ
ช่องโหว่ในการตรวจสอบแคตตาล็อกหรือการจัดการการมีส่วนร่วม อย่าใช้ issue สาธารณะสำหรับช่องโหว่ที่ยังไม่ได้รับการแก้ไข

## ความลับและข้อมูลส่วนตัว

ห้ามส่ง access token, API key, คุกกี้, ที่อยู่อีเมลส่วนตัว ข้อมูลรับรองตัวตน หรือเนื้อหาจากรีโพซิทอรีส่วนตัวใน
รายการ พูลรีเควสต์ หรือแบบฟอร์ม issue เด็ดขาด หลักฐานสาธารณะต้องมาจากรีโพซิทอรีต้นทางสาธารณะดั้งเดิมและคอมมิต
ที่ตรึงไว้ของมันเท่านั้น

## สถานะไม่เป็นทางการ

นี่คือโปรเจกต์ชุมชนที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง และไม่ได้รับการสนับสนุนจาก DeepSeek
ชื่อและเครื่องหมายการค้าของ DeepSeek เป็นของเจ้าของแต่ละราย
