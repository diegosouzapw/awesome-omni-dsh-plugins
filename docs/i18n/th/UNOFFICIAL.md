# ประกาศโปรเจกต์ไม่เป็นทางการ

> 🌐 [English](../../docs/UNOFFICIAL.md) · **ไทย (th)**

> **โปรเจกต์ชุมชนที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง และไม่ได้รับการสนับสนุนจาก DeepSeek**
> ชื่อและเครื่องหมายการค้าของ DeepSeek เป็นของเจ้าของแต่ละราย

Awesome Omni DSH Plugins เป็นโปรเจกต์แคตตาล็อกและตัวติดตั้งของชุมชนที่เป็นอิสระ การที่ปลั๊กอินปรากฏอยู่ใน
แคตตาล็อกไม่ได้หมายความถึงการรีวิว การรับรอง การสนับสนุน หรือการอนุมัติจาก DeepSeek หรือจากผู้ดูแลของโปรเจกต์นี้

โปรเจกต์นี้ไม่ใช้โลโก้อย่างเป็นทางการของ DeepSeek ไม่เลียนแบบอัตลักษณ์ภาพอย่างเป็นทางการของ DeepSeek และไม่
บรรยายสถานะของแคตตาล็อกว่าเป็นการรับรองอย่างเป็นทางการ การอ้างอิงถึง DeepSeek Harness และ DSH ระบุเพียง
เป้าหมายความเข้ากันได้เท่านั้น

ชื่อปลั๊กอิน ชื่อโปรเจกต์ โลโก้ ภาพหน้าจอ โค้ด และเอกสารประกอบเป็นของเจ้าของแต่ละรายและยังคงอยู่ภายใต้ใบอนุญาต
และนโยบายเครื่องหมายการค้าดั้งเดิมของพวกเขา
