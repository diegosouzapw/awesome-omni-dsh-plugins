# วิธีการจัดอันดับ

> 🌐 [English](../../docs/RANKING.md) · **ไทย (th)**

> **โปรเจกต์ชุมชนที่ไม่เป็นทางการ ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง และไม่ได้รับการสนับสนุนจาก DeepSeek**
> ชื่อและเครื่องหมายการค้าของ DeepSeek เป็นของเจ้าของแต่ละราย

การจัดอันดับคือมุมมองที่โปร่งใสเหนือรายการแคตตาล็อกสาธารณะที่ผสานแล้ว การจัดอันดับไม่เคยใช้คะแนนรวมที่ซ่อนอยู่
และไม่เคยถือว่าดาวจากโปรเจกต์แม่ที่กว้างกว่าเป็นความนิยมของปลั๊กอิน

## หลักเกณฑ์ปลั๊กอิน 10 อันดับตามดาว (Top Plugins by Stars)

รายการจะผ่านเงื่อนไขก็ต่อเมื่อทุกเงื่อนไขด้านล่างเป็นจริง:

```text
kind == plugin (the canonical native DSH bundle discriminator)
repositoryScope == dedicated
verification.status in [eligible, verified]
repository is active and not archived
stars belong to the exact plugin repository
entry is merged into the public catalog
```

รายการที่ผ่านเงื่อนไขใช้ `popularity.starsPolicy: exact-repository` และจำนวนเต็มที่ไม่ติดลบใน
`popularity.stars` ในกรณีที่คะแนนเท่ากัน จะใช้ ID ปลั๊กอินแบบไม่สนตัวพิมพ์เล็กใหญ่เป็นลำดับการแสดงผลที่แน่นอน
การตัดสินเสมอนี้ไม่ได้หมายความถึงความแตกต่างด้านคุณภาพ

`kind` เป็นตัวจำแนกประเภทผลงานเพียงตัวเดียว สคีมาจงใจไม่เก็บฟิลด์ประเภทการเชื่อมต่อ DSH ที่สองซึ่งอาจขัดแย้งกัน

## ข้อยกเว้นที่ชัดแจ้ง

ปลั๊กอินที่อยู่ใน monorepo ที่กว้างกว่ายังคงมีสิทธิ์อยู่ในแคตตาล็อก แต่ดาวของโปรเจกต์แม่ไม่ถูกกำหนดสำหรับการ
จัดอันดับปลั๊กอิน มันต้องใช้ `repositoryScope: monorepo`, `popularity.starsPolicy: undefined-parent-repository`
และ `popularity.stars: null` มันจะปรากฏในส่วนการใช้งานและถูกยกเว้นจากการจัดอันดับตามดาวทุกประเภท

กลุ่มปลั๊กอิน (plugin families), ธีม, สกิน, สกิล, พรีเซ็ต, ไคลเอนต์, อินเทอร์เฟซ, สะพานเชื่อม และโปรเจกต์
ecosystem ที่กว้างกว่า จะไม่ปรากฏในปลั๊กอิน 10 อันดับตามดาว พวกมันจะได้รับส่วนแยกต่างหากในที่ที่มีข้อมูลที่
เปรียบเทียบกันได้ Aggregator มาร์เก็ตเพลส แคตตาล็อกตัวติดตั้ง และรายชื่อ ไม่ใช่รายการในแคตตาล็อกและไม่ได้รับส่วน
ในแคตตาล็อกใด ๆ

## มุมมองการจัดอันดับ

โปรเจกต์นี้อาจเผยแพร่มุมมองที่แตกต่างกันสำหรับดาว การเติบโตใน 24 ชั่วโมง การเติบโตใน 7 วัน การอัปเดตล่าสุด
การติดตั้งที่ยืนยันแล้ว กลุ่มปลั๊กอิน ธีมและสกิน ไคลเอนต์และอินเทอร์เฟซ และการผสานรวมกับ ecosystem แต่ละมุมมอง
ต้องเปิดเผยกฎการรวมของตัวเองและเวลา snapshot

เมื่อมีรายการที่ผ่านเงื่อนไขเป็นศูนย์ ปลั๊กอินยอดนิยม (Top Plugins) จะไม่ถูกแสดงผล การผสานรายการแรกที่ผ่านเงื่อนไข
จะสร้างมุมมองปลั๊กอินยอดนิยม ป้ายชื่อจะเปลี่ยนเป็น 10 อันดับก็ต่อเมื่อมีรายการที่ผ่านเงื่อนไขครบสิบรายการแล้ว
เท่านั้น ไม่อนุญาตให้ใช้การจัดอันดับตัวยึดตำแหน่งหรือที่กุขึ้นเองเด็ดขาด

## การยืนยันไม่ใช่การรับรอง

`eligible` หมายความว่าโครงสร้างสาธารณะและการเชื่อมต่อ DSH ได้รับการตรวจสอบแล้ว `verified` หมายความเพิ่มเติมว่า
การทดสอบเบื้องต้นของการติดตั้งผ่านสำหรับซอร์สหรือแพ็กเกจที่ตรึงไว้ ไม่มีสถานะใดเป็นการรับรอง การรับประกัน หรือ
ใบรับรองด้านความปลอดภัยแบบสมบูรณ์
