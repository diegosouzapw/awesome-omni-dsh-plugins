# Política de Segurança

> 🌐 [English](../../../SECURITY.md) · [Português (Brasil)](../pt-BR/SECURITY.md) · [中文（简体）](../zh-CN/SECURITY.md) · **Português**

## Âmbito do catálogo

Este repositório contém metadados de catálogo, documentação e configuração genérica de
contribuição. Uma listagem não é uma certificação de segurança, e este projeto não endossa nem
garante nenhum plugin. Verifique o repositório original, o commit de origem fixado, a licença e
o comportamento de instalação antes de instalar uma entrada.

## Reportar uma vulnerabilidade de um plugin

Reporte vulnerabilidades num plugin listado, de forma privada, ao mantenedor original desse
plugin. Não publique detalhes de exploração nas issues deste catálogo. Depois de coordenar com o
mantenedor, peça uma correção ou um estado de quarentena no catálogo, sem incluir material de
reprodução sensível.

## Reportar uma vulnerabilidade do catálogo

Quando o repositório público estiver disponível, use o seu canal privado de GitHub Security
Advisory para vulnerabilidades na validação do catálogo ou no tratamento de contribuições. Não
use uma issue pública para uma vulnerabilidade ainda não corrigida.

## Segredos e dados pessoais

Nunca submeta tokens de acesso, chaves de API, cookies, endereços de e-mail privados,
credenciais ou conteúdo de repositórios privados em entradas, pull requests ou formulários de
issue. A prova pública tem de vir do repositório de origem público original e do seu commit
fixado.

## Estatuto não oficial

Este é um projeto comunitário não oficial. Não tem afiliação, endosso nem patrocínio da
DeepSeek. Os nomes e marcas DeepSeek pertencem aos respetivos proprietários.
